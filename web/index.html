一念生两仪，两仪成决策

AI 产品开发工作流。在关键决策点用两个结构性不同的 AI 产出对抗性输出，由人处理张力并做最终决策——对抗的是 AI 悄悄溶解掉人的独立判断。

默认：Claude × 4 + DeepSeek × 2 + GLM × 1 · 跨维度是硬规则，具体模型可替换

把你的想法跑一遍

写一段产品想法，看它走完全部 13 步：两个对立的专家各出方案、融合、四轮批判与修订。每一步谁在跑、花了多少、产出了什么都会摊开。

最终方案

十三步，四种收场

批判步和修改步交替：每一次批判来自一个新开的、坐标不同的窗口；每一次修改都由同一个执笔窗口完成——分歧在审查环节，不在修改环节，否则方案会变成多个 AI 的拼贴。

最后一步判定之后

产出 v5没有致命论据，且大部分批判打的是实施细节——方向站得住，正常结束。
回 P1 重做两条以上致命论据——方向被推翻，只带原始想法回到起点，整链重跑。
回 P2 重压致命论据不足两条，但大部分批判都在打前提——成品当作新一轮初稿，只重跑四轮批判。
结构性死锁第二轮仍有致命论据且议题与第一轮大量重叠——重跑也会撞同一堵墙，停下来出报告。

最多两轮、单链 $3 封顶。循环是工程层的实现；方法论本体的立场是「回不回退由人判断」，这里把它交给了规则。

为什么是这几个模型

选型分两件事判：坐标判不判得了（硬规则管这个）、能力够不够用。同坐标的模型共享对齐栈和语料文化，因此共享盲区——全 Claude 覆盖等于假覆盖。

维度 A · 冲突偏向含义代表
A1 规范优先有一份独立于任务的成文规范，冲突时规范压过任务Claude、Gemini
A2 权限优先规范是「谁说了算」的权限链，不是价值命题GPT
A3 任务优先公开材料里没有独立规范层，奖励全部来自任务完成度DeepSeek、Kimi、GLM
未公开后训练目标未公开，判不了坐标——不进入任何组合Qwen、豆包、MiniMax

维度 B · 语料文化：B1 英文母语 / B2 中文母语 / B3 跨文化双核。P2 批判链必须跨至少一维。

参考组合

默认

Claude + DeepSeek + GLM

A1·B1 + A3·B3 + A3·B2。两维都跨，坐标三个各不相同。本站演示用的是同结构的便宜档：GPT + DeepSeek Flash + GLM Flash。

替代

Claude 不可用

整体换成 GPT（A2·B1）做锚。跨冲突偏向仍成立，只是 A 侧不是 A1 极端点。

宽松

中文侧只有一家

单盲和拆台共用同一坐标的不同会话。仍跨中西两侧，但中文侧坍缩成一点，建议单盲的提示词纪律更严。

违规

同坐标全覆盖

Claude × 7 不同窗口号，或 Claude + GPT + Gemini。看似独立的四条批判可能一起漏掉同一块维度。硬规则直接拒绝开跑。

六条核心机制

四轴 divergence

任何一对窗口都应在四个维度不同：AI 身份、角色、上下文、范围。四轴完全一致只是一个批判者，不是两个。

P2 链跨底模坐标

四轮批判必须跨至少一维。同坐标 = 假覆盖。这一条由代码在开跑前检查，不过不开跑。

单盲 = 零上下文

单盲窗口只收到方案正文。一旦给背景，它就开始猜意图，机制当场失效。窗口主动拒绝任何注入历史的尝试。

作者 ≠ 批判者

执笔窗口负责所有修改，批判者和复审者各自新开。一个窗口复用多角色会让机制整体坍塌。

Linear 链路防过载

一次处理一条批判。四条一起上会逼人同时持有四个框架，必然选择性忽略。

知情复审查的是漂移

细节错漏属于投资人批判那一轮。知情复审问的是：响应完前两轮之后，是否已从最初的核心定位偏移。
