# 运行手册 · 2026-05-23 投资 Skill · 本体完整跑

这份手册包含 P1 到 P3 每一步的窗口分配、可复制 prompt、以及人工决策点的判断指引。配合 `decision-log.md`(你在每个决策点填)和 `round-1/` 下的结果文件(把各 AI 输出粘进去)使用。

## 用法

每一步:确认窗口编号 → 复制 prompt → 在对应 AI 窗口运行 → 输出粘进 `round-1/` 对应文件 → 遇到决策点,停下,自己判断,填 `decision-log.md`。

窗口编号:同号 = 同一个窗口(保留上下文),不同号 = 新开窗口(清零)。完整分配见 `README.md`。

## 三条硬规则(踩了流程当步失效)

1. **P1.2 专家 B 必须全新独立的 DeepSeek 窗口**——绝不能让它看到专家 A 的方案,只能拿到 P0 精炼想法。看到了 A 的方案,divergence 当场失效。
2. **P2B 单盲必须零上下文**——给 Qwen-1 的窗口里,只粘贴 idea-v2 这一份文档本身。不要粘 P0、不要粘专家方案、不要粘任何批判历史、不要做任何背景说明。给了背景,P2B 当场失效。
3. **idea.md 的所有修改都由 Claude-2 这一个窗口做**——2A-fix / 2B-fix / 2C-rollback / 2D-fix 全部在同一个 Claude-2 窗口续着做,不换窗口、不换 AI。

## 两个非线性分支(提前知道)

- **P2D 是否触发是决策点 6**——跑完 2A/2B/2C 后才判。手册照给 P2D 的 prompt,但触发与否你定。
- **2D-fix 可能回 P1**——若决策点 7 判定"框架级质疑",回 P1 重做、round-2 重启。本手册覆盖 round-1 完整路径;真回 P1 再找 Claude。
