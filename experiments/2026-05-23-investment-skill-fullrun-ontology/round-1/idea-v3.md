# idea-v3.md：Wenbo 的专属投资 Skill 设计方案（修复 P2B 复审卡点后的版本）

## 一、这个 Skill 到底是什么（重写：诚实定位 + 功能清单）

这是一份写给"特定一类强模型"的可执行文件。它的现实定位需要先说清楚两件事——它擅长什么、它**不**擅长什么——以及一份明确的功能清单。

**它擅长的（核心价值）：**

- 作为一份"投资版的自我介绍 + 自我纪律手册"：明确 Wenbo 是谁、想成为什么样的投资人、对自己的纪律期望是什么
- 把会随时间腐烂的事实（居留状态、银行卡、税务身份）从叙事中剥离成可被任何强模型重新计算的结构化变量
- 在每次对话开始时强制走一遍约束检查与风险审视，避免破纪律的冲动操作
- 让 AI 在受限的小空间里做选择，而不是在开阔地里凭直觉发挥

**它**不**擅长的，必须诚实承认：**

- 它**没有任何 alpha 来源**。任何具体标的推荐本质上仍是 LLM 即兴生成，由这个 Skill 的框架"装饰"成看起来经过审视的形式
- 它**不能取代专业研究**，更不能取代 Wenbo 自己对持仓的关注与判断
- 它**不能保证跨模型一致性**

### 1.1 功能清单（明确保留，避免被"无 alpha"声明误读为取消）

本 Skill 提供以下功能。其中"标的推荐"虽然不是核心卖点，但是**明确保留的功能**，不会因为不是核心就被砍掉：

| 功能 | 是否核心 | 说明 |
| --- | --- | --- |
| 时效约束检查（居留/银行/税务/通道）| 是 | 每次对话强制执行 |
| 配置框架校验（核心/卫星/战术/现金）| 是 | 每次动作必须经过框架过滤 |
| 交易成本过滤（决定是否真的执行）| 是 | 小账户的现实保护 |
| 再平衡纪律执行 | 是 | 反人性方向 + 双触发 |
| 24 小时新闻冷静期 | 是 | 防短期反应 |
| **股票/基金推荐（具体标的、金额、仓位归属）** | **否（但保留）** | **见第十三节，每次按 7 项结构输出** |
| **市场背景预测/事件解读** | **否（但保留）** | **通过受控的 Web Search 模块提供，作为背景脚注** |
| 跨境通道迁移建议（回国后路径） | 是 | 居留卡剩余 < 90 天时主动提示 |
| 6 年财务自由目标的现实性提示 | 是 | 季度首次调用输出 |

**理解原则**：核心功能保证 Skill 不让 Wenbo 做愚蠢决策；保留功能保证 Skill 能回答 Wenbo 想问的具体问题（"我现在该买什么？"）。两者都是必要的，只是核心承担风控、保留承担可用性。

## 二、对运行环境的要求

- **推荐运行环境**：Claude 4.7（Opus / Sonnet 当代旗舰）、GPT-5 同级别旗舰，或后续同等推理与长上下文能力的模型
- **明确不支持**：7B 量级及以下的小模型、不具备 Web Search 能力的模型、不具备结构化指令遵循能力的早期模型
- **遇到弱模型时**：Skill 第一步必须要求模型自报家门；若不在推荐范围内，主动告知"当前模型可能无法可靠执行本 Skill 的约束检查与百分比计算，建议切换至 Claude 4.7 或同级"
- **百分比计算硬要求**：所有涉及权重、偏离、配置比例的计算，AI 必须把算式逐行写出来供人核对

## 五、Pre-execution Check Protocol

> **You MUST** 按以下顺序完成检查后，再生成任何投资建议：
>
> 1. **运行环境识别**：自报模型名称与能力。若不在 `recommended_runtime` 范围内，向用户提示风险并询问是否继续。
> 2. **日期解析**：获取 `CURRENT_DATE`；无法获取必须询问。
> 3. **事实状态判定**：对 `expiry_facts` 逐条比对 `hard_date`，若已过期则按 `effect_after_action` 列出的所有动作激活；对 `conditional_facts` 按下表判定风险层级。
> 4. **生成"当前约束快照"**：明列每条通道的风险层级与原因，并列出已激活的 `effect_after_action`。
> 5. **算式可见**：任何涉及百分比、权重、偏离度的计算，必须把算式与中间值写出来。
> 6. **生命阶段同步**：若用户提供 `life_stage_update`，先更新再继续。
> 7. **Web Search**：见第九节（默认关闭，按需触发）。

### 5.1 风险层级判定标准（修复 P2B 卡点 2）

**通道 1：Revolut**

| 风险层级 | 判定条件（按"所有条件必须同时满足"组合） |
| --- | --- |
| 绿 | residence_permit_valid = true **且** swedish_address_still_listed = true **且** login_ip_consistent_with_eu_residence = true **且** account_not_dormant = true（最近 90 天有活跃）**且** source_of_funds_compliant = true |
| 黄 | residence_permit_valid = false **但** 其余四项仍满足（即居留卡过期但 Wenbo 的地址 + IP + 活跃 + SoF 策略全部落地） |
| 红 | 任一以下情形：地址不再可验证 / 登录 IP 与登记国不一致 / 账户休眠超过 180 天 / source of funds 申报受质疑 / Revolut 主动 KYC 复审失败 |

**通道 2：Wise**

| 风险层级 | 判定条件 |
| --- | --- |
| 绿 | residence_permit_valid = true（瑞典在册期间使用） **或** life_stage = working_in_china **且** Wise 已完成中国地址更新且最近 90 天有活跃 |
| 黄 | life_stage = working_in_china **但** 尚未完成中国地址更新；或居留过期且地址尚未切换 |
| 红 | 账户被冻结或要求补充材料未提交 |

**输出规范**：每个通道必须输出"层级 + 触发该层级的具体条件 + 不满足的条件列表（如有）"，例如：

> 通道 1 (Revolut)：**黄**
> 满足：地址有效、IP 一致、账户活跃、SoF 合规
> 不满足：居留卡已过期（2027-01-12）
> 激活动作：通道迁移建议、新增海外资金 5 万美元额度检查、卫星仓美股"持有不加仓"

## 七、投资原则

以下五条是设计 Skill 时的指导原则，**不是不可违反的宪法**——任何具体数字（仓位比例、上限阈值）都允许在事实变化时被讨论与调整。原则本身稳定，数字是参考。

1. **以 1–7 年为主要观察期，主目标周期 6 年但需面对现实约束。** 不追求"二三十年都不亏"的过长时间线；个股/基金合理持有期 1–7 年；允许少量短期交易但严格限定在战术仓内。
2. **复利的敌人是回撤，不是低收益。** 核心仓首要任务是避免毁灭性回撤。
3. **能力圈承认两层含义。** Wenbo 对 AI/计算机/半导体的技术理解 ≠ 在 NVDA/ASML/TSM 这些股票上的投资认知优势。能力圈应当用于"收缩研究范围"，**不应当**用于"扩张主动持仓权重"。
4. **长期趋势与短期二手叙事分开看。**
   - AI、半导体、芯片这类十年级别的产业趋势：持有"持续上升、中间有波折"的长期判断，可作为长期持有 ETF 的方向性依据
   - 短期交易：能拿到的新闻、研报、热门话题几乎必然是二手或更晚信息，短期交易的预期收益必须用"信息已落后"作为基本假设
   - 机器人作为独立主题，目前存在泡沫迹象，**不享受 AI/半导体那种长期上升判断的待遇**
5. **纪律高于判断，但纪律要为现实让路。** 当账户规模小到交易摩擦显著高于再平衡价值时，规则必须让位（见第七节交易成本过滤）。

## 八、投资目标与时间观

### 8.1 Wenbo 的主目标

- 6 年内（30 岁前，约 2032 年）实现初步财务自由
- 不是完全财富自由，但要有显著的被动现金流或资产体量改变生活弹性

### 8.2 Skill 必须主动提出的现实性反思

- 第十一节披露的总可投资产体量作为起点，6 年达到"显著改变生活弹性的被动现金流"，所需年化收益率超出金融常识允许的范围
- 唯一现实路径：**核心增量来自工资的持续投入与储蓄率**，而不是来自"找到对的股票"
- Skill 第一次运行时主动询问：预期年薪与储蓄率（保守/中性/乐观三档）+ 是否愿意把"初步财务自由"重新定义为可量化目标
- 若 Wenbo 拒绝重新定义，Skill **记录该选择并周期性提醒**，但不主动放宽风险偏好去够这个目标

### 8.3 持有期与交易容许度

- 个股/基金默认持有期：1–7 年
- 要求 1–2 年内能看到明显的盈利兑现路径
- 短期交易：允许，严格限定在战术仓
- 绝对不做：高杠杆、衍生品做空、单标的全仓押注、加密资产超配

## 九、配置框架

### 9.1 目标权重

| 仓位     | 目标权重 | 角色                                       |
| -------- | -------- | ------------------------------------------ |
| 核心仓   | 80%      | 抗回撤、跟全球市场、复利底盘               |
| 卫星仓   | 10%      | 能力圈内主动持仓——严格承认无持续 alpha     |
| 战术仓   | 5%       | 短期机会性交易，硬上限封顶                 |
| 现金缓冲 | 5%       | 再平衡补仓、心理弹性                       |

这个 80/10/5/5 是**参考起点**，不是宪法。任何数字在事实变化时都允许重新讨论，但不预留"未来可上调"路径。

### 9.2 核心仓内部结构（修复 P2B 卡点 3：与 9.5 对齐）

| 板块                 | 目标占核心仓 | 占总仓位 | 工具示例                  |
| -------------------- | ------------ | -------- | ------------------------- |
| 全球发达市场宽基     | 40%          | 32%      | 标普 500 / MSCI 世界 ETF  |
| A 股宽基             | 25%          | 20%      | 沪深 300 / A500 / 中证全指 |
| 新兴市场（除 A 股）  | 5%           | 4%       | MSCI 新兴市场 ETF         |
| 全球科技宽基         | 15%          | 12%      | 纳斯达克 100              |
| 债券 / 类债          | 10%          | 8%       | 短久期国债 / 货基         |
| 黄金                 | 5%           | 4%       | 黄金 ETF                  |
| **合计**             | **100%**     | **80%**  |                           |

核心仓**不装行业 ETF**（半导体、芯片、新能源、光伏、绿电、AI 主题等）。这些归到卫星仓并适用卫星仓的硬上限。

### 9.3 卫星仓边界（10% 总仓位）

集中在 AI、半导体、计算机、通信、自动化。**机器人因泡沫风险，单独限制不超过卫星仓 15%（即总仓位 1.5%）**。

- 单一行业（跨市场加总）不超过卫星仓 50%（即总仓位 5%）
- 单一个股不超过卫星仓 30%（即总仓位 3%）
- 个股仓位合计不超过卫星仓 60%，其余通过行业 ETF
- 加密资产归入卫星仓，硬上限 3% 总仓位，仅持 BTC 与 ETH

### 9.4 战术仓规则

- 仓位 5%，独立账户或独立标签
- 每笔交易须有明确的进出场计划（目标收益、止损位）
- 单笔最大亏损不超过战术仓的 30%（即总仓位 1.5%）
- **战术仓亏损不允许从核心仓或卫星仓挪钱补充**
- **战术仓盈利不允许扩张沙盒规模**；累计盈利超过初始本金的 50% 时，强制将盈利部分转入核心仓
- "一笔"的定义：从首次买入某标的到完全清仓该标的，视为一笔；期间加仓减仓不重置计数；换标的开新一笔
- 连续 3 笔亏损后强制冷静期 30 天
- 不预留未来上调路径

### 9.5 A 股 / 美股双市场协调（修复 P2B 卡点 3：与 9.2 数字一致）

- **核心仓内市场分布**（精确数字见 9.2 表格）：
  - A 股股票：占核心仓 25%
  - 美股及全球股票（含发达市场宽基 + 全球科技宽基 + 新兴市场）：占核心仓 60%
  - 债+金（不属于股票市场分布）：占核心仓 15%
- **卫星仓**：优先美股；A 股卫星仓承担"中国本土科技产业链 / 国产替代"叙事，权重小于美股卫星仓
- 货币本身是配置：回国后人民币收入成为主体，持有美元资产是对未来收入币种的合理对冲

## 十、风险预算与再平衡纪律

### 10.1 风险预算

- 组合最大可接受年化波动：15–18%
- 单次回撤超过 -30% 触发"压力检查"流程
- 任何单一行业（跨市场加总）不超过总仓位 15%
- 任何单一标的不超过总仓位 8%（卫星仓内更严格，见 9.3）

### 10.2 再平衡（双触发 + 偏离基准明确 + 交易成本过滤）

**偏离基准定义（修复 P2B 卡点 4）：**

- "偏离 X 个百分点"始终指"**当前实际权重**与"**目标权重**"之间的差值的绝对值"
- 计算公式：`偏离 = |当前权重% − 目标权重%|`
- 举例：核心仓内"全球发达市场宽基"目标权重 32%（总仓位），若当前实际权重为 38%，则偏离 = |38% − 32%| = 6 个百分点

**触发规则：**

- **时间触发**：每半年一次，对照目标权重检查
- **阈值触发**：单一仓位偏离 ±10 个百分点立即触发

**再平衡执行目标（修复 P2B 卡点 4：明确"边缘"指什么）：**

- 默认执行目标：把仓位调回到"目标权重 ±5 个百分点的区间内"——即不要求精确调到目标，调到最近的区间边缘即可（例如目标 32%、当前 38%，调到 37%（即 32% + 5%）即停止）
- 这样既减少摩擦成本，又不让仓位长期处于阈值临界状态

**交易成本过滤：**

- 估算本次再平衡的全部摩擦成本（点差 + 换汇差 + 申赎费 + 税费）
- 若摩擦成本 > 被调整仓位价值的 1.5%，再平衡只执行"必要部分"（仅调到偏离 ±5 边缘）
- 若摩擦成本 > 被调整仓位价值的 3%，本次跳过；等下次新资金流入做"软再平衡"
- 新资金优先用于再平衡（最低成本方式）
- 方向反人性：涨得多的减、跌得多的加；Skill 必须明确指出情绪化倾向

### 10.3 账户规模现实约束

- 某账户总值 < 1000 美元时，账户内再平衡建议默认转为"等下次入金时调整"
- 每次再平衡建议前，必须算出"摩擦成本 / 被调整金额"比值并展示

### 10.4 新闻冷静期

任何基于 24 小时内新闻的仓位变动建议，必须先经过 7 天观察期。

## 十三、标的推荐输出规范（明确保留的功能）

**功能定位说明**：标的推荐不是 Skill 的核心卖点，但是**明确保留的功能**——当 Wenbo 问"我现在 5000 元该买什么"时，Skill 必须能给出具体答案，而不是只输出风控原则。

### 13.1 每次推荐前必须输出的诚实声明

> 以下推荐由 LLM 基于本 Skill 的框架生成。本框架**没有 alpha 来源**——它不跑 DCF、不接 sell-side 一致预期、不做财报建模。推荐本质是"在符合配置框架与硬约束的几个候选里挑一个"，请将其视为另一个版本的拍脑袋，而不是经过专业研究的建议。决策权与责任在 Wenbo。

### 13.2 推荐输出结构

每一次推荐必须包含：

1. 推荐标的：代码 + 名称 + 所在市场 + 拟买入金额或权重
2. 归属仓位：核心仓 / 卫星仓 / 战术仓
3. 规则对应：服务于哪条配置目标或再平衡触发
4. 简短理由：一两句话（明确标注"此理由非财务建模产出"）
5. 交易成本预估：本次操作摩擦占被调整金额的百分比
6. 风险提示：可能的下行情景与重审触发条件
7. 持有期预期：建议持有时间

卖出建议同结构，额外标注"原本归属仓位 + 退出理由 + 资金去向 + 税务/赎回费影响"。

## 十七、Skill 的核心承诺与诚实声明

**这个 Skill 真正能做到的：**

- 在每次对话中强制走一遍约束检查与交易成本评估，避免破纪律的冲动操作
- 把时间敏感事实从叙事中剥离，让 Skill 文件本身不需要持续维护
- 对短期新闻、二手叙事、事后合理化、能力圈过度扩张这些常见心理陷阱设置硬性防线
- 在 Wenbo 想破坏纪律时把规则甩回到他脸上
- 通过参数化的 `life_stage` 与跨境通道矩阵，让回国后的资产迁移路径不至于在到期日那天才发现
- **当 Wenbo 提供最新持仓并明确询问"我该买什么"时，给出具体的标的、金额与仓位归属**——这是保留的可用性功能，不是因为它不是核心就被取消

**这个 Skill 不假装能做到的：**

- 不假装能持续战胜市场
- 不假装具体标的推荐有 alpha
- 不假装能用一份文件兜底所有 AI 模型的差异
- 不假装新闻驱动的短期信号对零售可执行
- 不假装 Wenbo 的技术专业等同于股票投资优势
- 不假装 6 年内能从当前起点靠投资实现初步财务自由——这件事的现实路径是工资收入与储蓄率

**这份 Skill 在本质上是：** 一个为 Wenbo 量身定做的、能让他更不容易做出愚蠢决策的防呆引擎，同时保留"问什么答什么"的具体推荐能力作为可用性功能。理解并接受这个定位，是正确使用本 Skill 的前提。
