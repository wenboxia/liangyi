**文档基线**：r2-idea-v5（已锁定）+ PRD v1.0 + PRD-2
**文档目的**：基于 P3.1.2 用户反馈对 PRD-2 的轻度调音 + 1 处反向回拉 + 产品命名落地
**版本**：PRD v3.0

**与 PRD-2 的关系**：本文档延续 PRD-2 的所有修改，再做 8 条 fine-tuning 调整 + 1 处反向回拉（PRD-2 把"双峰用户"概念藏得过头了，PRD-3 显式恢复"两种入口"的灵活性但不分类用户）+ 完成产品命名（中文 **未镜** / 英文 **The Other Path**）。

## 0. 产品命名说明

**中文名：未镜**——"尚未照见之镜"。"未"指那条还没走、但已经在你身上准备发生的路；"镜"指映照（呼应产品里的开场镜子、原型镜鉴、反思式塔罗的本质）。

**英文名：The Other Path**——直接对应产品的中文钩子"你纠结的每个决定背后，都有一条没走的路"。在英文文化里与 Robert Frost 的《The Road Not Taken》有自然共振——反思、岔路、生命选择。

**为什么中英异名**：未镜在中文里诗意、有"镜"的产品根、有"未"的钩子张力；The Other Path 在英文里自然、不撞 fortune-telling 标签、不暗示"预测"。两个名字各自在自己的语言里立住，品牌灵魂（看见你没走的路 / 镜照内心）是同一个。这是日韩出海品牌的标准姿势（资生堂 SHISEIDO、无印 MUJI）——硬翻往往两败俱伤，异名让两种语言各自承载产品灵魂的不同侧面。

**关于"未"暗示预测的风险纪律**：必须在产品文案 / FAQ / onboarding 里明确——

> "**未镜不是预言之镜。我们映照的是你心里那条还没走、但已经在你身上准备发生的路——不是 AI 算出来的未来。**"

把"未"重新框定为"用户内心已有的、尚未付诸行动的可能性"，而不是"AI 算出来的未来"。这是 voice 上的硬纪律，与 §5.3 反思式塔罗"主语永远是用户"的纪律同源。

## 1. 产品概述

### 1.1 一句话定义

**产品宣告**（保留 r2-v5 钩子）：

> 你纠结的每个决定背后，都有一条没走的路。未镜帮你看见那条路上的你——三个月后在做什么、三年后在哪里、五年后成了什么样的人。

**"看见"的精确含义**：路径的形态、你的成长课题、短期 0–6 个月会经历的具体瞬间、中期 1–3 年的概率带情景。**不是 2031 年 7 月你具体遇到谁**——产品在长期段只给故事核 + 方差形状。

**对外口语化定位**（给用户面对朋友时的语言工具，落地页 + FAQ + 注册页都用这版）：

> "如果你要用一句话告诉朋友这是什么，可以说：'它陪我把心里那些想了好久没结论的事，慢慢理一遍——不替我做决定，但帮我看清我在选什么。'"

**如果朋友进一步问"那不就是写日记 + 自己分析吗"**——给用户一段可以接得上的话：

> "差别在它会让我看见我自己没意识到的偏差——比如我说'比较可能'，它会问'是不是因为你刚听了一个朋友的故事'。让我自己点头或反对。最后做决定的还是我，但做这个决定时，我自己心里清楚多了。"

这段补在 §1.1 与 FAQ，给用户对抗"和写日记没区别"的具体说服素材。

### 1.2 核心价值主张

未镜服务于"想了两周还没决定"和"已经倾向某个选项但想再认真挑战一次"两类心理状态。

它的核心价值是：

1. **陪用户慢慢把纠结结构化**——AI 不替用户拍板，用户自己认领可能性、自己点头或驳回偏差审计、自己写 Pre-mortem。用户走完一次推演不是因为 AI 算给他听，而是因为他自己想清楚了。
2. **用心理学原型语言为路径命名 + 大白话翻译**——让结构化推演的结论在情感层面被用户接住，每条原型描述都配一行大白话同义补充（说"具体要面对的事"，不说"你会有什么感受"）。
3. **可选的开场反思入口**——为想用图像作触发的用户提供 reflective tarot 作为投射 prompt（用户可选系统抽牌或自己选牌），主语永远是用户，不预言。

### 1.3 目标用户精确画像

**主要覆盖：大陆背景中文用户（全球分布，共享同一套决策语言与文化参照）**

| 子群体 | 物理位置 | 触达通道 | 付费方式 |
|---|---|---|---|
| 大陆境内 VPN 用户 | 中国大陆 | 小红书 / 微信公众号转载 / 即刻 | 国际信用卡 / 支付宝海外版 / 微信支付国际版 |
| 海外留学 / 工作 / 移民华人 | 北美 / 欧洲 / 澳新 / 东南亚 | 即刻 / 小宇宙 / 海外华人社群 | Stripe / Paddle / 信用卡 |
| 港澳台用户 | 港澳台 | 被动覆盖,前期不主推 | Stripe / 信用卡 |

**画像特征（设计假设，需首批 50 用户深访验证）**：

- 28–38 岁城市白领，本科及以上教育；
- 在心理咨询、灵修工作坊、MBTI、塔罗上有过付费经历，对"被看见"有支付意愿；
- 正面对人生级节点：转型、婚恋、生育、迁移、创业；
- 对纯理性方法已经感到疲惫——做过 SWOT、列过优劣表，发现还是决定不了。

**补充覆盖**：海外华裔中文流利者、ABCs（通过英文版本）、对 Jungian / 东方哲学有兴趣的英语用户。

**明确不主推**：纯西方非华裔英语用户。

> **PRD 内部说明（不进入用户面）**：产品是为"双峰用户结构"设计的——理性派用户跳过镜子层、由结构层做主；反思派用户启用镜子层。这个分类是产品内部模型，**不在落地页 / onboarding / Marketing 文案中以"双峰"或"理性 vs 灵性"形式暴露**。但产品**要显式让用户看到"两种入口都为他敞开"**——不分类用户，但灵活性可见。详见 §3.7 + §4.2.1 onboarding 文案。

#### 3.2.2 AI 重构机制

#### 3.2.3 心理状态识别 + 单一推荐(PRD-3 加确认 + 我猜文案)

**当前 PRD-2 流程**:用户输入决策 → AI 心理状态识别 → 直接进入推荐档。

**PRD-3 改为**:用户输入决策 → AI 重构 → **1 行确认**:

> "听起来你还在反复琢磨,对吗?"
> [是的] [其实我已经有点倾向某个选项了]

用户点[是的] → 推荐完整推演;
用户点[其实有点倾向] → 推荐轻推演。

**推荐文案语气**(从 PRD-2 的"推荐你试试 X"改为"我猜你现在适合 X——也可以试试别的"):

> "我猜你现在适合**完整推演**(30-40 分钟)——慢慢把可能性都摊开来看。
> [开始] [试试更轻的] [先简单看看]"

"我猜"是 AI 的猜测姿态,不是判定姿态——降低用户"被误判"的烦躁。

### 3.5 多路径人生模拟模块

#### 3.5.1 颗粒度梯度(三时间尺度)

(与 PRD-2 §3.5.1 相同)

#### 3.5.2 输出页顺序重排(PRD-3 关键改动)

**PRD-2 输出页顺序**:多路径画像(原型层在前)→ 三个具体瞬间(短期)→ 概率带(中期)→ 故事核(长期)→ 对比表 → 倾向性结论。

**PRD-3 改为**:
1. **三个具体瞬间(短期)**——视觉重点,放在第一屏;
2. 概率带(中期);
3. **原型层 + 大白话翻译**——作为"如果你想要一个故事核来理解这条路"的**可折叠层,默认折叠**;
4. 长期故事核(原型层展开后才看到);
5. 对比表;
6. 倾向性结论;
7. **"未决定也可以"承接**(新增,详见 3.5.4)。

这个顺序改动回应用户反馈"我真正在意的不是这条路叫什么原型,而是选这条路接下来要面对什么具体困难"。

#### 3.5.3 原型大白话翻译措辞调整(PRD-3 关键改动)

| 原型 | PRD-2 版本(感受导向) | PRD-3 版本(具体面对的事) |
|---|---|---|
| 探索者的远行 | "接下来你会成为一个学习者,主要的**感受**是兴奋 + 孤独 + 现实压力的拉扯" | "接下来你会成为一个学习者,主要要面对的**事**是:从零搭建专业认同 / 处理身份不确定的孤独 / 应对收入断崖的现实压力" |
| 照顾者的深耕 | "接下来你会承担更多责任,生活节奏稳但累。主要的**感受**是被需要 + 偶尔的疲惫 + 长期看会获得别人难以替代的位置" | "接下来你会承担更多责任,主要要面对的**事**是:在体系内积累但放弃外部探索 / 处理日常被需要时的疲惫 / 长期建立别人难以替代的位置感" |

把"感受是 X+Y+Z"改为"要面对的事是 X+Y+Z"——这是用户明确诉求("我想知道具体要面对什么,不是我会有什么感受")。

工程实施时建立完整原型对照表(覆盖 8-12 个常用原型)。

#### 3.5.4 "未决定也可以"承接(PRD-3 新增)

在倾向性结论之后,加一段:

> **如果你看完仍然没倾向某个选项,那也没关系**——纠结本身在告诉你这件事的赌注真的不小。把推演留在思考流里,过几天再回来,有新想法可以用[快速捕捉]补一段。**未决定本身也是一种状态,不是失败。**

这一段不动 idea 层的核心机制(产品仍然给倾向性结论),但**为"未决定"这个用户状态在产品里留位置**——回应用户反馈中的"产品可以陪我理一遍,但如果理完我还是没决定,它能不能说一句'没关系,纠结本身也是有意义的'"。

### 9.13 用户预期与产品 voice 错位(PRD-3 升级监测条件)

**风险描述**:即使产品机制是用户参与,如果文案语气过于"指引",用户体验仍会是"被要求"。两轮用户反馈累积显示这是真实信号——voice 调音可以缓解,但不能完全消解。

**对策**(PRD-3 升级):
- PRD-3 全文档已做 voice 进一步调音(Step 4/6 改为"我陪你想/我等你");
- 首批 50 用户深访必问以下三个问题(任一 ≥ 30% 答负面 → 回流 P2):
  1. "产品让你感觉是被陪着想,还是被推着想?"
  2. "**如果你推演完仍未决定,产品让你感觉这是失败还是正常状态?**"(PRD-3 新增)
  3. "你会推荐给朋友吗?"

第 2 个问题直接验证 idea 层 gap("被允许混乱 / 未决定也可以"诉求是否在产品里得到承接)。如果 30%+ 答"感觉是失败",§3.5.4 的"未决定也可以"承接还需要更强的产品级落地——可能需要 idea 层重审"必出倾向性结论"的纪律。

## 综合判断说明

### 关于 PRD-3 是 PRD-2 的轻度调音 + 1 处反向回拉 + 命名落地

PRD-3 不动 idea(r2-v5 已锁),不动产品的核心机制。PRD-3 改的是:

1. **产品命名落地**:中文 **未镜** / 英文 **The Other Path**;加"未"字预言暗示的文案纪律;
2. **§1.1 加"和写日记的区别"explainer**——给用户对抗"那不就是写日记"的具体说服素材;
3. **§3.2.3 推荐前加 1 行确认 + "我猜"语气**——降低"被误判"焦虑;
4. **§3.4.2 Step 4/6 文案进一步软化**——"只能你来"换成"我陪你想 / 我等你";
5. **§3.5 输出顺序重排 + 原型大白话改"具体面对的事"**——回应用户"想要具体困难,不要感受标签";
6. **§3.5.4 加"未决定也可以"承接**——为"被允许混乱"的诉求在产品里留位置;
7. **§3.7 + onboarding 显式恢复"两种入口"灵活性**(反向回拉)——PRD-2 把"双峰"藏过头了,PRD-3 让"两种入口"可见但不分类用户;
8. **§6.3 加"愿意收到匿名故事"勾选**——v6+ 实施的入口列表收集;
9. **§9.13 升级深访问题**——加"未决定让你感觉是失败还是正常状态"作为 idea 层 gap 第二验证问题;
10. **§9.15 加"未字纪律"风险监测**;
11. **§10 加"非塔罗触发图"作为 v6+ 候选**——记录用户的扩展需求但不实施。

### Qwen-2 信号(P3.1.2 用户反馈进一步验证)

PRD-2 加"对外口语化定位"作为补桥的尝试,在 P3.1.2 用户反馈中**确认有效**——用户读到这句话愣了一下,说"这就是我心里想说但之前没组织好的话"。但**桥还没完全搭通**——朋友可能仍会问"那不就是写日记+自己分析吗",用户能不能 answer 仍是问题。PRD-3 的 §1.1"和写日记的区别"explainer 是补这个 gap 的下一层尝试;首批 50 用户深访仍需验证。

### 诚实标注:idea 层潜在 gap 的演进

P3.1.2 反馈把 idea 层 gap 进一步具体化:

- PRD v1.0 后:用户表达"被允许选错、反复、不知道想要什么";
- PRD-2 后:用户进一步表达"未决定也可以是合法状态——产品没给这个状态留位置";

**PRD-3 的 §3.5.4"未决定也可以"承接是 PRD 范围内最合理的回应**——为"未决定"在产品输出里留位置,不动 idea 层"必出倾向性结论"的纪律。

但这只是文案级的承接,不是机制级的。如果首批 50 用户深访中超过 30% 答"推演完没决定觉得是失败",这是 idea 层信号——需要 Wenbo 决策是否回流 P2 重审"必出倾向性结论"是否需要软化为"如果有充分判据,给倾向性结论;如果没有,明确说我们也无法定夺"。

**本 PRD 范围内不能解决这个 gap;只能标注、监测**。

### 关于"未"字命名的潜在风险

中文产品名"未镜"自带"未来 / 预测"暗示,与产品"不预言"的核心纪律有张力。PRD-3 通过三层文案纪律压制这个张力:

1. 落地页 Hero 之后的"未镜不是预言之镜"声明;
2. FAQ 第一条必须是"未镜会预测我的未来吗?";
3. 所有 Marketing 文案禁用"算出 / 预测 / 推算 / 命运"。

但纪律最终能不能落地,取决于内部团队的 voice 一致性。**这是 PRD 写下纪律,但执行依赖团队**——纪律本身是产品质量的一道护栏,做不好用户会立刻把"未镜"误读为"AI 算命"。

英文名"The Other Path"没有这个张力——是 PRD-3 选异名而非直译的核心理由之一。
