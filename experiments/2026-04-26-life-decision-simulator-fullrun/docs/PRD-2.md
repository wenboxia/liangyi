# 明决（Clear Choice）· 产品需求文档 PRD-2

**文档基线**：r2-idea-v5（已锁定）+ PRD v1.0
**文档目的**：基于 P3.1.1 用户反馈对 PRD v1.0 的中度调音
**版本**：PRD v2.0

**与 PRD v1.0 的关系**：本文档不动 idea，不动产品的核心机制，调整的是文档语言、UX 流程、付费摩擦、回访设计、问卷题面包装——把整体 voice 从"很聪明的工具"调到"陪你慢慢想的伙伴"。

---

## 1. 产品概述

### 1.1 一句话定义

**产品宣告**（保留 r2-v5 钩子）：

> 你纠结的每个决定背后，都有一条没走的路。明决帮你看见那条路上的你——三个月后在做什么、三年后在哪里、五年后成了什么样的人。

**"看见"的精确含义**：路径的形态、你的成长课题、短期 0–6 个月会经历的具体瞬间、中期 1–3 年的概率带情景。**不是 2031 年 7 月你具体遇到谁**——产品在长期段只给故事核 + 方差形状。

**对外口语化定位**（给用户面对朋友时的语言工具，落地页 + FAQ + 注册页都用这版）：

> "如果你要用一句话告诉朋友这是什么，可以说：'它陪我把心里那些想了好久没结论的事，慢慢理一遍——不替我做决定，但帮我看清我在选什么。'"

这一版替代用户脑里浮现的"AI 决策推演工具"——后者是机制描述，听起来和 ChatGPT 没区别；前者是体验描述，让朋友能听懂"和 ChatGPT 不一样的地方"。

### 1.2 核心价值主张

明决服务于"想了两周还没决定"和"已经倾向某个选项但想再认真挑战一次"两类心理状态。

它的核心价值是：

1. **陪用户慢慢把纠结结构化**——AI 不替用户拍板，用户自己认领可能性、自己点头或驳回偏差审计、自己写 Pre-mortem。用户走完一次推演不是因为 AI 算给他听，而是因为他自己想清楚了。
2. **用心理学原型语言为路径命名 + 大白话翻译**——让结构化推演的结论在情感层面被用户接住，每条原型描述都配一行大白话同义补充。
3. **可选的开场反思入口**——为想用图像作触发的用户提供 reflective tarot 作为投射 prompt（用户可选系统抽牌或自己选牌），主语永远是用户，不预言。

### 1.3 目标用户精确画像

**主要覆盖：大陆背景中文用户（全球分布，共享同一套决策语言与文化参照）**

| 子群体 | 物理位置 | 触达通道 | 付费方式 |
|---|---|---|---|
| 大陆境内 VPN 用户 | 中国大陆 | 小红书 / 微信公众号转载 / 即刻 | 国际信用卡 / 支付宝海外版 / 微信支付国际版 |
| 海外留学 / 工作 / 移民华人 | 北美 / 欧洲 / 澳新 / 东南亚 | 即刻 / 小宇宙 / 海外华人社群 | Stripe / Paddle / 信用卡 |
| 港澳台用户 | 港澳台 | 被动覆盖,前期不主推 | Stripe / 信用卡 |

**画像特征（设计假设，需首批 50 用户深访验证）**：

- 28–38 岁城市白领，本科及以上教育；
- 在心理咨询、灵修工作坊、MBTI、塔罗上有过付费经历，对"被看见"有支付意愿；
- 正面对人生级节点：转型、婚恋、生育、迁移、创业；
- 对纯理性方法已经感到疲惫——做过 SWOT、列过优劣表，发现还是决定不了。

**补充覆盖**：海外华裔中文流利者、ABCs（通过英文版本）、对 Jungian / 东方哲学有兴趣的英语用户。

**明确不主推**：纯西方非华裔英语用户。

> **PRD 内部说明（不进入用户面）**：产品是为"双峰用户结构"设计的——理性派用户跳过镜子层、由结构层做主；反思派用户启用镜子层。这个分类是产品内部模型，**不在落地页 / onboarding / Marketing 文案中以"双峰"或"理性 vs 灵性"形式暴露**。用户不会被告知他属于"哪一峰"——他只看到产品提供"两种入口"，自己选。

## 3. 核心功能模块

### 3.1 "Create Yourself" 入会问卷模块

#### 3.1.1 重新命名与 voice

模块对外名称从"自我画像问卷"改为 **"先认识一下你"** ——避免"问卷"二字带来的"做题感"。

题目之间加柔和过渡语:"再问一件事——" / "另一个想了解的——",不是冷冰冰的列表。

#### 3.1.2 首次问卷(4 分钟,9 题)

**采集维度与题目方向**:

| 维度 | 题量 | 题目方向 | 用途 |
|---|---|---|---|
| 处境锚点 | 5 题 | 年龄 / 城市 / 职业 / 婚育 / 家庭经济缓冲 | 路径模拟硬约束 |
| 价值张力 | 4 题 forced-choice | 自由 vs 稳定 等 | 效用函数 |

**显式不采集**:出生年月时、生辰八字、星盘、紫微命盘、主导原型识别。

#### 3.1.3 深化问卷(6 分钟,在第一次推演完成后或第三天 push 唤回)

**关键 UX 改进**:风险态度题与偏差测试题**全部生活化包装**,不出现 textbook 题面。

| 维度 | 原题 (textbook 版) | 改版 (生活化版) |
|---|---|---|
| 风险态度 | "确定 50 万 vs 50% 概率拿 120 万" | "假设两个选择——A:现在拿 50 万奖金;B:抛硬币,正面 120 万、反面什么都没有。**直觉**选哪个?" |
| 时间贴现 | "现在 1000 vs 一年后 1500" | "公司发 1000 元年终奖。可以现在拿,也可以等一年拿 1500。你会怎么选?" |
| 锚定偏差 | base rate neglect 数值题 | 包装为生活情境(朋友买股票的故事 → 你的判断) |

题目语气一律是"想了解你的直觉",不是"测试你的判断"。

### 3.2 决策输入模块

#### 3.2.1 输入界面

主入口:一个文本框,placeholder 文案改为更柔和:"想到什么写什么——把你最近反复琢磨的那件事先告诉我。"

不强制冥想动作。不要求结构化输入。

#### 3.2.2 AI 重构机制

用户输入后,AI 做两件事:

1. **决策类型识别**(后台);
2. **二元 → 探索式重构**(对用户可见,以柔和方式呈现):
   > "我想我听到的是——你在权衡:[改写后的探索式提问]。这样理解对吗?"
   > [是的,继续] / [让我改改]

#### 3.2.3 心理状态识别 + 单一推荐(关键 UX 改动)

AI 根据用户输入语气与措辞,识别用户处于:

- **真酝酿期** → 推荐**完整推演**;
- **事后压力测试** → 推荐**轻推演**;
- **未识别** / 不确定 → 默认推荐基础推演,文案:"先简单看看吧,5 分钟"。

**用户进入推演选择页时,默认是 AI 推荐的那一档**——不显示三档并列。其他两档以小字 link 提供:

```
推荐:[完整推演 30-40 分钟]
也可以:[更轻的版本 10-15 分钟] · [先简单看看 5 分钟]
```

这是从"让用户在三档之间选"改为"AI 帮用户选,用户可改"。

### 3.3 开场镜子模块(可选,30 秒)

#### 3.3.1 用户体验流程

1. 用户在推演前选择 [抽一张塔罗作为反思的起点] / [跳过,直接进入分析];
2. 选抽牌后,用户**二选一**:
   - **[让系统抽一张]** —— 22 张随机
   - **[让我自己选一张]** —— 展示 22 张大阿尔卡纳缩略图,用户点选
3. 展示牌面图像 + 3-5 个传统象征词 + 微小说明文字:"**——这些是参考,不是答案。任何牌都不暗示任何结局。牌只是一张图——你看到这张图想到什么,那是你心里已经有的话,跟牌面无关。**"
4. 关键 prompt:"这张牌的画面让你想到什么?它和你正在纠结的这件事,有什么连接你还没说出口的吗?"
5. 用户自由作答 1-3 句;
6. AI 凝练为"你的开场镜子"草案;
7. 用户三选一:[确认] / [调整] / [移除]。

### 3.5 多路径人生模拟模块

#### 3.5.1 颗粒度梯度(三时间尺度)

| 时间尺度 | 颗粒度 | 输出内容 | 关键改动 |
|---|---|---|---|
| 短期(0-6 个月) | 高 | **三个具体瞬间** | **从"具体行为/情绪/挑战列表"改为三个具象、有时间锚点、第二人称的场景描述** |
| 中期(1-3 年) | 中 | 结构性变化 + 概率带(基线 / 上行 / 下行) | 不变 |
| 长期(5+ 年) | 低 | 原型故事核 + 方差形状 | 不变 |

**短期"三个具体瞬间"格式样例**(取代原列表式输出):

```
接下来 1-3 个月,你大概率会经历的三个具体瞬间——

瞬间 1 · 第 4 周左右
你会在某个深夜怀疑"是不是错了"。这是从体系外做学习者必经的一段。
不需要做什么,知道这是路径自身的形状就好。

瞬间 2 · 第 8-10 周
会有一个朋友对你的选择表达不理解,你会有一次解释 / 自我怀疑的内耗。
关键不是说服对方,是观察自己解释时的语气——里面藏着你真实的信心程度。

瞬间 3 · 第 12 周左右
会出现第一个让你感到"确实跟以前不一样了"的小信号。
可能是一个客户、一个见解、一次小成就。这是路径开始变实的时刻。
```

这种格式比抽象的"具体行为 / 情绪 / 关系变化"列表更能让用户预演,也更回应用户反馈中的"我需要大白话"。

## 综合判断说明

### 关于 PRD-2 是 PRD v1.0 的中度调音,不是结构性重写

PRD-2 不动 idea(r2-v5 已锁),不动产品的核心机制(六步流水线、双层叙事、开场镜子三选一、Barnum 护栏)。PRD-2 改的是:

1. **文档语言 voice**——从"很聪明的工具"调到"陪你慢慢想的伙伴";
2. **UX 流程**——AI 心理状态识别后的单一推荐替代三档并列选择;
3. **付费摩擦**——同决策 24 小时免重支付 + 决策包 ¥19.9;
4. **回访设计**——4 题 + 自由文本 → 2 题 + 表情 + 匿名聚合反馈;
5. **问卷题面**——textbook 题改为生活化包装;
6. **输出呈现**——短期段从"具体行为列表"改为"三个具体瞬间"+ 原型层加大白话翻译;
7. **加桥**——§1.1 加"对外口语化定位",补钩子和机制描述之间的桥;
8. **不暴露内部模型**——"双峰用户"概念从用户面消失,只保留在 PRD 内部说明;
9. **开场镜子**——加用户自己选牌选项 + "牌只是参考不是答案"教育文案。

### Qwen-2 信号(P3.1.1 用户反馈验证)

真实用户在场景测试中确认了 r2-v5 综合判断标注的"钩子比机制略 overpromise"——她头脑里浮现的口语版本是"AI 决策推演工具",不是"看见你没走的那条路"。她说不出与 ChatGPT 的区别。

**这不是钩子失败**(她仍然会点[开始你的第一次推演]),**是钩子和机制描述之间缺一座桥**。PRD-2 通过加"对外口语化定位"补这座桥,但首批 50 用户深访必问:"如果让你用一句话告诉朋友这是什么,你会怎么说?"——如果普遍答"AI 决策助手",钩子需要降温;如果出现接近"陪我把心里的事理一遍"的口语化版本,桥搭通了。

### 诚实标注:idea 层潜在 gap

P3.1.1 用户反馈中表达的**"想要被允许选错、反复、不知道想要什么"**诉求,与产品 idea 层的"结构化推演 + 用户必填 Step 4 / Step 6"存在潜在张力。

idea 层的"必填"是产品的核心认知干预动作(详见 r2-v5 §6),不是 PRD 可调整的。PRD-2 在文案 voice 上做了软化:
- "你必须填"改为"这一步只能你来——慢慢想";
- "强制"概念从用户面消失,但功能纪律保留;
- 增加"想停就停,不想填的可以跳过"等容错文案。

**但这不能完全消解 idea 层的 gap**:产品的核心价值就是"用户被迫认领可能性、被迫面对自己的不确定性",这条认知干预是 idea 层的产品宣言。

**本 PRD 范围内不能解决这个 gap;只能标注、监测**:

- 首批 50 用户深访必问:"产品让你感觉是被陪着想,还是被推着想?"
- 若超过 30% 答"被推",这是 idea 层 gap 信号;
- **回流 P2 重审"必填"纪律是否需要软化为"强烈引导"或"建议"**——这是显性动作,需要 Wenbo 在数据出来后决策。
