# idea-v1 · 明决（Clear Choice）

## 1. 产品名

工作名：**明决**。取"明镜"之映照（让用户被看见）+ "决断"之结构（让用户看清自己在选什么）。后续可换正式名。

## 2. 一句话产品定义

明决是一款 C 端 AI 决策伴侣——把人生重大决策的结构化推演，包裹在一层原型化的象征语言里，让用户在一个被严肃对待的时刻里看清自己在赌什么。

## 3. 核心价值主张

人生决策之难，是两件事同时发生：

- 用户被认知偏差、二元锚定、情绪噪声扭曲，看不清自己真正在选什么；
- 用户的理性防御又同时筑高，让任何冷冰冰的"决策框架"在情感层面被他自己屏蔽掉。

明决的价值，是**用象征与原型的语言，让结构化决策推演真正发生**。

象征不是装饰，它是让用户愿意慢下来、愿意诚实面对自己、愿意接受推演结论的容器。结构不是装饰，它是让象征不退化成 Barnum 安慰剂的骨架。两者缺一，产品都活不下去。

我们不卖预言。我们卖的是 **"在一个被严肃对待的时刻里，看清自己面对的真实选项与赌注"**。

## 4. 目标用户

**核心人群：28–38 岁一线 / 强二线城市白领。**

更精准的画像——"读过《思考，快与慢》，也找人看过塔罗或紫微"的那批人。他们：

- 受过本科及以上教育，能看懂"期望效用""路径依赖""认知偏差"这类概念；
- 但**对纯理性方法已经感到疲惫**——他们做过 SWOT、列过优劣表，发现还是决定不了；
- 在塔罗、心理咨询、灵修工作坊、MBTI 上有过付费经历，对"被看见"的体验有支付意愿；
- 正面对人生级节点：职业转型、婚恋、生育、城市迁移、创业。

为什么不是更宽的"灵魂探寻者"：那群人付费但不黏着，对"看清"没耐心，对结构化输出会反感。
为什么不是更窄的"咨询/金融从业者"：那群人会把产品当 Excel 用，享受不到象征层带来的复利价值。

夹缝精准度比覆盖广度更重要——早期不追求大盘渗透，追求这个夹缝人群里的"疯狂喜欢"。

## 5. 核心使用流程

### 5.1 "Create Yourself" 入会问卷（约 12 分钟，可分两次完成）

四层采集，**所有字段都进入下游模型，没有装饰性问题**。

**第一层 · 处境锚点（约 2 分钟）**
年龄、城市层级、职业大类、婚育状态、健康自评、家庭经济缓冲（可承受失业月数）、当前关系/责任结构。
作用：作为路径模拟的硬约束。月光族和有 18 个月现金缓冲的人，"要不要辞职"的期望值结构完全不同。

**第二层 · 价值张力排序（约 3 分钟）**
通过 forced-choice 与卡片排序，让用户在"自由 vs 稳定""成就 vs 关系""短期愉悦 vs 长期意义""掌控 vs 自由度"等核心张力上排序。
作用：建立用户的效用函数。同一条路径对不同效用函数的人净值不同。

**第三层 · 风险与时间偏好（约 2 分钟）**
经典风险态度题（确定 50 万 vs 50% 概率拿 120 万）、时间贴现题。
作用：模拟时显式区分"客观期望值高"和"对你而言期望效用高"。

**第四层 · 原型与认知风格（约 5 分钟）**
不是星座、不是 MBTI、不是出生时辰。是一组**意象偏好题 + 情境反应题**：
- 意象题（"你此刻更觉得自己在深渊、迷宫、荒原、还是高塔上？"）映射到 Jungian 原型——揭示用户当前活在哪个故事里（英雄、孤儿、照顾者、探索者、破坏者、智者……）；
- 情境题暗藏锚定、可得性、base rate neglect 陷阱，行为式采集偏差档案（不用自评题）。

输出的不是冷冰冰的"用户画像"，而是一份 **"灵魂剧本摘要"**：
> 你现在带着"照顾者"的主导原型在生活，效用函数偏向关系胜于成就，风险偏好中性偏保守，决策时容易被锚定与可得性偏差影响。

**显式不采用的字段**：出生年月时（紫微斗数 / 星盘排盘所需）、生辰八字。理由三层：合规风险高、采集摩擦大、因果声称无法在产品价值主张里自洽。原型层的"被看见"用 Jungian 框架替代——它被主流心理学接受，可作为思考隐喻而非神秘学预言。

### 5.2 决策输入

用户带一个决策进来（"要不要离职""要不要分手""要不要回老家"……）。

入口不是输入框 + 提交按钮。是一个 **"心念注入"** 仪式：
- 让用户先深呼吸 30 秒，把决策写下来；
- AI 引导把"该不该 X"的二元提问，重构为探索式提问——"如果我选 X，我将要学习的课题是什么？我可能遇见什么样的自己？"
- 用户文字陈述的语义，被系统转写为一个**问题意象**（一段诗化的镜像描述，作为整次推演的入口画面）——这不是用来占卜的，是用来在结果页给用户一个"他自己提的问题的象征性镜像"。

### 5.3 输出形式

输出**两层叠加**，不是两份并列报告：

**外层 · 原型镜鉴（用户先看到的）**
用 Jungian 原型 + 大阿尔卡纳象征语言（不排牌阵作真预言，明确标注"这是用来思考的隐喻"），把每个选项命名为一段原型旅程：
> 选项 A 是一段"愚人之旅"——你将丢掉积累、在新地里重新做一个学习者。
> 选项 B 是一段"皇帝之路"——你将在已有秩序里继续累积权威，但要付出 X 代价。

**内层 · 结构化推演（点开"看清这条路"展开）**
每条路径对应一份结构化展开（详见第 6、7 节）——选项树、不确定性变量、概率与效用估算、偏差审计、Pre-mortem。

**关键设计纪律**：原型层的诗意叙述与结构层的概率推演**严禁互相冲突**。如果原型层说"愚人之旅"，结构层就必须显示与之一致的"高方差、上下限拉大"的路径分布形状。这是产品可信度的根基，也是最大的工程风险点。

## 6. 决策建议生成机制

走一条显式六步流水线，每一步对用户可见——这是**和通用大模型的根本区别**。

| 步骤 | 决策科学动作 | 原型层呈现 |
|---|---|---|
| 1. 决策框定 | 识别决策类型（一次性 / 可逆 / 链式）、Bezos 双向门 vs 单向门 | "命名你正站在什么样的门槛上" |
| 2. 选项树展开 | 强制 ≥3 个选项（含"延迟决定，N 个月内收集 Y 信息"路径） | "看清面前不止两条路" |
| 3. 不确定性识别 | 每个选项 3–5 个关键变量、可控/不可控分类 | "辨认风从哪里来" |
| 4. 概率与效用估算 | **用户自己填**主观概率 × 问卷效用函数 → 期望效用 | "给每条路的可能性赋一个重量" |
| 5. 偏差审计 | 对照用户偏差档案，主动指出本次推演中的偏差痕迹 | "你内在的某个角色正在替你做决定，请认出它" |
| 6. Pre-mortem | "假设 18 个月后这个选择失败了，最可能的失败原因是什么" | "拜访那个 18 个月后失败的自己" |

最终建议形态：**一份倾向性结论 + 该结论的边界条件 + 你为什么可以信它的推理链**。永远不替用户拍板"就选 A"，但也永远不和稀泥——这是工具相对于通用 GPT 的硬区别（GPT 的训练目标决定它倾向给中庸的"看你自己感受"）。

**关键纪律**：Step 4 的概率必须由用户自己填，AI 只引导不替写。这本身就是认知干预——用户自己赋的概率，是他第一次被迫直面自己的不确定性结构。

## 7. 多路径人生预测生成机制

每个选项产出一份**双层人生画像**：原型层叙事 + 结构层情景。

**纪律一：分时间尺度区分颗粒度**

- **短期（0–6 个月）**：高颗粒度。具体的行为、情绪、关系变化、典型挑战。两层都给出。
- **中期（1–3 年）**：中颗粒度。结构性变化（职业层级、家庭结构、财务状况）。两层都给出，并显式标注概率带——基线 ~50% / 上行 ~25% / 下行 ~25%。基线情景必须挂靠在"画像匹配度高的真实人群中位结局"上（参考类预测 / reference class forecasting）。
- **长期（5–10 年）**：低颗粒度。**只给原型层**——这条路径的"故事核"和方差形状（"上限更高下限更低"），不预测具体事件。

**为什么长期只给原型**：长期具体预测必然是 Barnum 或证伪自杀，是产品的死亡区。但完全不说长期，用户会觉得不过瘾。原型层在这里**正好胜任**——它不假装预测事件，它命名一类人生形态。"愚人之旅可能终于'世界'，也可能终于'月亮'"——这是诚实的、有意义的、且不可证伪也不假装可证伪的。这是综合方案的甜点，纯 A 路线给不出（它会拒绝长期预测），纯 B 路线会过度具体（它会真的预测事件）。

**纪律二：路径之间显式做对比**
不出三份独立报告，出一张对比图：每条路径在用户问卷里标注的 3–5 个最重要效用维度上的相对位置。用户一眼看出"我选 A 是在赌 X，我选 B 是在赌 Y"。

**纪律三：参考类预测是底层数据资产**
中期路径的基线情景挂靠在"画像匹配度高的真实人群结局分布"上。早期靠公开数据 + 文献元分析 + 半合成数据（并诚实标注数据来源）；中长期靠用户回访数据飞轮（见第 9 节）。

## 8. 占卜与决策科学的融合方式 / 取舍

明决的综合立场，可以一句话概括：

> **取占卜的容器，不取它的认识论；取决策科学的骨架，不取它的冷感。**

具体取舍：

| 维度 | 取自占卜命理派 | 取自决策科学派 |
|---|---|---|
| 仪式感容器（心念注入、慢节奏、视觉隐喻） | ✓ | |
| 原型语言（Jungian 原型作为思考隐喻） | ✓ | |
| 大阿尔卡纳作为路径"故事核"命名 | ✓ | |
| 入口意象（用户问题转写为镜像） | ✓ | |
| 出生时辰排盘 / 紫微斗数 / 星盘 | ✗ | |
| 占卜式确定性预言、凶吉判断 | ✗ | |
| 决策六步流水线 | | ✓ |
| 期望效用 + 用户自填概率 | | ✓ |
| 偏差档案 + 偏差审计 | | ✓ |
| 参考类预测 | | ✓ |
| Pre-mortem | | ✓ |
| 冷冰冰的报告美学 | | ✗ |

**底线纪律**：原型层和结构层永不冲突。任何象征叙事必须有结构层的事实依据；任何结构层结论必须能被翻译到原型层叙事中。这条纪律是产品质量的生死线——一旦双层不一致，产品瞬间退化为"用算命语言包装套壳 GPT"。

## 9. 差异化壁垒

四层。

**第一层 · 双层叙事的工程门槛**
通用大模型对"要不要离职"的默认反应是 helpful & harmless 的中庸建议。明决强行让模型走六步流水线 + 双层叙事一致性约束，要求一套精心设计的中间产物 schema、一套训练用户配合流水线的 onboarding、一套压制模型"跳过流水线直接给建议"倾向的对齐策略，再加一套双层一致性审查。这不是 prompt 工程能轻易复刻的——能形似但难神似。

**第二层 · 决策回访数据飞轮**
每个用户在做完决策后 3 / 6 / 12 个月被产品 prompt 回访"实际怎么样了"，形成不断增厚的"决策—画像—后果"数据集。这个数据集既喂回参考类预测的中期基线，又是公司最值钱的私域资产。GPT 永远拿不到。

**第三层 · 信任壁垒（推理链可见 + 双层都讲）**
通用模型说"建议你 X"，用户半信半疑。明决说"基于你的偏差档案、你的效用函数、你估计的这些概率，期望效用最高的是 X，前提是 Y 假设成立、且你愿意承担 Z 风险——以下是 pre-mortem"，然后**用原型语言再讲一遍同一个结论**。用户付费买的是"我看得见它怎么算出来的，并且我感觉它真的看见了我"——这两件事单独任何一个产品都做不到。

**第四层 · 个人神话编年史（留存复利）**
用户在产品里逐次积累一份**"决策档案 + 原型演化轨迹"**：你 2025 年是"照顾者"原型走过了"皇帝之路"中段，2027 年转向"探索者"踏上"愚人之旅"——既是真实数据库（喂模型），也是用户的个人叙事资产（情感粘性）。一旦积累，迁移成本极高。

这是占卜路线的留存逻辑（精神伴侣）和决策科学路线的留存逻辑（决策链下游 + 偏差画像复利）的正面合流。

## 10. 商业模式

**免费层**
- 完整 "Create Yourself" 问卷（一次性）；
- 每月 1 次完整决策推演；
- 短期 + 中期路径预测的原型层；
- 结构层只展示 Step 1–2（决策框定 + 选项树），后四步锁住。

**订阅层 · ¥68 / 月（年付 ¥588，约 ¥49 / 月）**
- 无限次决策推演；
- 完整六步流水线 + 双层路径画像；
- 决策回访 push（3 / 6 / 12 个月）；
- 偏差档案演进、历史决策对比、个人神话编年史；
- 周期性"当下映照"小工具（生日 / 新年 / 季节节点的轻量自我校准，不消耗决策次数）——核心留存抓手，让用户在没有大决策的月份也有理由打开。

**单次大额决策包 · ¥298 / 次（订阅可抵扣部分金额）**
- 针对房产 / 婚育 / 跨国迁移 / 创业等高利害决策；
- 更深度的参考类数据 + 多轮推演 + 可选的人工决策教练审阅（合作教练分成）。

**何时付费**：免费版给用户用一次完整推演 + 锁住后四步。用户在 Step 1–2 会被"决策框定"和"选项树展开"打开认知（"原来我以为的二元选项不是真二元"），到 Step 3 想看不确定性变量时撞上付费墙——此时付费意愿最高。
订阅率早期目标 12–18%——比纯工具类产品高（情感粘性强），比纯灵性类产品付费稳定（有结构性产出）。

## 11. 核心风险与不确定性

**风险 1 · 双层叙事一致性失控**
原型层和结构层必须严格对齐。一旦模型在某个边角 case 让两层冲突（"愚人之旅"配上"低方差稳定增长"的概率分布），用户立刻识别为"装神弄鬼"。**对策**：双层各自独立生成后做一致性审查 pass，冲突时以结构层为准、原型层重写。这条工程能力本身是壁垒，但也是最大技术风险。

**风险 2 · 合规边界**
中国大陆 + iOS 双轨监管。即使去掉紫微斗数和星盘排盘，"塔罗 + 原型 + 占卜式语言"在政策收紧周期仍可能被波及。
**对策**：
- 全产品话语严格使用"原型隐喻 / 思考工具 / 心理意象"框架，**不出现"算命 / 预测命运 / 凶吉"语言**；
- 对外文案定位为"AI 决策伴侣 + 心理映照工具"，不出现"占卜""算命"字样；
- iOS 上架走"心理 / 自我提升"类目；
- 保留一个纯结构化的"理性版本"开关作为政策应急的降级方案。

**风险 3 · 人群定位夹缝**
"读过《思考快与慢》也信塔罗"的人群确实存在，但比纯灵性人群或纯理性人群都更窄。早期增长曲线可能比单纯走任一边更慢。
**对策**：早期不追求规模增长，追求该夹缝人群里的高 NPS。这群人在小红书 / 即刻 / 播客圈子里影响力强，口碑增长 ROI 高。

**风险 4 · 长期预测的可信度地基**
长期路径只给原型叙事不给具体事件，是设计纪律也是赌注——赌用户能接受"长期不可预测但可命名"。如果用户期望"算到 5 年后我有没有娃"，这条产品逻辑就崩。
**对策**：onboarding 与首页文案明确管理预期——"明决不预言事件，明决帮你看清你正在选择什么样的故事"。早期会过滤掉一部分用户，但留下的用户精准度高。

**风险 5 · 数据飞轮起飞慢**
参考类预测的中期基线需要回访数据，早期数据稀薄时容易被识破。
**对策**：早期的中期预测显式说明"基于公开数据 + 同类样本估计、不基于本平台用户回访"，等回访数据起来后切换。诚实标注数据来源，比强行虚张声势的可信度高。

**不确定性 1**：工作名"明决"是否站得住，需在产品落地前做一次正式命名。

**不确定性 2**：双层叙事的 UX 呈现——默认展示原型层 + 点击展开结构层，还是横向并排，还是分两个 Tab。这是首版要打磨的核心交互。当前倾向"默认原型层 + 显式'看清这条路'按钮展开结构层"，因为它先打开情感通道再打开理性通道，符合产品的认识论顺序。

**不确定性 3**：是否在大额决策包里引入真人决策教练做混合服务——是商业模式扩展的关键岔路，但首版纯 AI 跑通后再决定。

## 综合判断说明（给后续审查者）

我在两个专家方案的张力里做的综合是：**取占卜的容器，不取它的认识论；取决策科学的骨架，不取它的冷感。**

**为什么不偏纯决策科学（专家 A）**：
A 的认识论自洽，但忽视了一个产品事实——通用 GPT 已经能把决策框架讲得很流畅，纯结构化决策辅助在 C 端的差异化护城河不够厚。冷感的输出不是"中产白领疯狂喜欢"的产品形态，是"中产白领订阅一次后续费乏力"的形态。A 自己也承认要"偷占卜的 UX 仪式感"——但仪式感不是 UI 装饰，仪式感来自象征语言本身。形式和内容在这里不可分。

**为什么不偏纯占卜命理（专家 B）**：
B 的体验设计极强，但有两个致命问题——一是核心声明（"愚人之旅可能经历高塔崩塌走向月亮"）本质仍是 Barnum，长期会被识破，特别是在目标人群是受过教育的城市白领时；二是合规风险显著（紫微斗数 + 出生时辰 + 占卜式预言在大陆 + iOS 双轨下是高风险品类）。把"宫廷弄臣"位置留给决策科学，意味着放弃产品最硬的护城河——结构化推理 + 数据飞轮。

**为什么走中间偏 A 一点的综合**：
**结构层是骨架，原型层是皮肤**。骨架决定产品是否真有用、能否产生数据飞轮、能否在用户回访中证明自己；皮肤决定用户是否愿意留下来、愿意付费、愿意把它讲给朋友。两者都不可缺，但**当冲突发生时以结构层为准**——这条纪律比"五五分"更重要，因为骨架错了产品没有持久价值，皮肤错了产品只是不够好看。

具体取舍偏向：
- **去掉紫微斗数和星盘**（合规 + 摩擦 + 因果不自洽，必须砍）；
- **保留 Jungian 原型**（被主流心理学接受，可作为思考隐喻而非神秘学预言）；
- **保留塔罗大阿卡纳作为象征语言**（不排牌阵作真预言，作为路径"故事核"命名）；
- **易经从"占卜起卦"重新定义为"问题镜像"**（用户输入问题被诗化转写为入口意象，不作为预测装置）；
- **决策科学的六步流水线整套保留**，但每一步用原型语言重新命名表层呈现。

用户画像在两份方案的中间收窄到一个更精准的夹缝——"读过《思考快与慢》也信过塔罗"的人。这个人群真实存在，且是 A 路线和 B 路线各自部分覆盖却都没真正吃透的人群。

最大的设计赌注是**双层叙事的一致性约束**。这是产品价值的根基也是最大的工程风险——做不好就两边不到岸。但做好了，护城河会比单边方案厚一倍：纯 A 路线复制不了体验，纯 B 路线复制不了可信度，套壳 GPT 两样都复制不了。
