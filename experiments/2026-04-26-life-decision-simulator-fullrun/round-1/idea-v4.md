# idea-v4 · 明决（Clear Choice）

## 1. 产品名

工作名：**明决**。后续可换正式名。

## 2. 一句话产品定义

明决是一款 C 端 AI 决策伴侣——在你为一个重要决策反复纠结的那段日子里，帮你看清两件事：你眼前真正有几条路，以及你在每条路上，正在赌的是自己的哪一面。

## 3. 核心价值主张

人生中段那些"想了两周还没决定"的事——要不要离职、要不要分手、要不要回老家——之所以难，是两件事同时发生：

- 用户被认知偏差、二元锚定、情绪噪声扭曲，**看不清自己在选什么**；
- 用户的理性防御又同时筑高，让任何冷冰冰的"决策框架"在情感层面被屏蔽掉。

明决用**两层语言**回应这两件事：

- **结构层**——决策科学的六步流水线（决策框定 / 选项展开 / 不确定性识别 / 可能性赋权 / 偏差审计 / Pre-mortem）。它解决的是"看清你在选什么"。
- **原型层**——Jungian 心理学的原型词汇（英雄 / 照顾者 / 探索者 / 智者 / 反叛者……）。它解决的是"让你愿意听结构层在说什么"。

两层做的不是同一件事的两种讲法。结构层提供事实与推理；原型层提供**意义命名**——把"选项 A 短期收入下降但学习曲线陡"翻译成"这是一段探索者的远行，主要课题是承受不确定性"。后者不是前者的装饰，而是让前者真正进入用户认知的载体。

我们卖的是 **"在你为这件事纠结的那段日子里，帮你看清自己面对的真实选项与赌注"**——不是预言，不是占卜，不是崩溃时段的情绪急救。

## 4. 目标用户与使用情境

### 4.1 用户画像

**28–38 岁一线 / 强二线城市白领。** 更精准——"读过《思考，快与慢》也找人看过塔罗"的那批人。他们：

- 受过本科以上教育，能看懂"期望效用""路径依赖""认知偏差"；
- 但对纯理性方法已经感到疲惫——做过 SWOT、列过优劣表，发现还是决定不了；
- 在心理咨询、灵修工作坊、MBTI、塔罗上有过付费经历，对"被看见"有支付意愿；
- 正面对人生级节点：转型、婚恋、生育、迁移、创业。

### 4.2 使用情境

明决**不为决策崩溃时刻设计**——凌晨 2 点哭、火锅店灌酒、HR 面前签字前 5 分钟，用户要的是朋友 / 酒 / 哭一场，不是结构化流水线。

明决服务的是 **"决策酝酿期"** ——从一个想法第一次冒出来、到最终签字之间那段反复琢磨的日子（通常 2–8 周）。这段时间用户**愿意花时间、有能力反思、会重复回访**——一次决策中多次回来调整。

为同时容纳重时刻与轻时刻，提供两种入口：

- **深度推演**（30–40 分钟一次）：用于关键节点。
- **快速捕捉**（90 秒，无需问卷）：地铁上 / 失眠时 / 洗澡后冒出的新想法、新担忧、新选项，写一段扔进去。

## 5. 核心使用流程

### 5.1 "Create Yourself" 入会问卷——分两次完成，首次最短 4 分钟

**首次（4 分钟）**——处境锚点 + 价值张力快速排序 + 主导原型识别（3 题意象题）。输出第一版"自我画像速写"。够做一次推演但承认是粗略的。

**深化（在第一次推演后或第三天唤回，6 分钟）**——风险与时间偏好、行为式偏差测试、原型补充。

**显式不采用**：出生年月时、生辰八字、星盘排盘、紫微命盘——合规风险大、采集摩擦高、因果不自洽。原型层只用 Jungian 心理学框架。

### 5.2 决策输入

入口不强制冥想动作（决策酝酿期用户不需要被教冥想）。

用户输入决策后，AI 主动做一件事：把"该不该 X"的二元提问，引导重构为探索式提问：
> "如果我选 X，我将要面对的课题是什么？我可能成为什么样的自己？"

这个改写动作本身就是认知干预——把用户从是 / 否的二元锚定里拉出来。

### 5.3 输出形式 + 视觉风格

输出**两层叠加**：

- **外层 · 原型镜鉴**——用 Jungian 心理学原型语言（英雄 / 照顾者 / 探索者 / 智者 / 创造者 / 反叛者 / 孤儿 / 寻道者……），把每个选项命名为一段成长课题。
- **内层 · 结构化推演**（点开"看清这条路"展开）——六步流水线的产物。

**两层如何被同时阅读**：它们不是两个互相打架的声音——但**这是产品的设计目标，不是它的默认状态，也是它真正难做的地方**。结构层说"是什么"，原型层说"你正在哪个故事里经历它"，两者本应是同一件事的两种粒度。但要让用户实际体验到这种"不冲突"，工程上需要**两层独立生成 + 一致性审查 pass + 冲突时以结构层为准重写原型层**。这条工程纪律是产品质量的生死线，也是与套壳模仿者的核心差异点——模仿者倾向让两层共用同一段生成，差异化随之消失。

**视觉风格**：现代极简、抽象自然意象（光影、地形、水面、晨雾），充足留白，serif + sans 混排。**没有塔罗牌、没有星盘图、没有占卜物件**——以"心理咨询室与读书 App 的中间地带"为参照，不向"排盘软件 / 灵性 App"那一侧倾斜。

### 5.4 一个具体的推演长什么样（关键样例）

用户输入："想了两个月，要不要从现在公司辞职去做自己的产品。"

**[决策框定]** AI 重述：
> "你真正在权衡的，可能不是'留 vs 走'，而是'在熟悉体系里继续累积 vs 在陌生环境里重新做学习者'。这个决策属于**单向门**（辞职后回到原岗的成本高），值得多花一周想清楚。"

**[选项展开]** AI 强制 ≥3 个选项：
- A. 现在辞职全职做产品
- B. 留在现公司
- C. 在职做副业验证，攒一年现金缓冲后再决定

**[不确定性]** A 选项的关键变量：市场需求 / 现金消耗速度 / 你独自工作的耐受度。

**[可能性赋权]** 不要求填百分比。问：
> "在你的画像里，A 选项在 12 个月内现金流转正的可能性，你的直觉是？"
> 选项：[非常可能] [比较可能] [五五开] [不太可能] [几乎不会]
> 选完后看到对应概率范围（如"五五开 ≈ 35–55%"），可拖滑块微调。

**[偏差审计]** AI 提一个**假设**而非判定：
> "看起来你给 A 选'比较可能'的判断里，可能有'可得性偏差'的影子——你前面提到过一个朋友最近创业进展不错。这只是我看到的一种可能性，不是结论。如果你有别的依据（比如做过用户访谈），可以告诉我，我重新审视。" [按钮：我不同意这个判断 / 我同意但有补充]

**[Pre-mortem]** "假设 18 个月后 A 选项失败了，最可能的失败原因是什么？" 用户自己填一段，这个回答会成为最终建议里的"边界条件"。

**[原型镜鉴 + 多路径画像]** 三条路径并列展示：

> **路径 A · 探索者的远行**
> 短期（0–6 个月）：每天解新问题的兴奋 vs 周末工作的孤独 vs 收入断崖的焦虑。
> 中期（1–3 年）：基线 ~50%——一次 pivot 后业务勉强自立、收入仍低于过去；上行 ~25%——产品-市场契合，收入超越；下行 ~25%——烧完缓冲回到雇佣市场，但能力让你拿到更高 offer。基线挂靠在公开创业人群数据 + 文献元分析。
> 长期（5+ 年）：这是"探索者"的故事核——**这条路的形状是高方差**（上限是建立自己的体系，下限是多元能力让你在任何雇佣关系里更有议价权）。我们不预测具体事件，因为 5 年后的世界与你都会变得我们没有理由假装预测得准。

> **路径 B · 照顾者的深耕** ……
> **路径 C · 寻道者的延后** ……

**[对比表]** 在用户最重要的 3–5 个效用维度（来自问卷）上每条路的相对位置——一眼看出"我选 A 是在赌 X，选 B 是在赌 Y"。

**[倾向性结论]**
> "基于你的偏好排序（自由 > 稳定 > 关系），A 期望效用最高——前提是你愿意承担 12–18 个月的现金流压力。如果不确定，C 是可逆的中间步骤，代价是 6 个月的决策延后。"

### 5.5 快速捕捉与深度推演的衔接

每个用户的每个决策有一条 **"思考流"**——按时间顺序叠放的卡片：你的快速捕捉、你做过的推演、决策回访的回答。

启动深度推演时，思考流里的快速捕捉卡片**自动浮到顶上**，让用户勾选哪些纳入这次推演（变成新的选项 / 新的不确定性变量 / 新的担忧）。不勾选的不丢失，留在思考流里。

地铁上记的东西**不会石沉大海**，下次坐下来推演时它会在那里等你。

## 6. 决策建议生成机制（六步流水线）

| 步骤 | 决策科学动作 | 原型层呈现 |
|---|---|---|
| 1. 决策框定 | 决策类型识别、双向门 vs 单向门 | "命名你正站在什么样的门槛上" |
| 2. 选项展开 | 强制 ≥3 个选项（含"延迟决定"路径） | "看清面前不止两条路" |
| 3. 不确定性识别 | 每个选项 2–3 个关键变量、可控/不可控分类 | "辨认风从哪里来" |
| 4. 可能性赋权 | 5 档可能性 + 可调滑块 → 粗概率范围 × 效用函数 | "给每条路的可能性赋一个重量" |
| 5. 偏差审计 | 以**假设**非判定呈现，用户可驳回 | "认出那个正在替你做决定的内在角色" |
| 6. Pre-mortem | "假设 18 个月后失败了，最可能的失败原因是什么" | "拜访那个 18 个月后失败的自己" |

**关键纪律**：

- **Step 4 是产品的核心认知干预动作之一**——让用户第一次被迫直面"我对这件事可能性的真实直觉是什么"。这条认识论不变，UX 实现方式经过修正：早期版本设想让用户对着空白框输入百分比，但真用户对着空白框敲不出有意义的概率（要么是拍脑门的假数字，要么是 round number），认知干预其实没发生。改为 5 档可能性 + 滑块后，被迫的那一刻仍然发生——用户必须认领一个语言档位（"我觉得这事儿是五五开还是不太可能"），这是真用户能给出的有意义直觉，也是 v1 想要却没用对载体的那个动作。**宣言不变，载体换成了人真用得上的语言。**

- **Step 5 永远以假设呈现**——若 AI 指认的偏差用户不认同，整次推演的信任感会崩。用户可点"我不同意"或"我同意但有补充"，画像即时更新。这是产品对用户的尊重也是信任根基。

## 7. 多路径人生预测

每条路径的双层画像：原型层 + 结构层。

**纪律一：分时间尺度区分颗粒度**

- **短期（0–6 个月）**：高颗粒度。具体行为、情绪、关系变化、典型挑战。两层都给。
- **中期（1–3 年）**：中颗粒度。结构性变化（职业层级、家庭结构、财务状况）。两层都给，显式标注概率带（基线 / 上行 / 下行），基线挂靠在公开数据 + 文献元分析的"画像相近人群中位结局"上，**诚实标注数据来源**。
- **长期（5+ 年）**：只给原型层 + **方差形状**。

**关于"长期只给故事核"是不是回避问题**：不是。这是诚实的边界。

5 年后的世界、技术、政策、用户自己——会变到没有人有理由假装预测得准。但这不意味着我们什么都不能告诉用户。我们能说的是 **路径的形状**：哪条路方差更大、哪条路上限更高下限更低、哪条路的核心课题是承担不确定性 vs 哪条路的核心课题是辨识被内化的他人期待。**这是关于"路径性质"的真实信息，不是关于"具体事件"的伪精确。**

如果用户期望的是"5 年后我大概率在哪、在干嘛"——明决会承认它给不了，并解释为什么任何号称能给的工具都是在编造。这是我们和"水军算命"的根本区别。早期会过滤掉一部分用户，但留下的精准度高。

**纪律二：路径之间显式做对比** 不出三份独立报告，出一张对比表 + 每条路径在用户最重要 3–5 个效用维度上的相对位置。

## 8. 占卜与决策科学的取舍

> **借决策科学的骨架，借 Jungian 心理学的原型语言提供仪式感，不借占卜的视觉与词汇外观。**

| 维度 | 取自 | 不取 |
|---|---|---|
| 决策六步流水线、期望效用、偏差审计、Pre-mortem、参考类预测 | 决策科学 ✓ | |
| Jungian 原型作为思考隐喻 | 心理学 ✓ | |
| 慢节奏、视觉留白、被认真对待的容器感 | 占卜的仪式感 ✓ | |
| 塔罗大阿尔卡纳具体牌名与图像 | | ✗ |
| 易经卦名 / 紫微星名 / 星盘 / 生辰八字 | | ✗ |
| 占卜式确定性预言、凶吉判断 | | ✗ |
| 冷冰冰的报告美学 | | ✗ |

**底线纪律**：原型层和结构层不冲突——这是产品的设计目标，**不是默认状态**。两层独立生成，一致性审查 pass 不通过则原型层重写。这条工程纪律是产品质量的生死线，也是与套壳模仿者的核心差异点：模仿者倾向让两层共用同一段生成，从而把"双层叙事"变成"同一段话写两遍"，差异化随之消失。明决的双层是两套独立约束 + 仲裁机制，做到位需要真功夫，做不到位用户立刻识别为"装神弄鬼"。

## 9. 差异化与可信度

不主张"VC 级护城河"。这是 indie 自洽产品，差异来自三件具体的事：

**1. 推理过程对用户可见 + 用户参与**
通用模型默认给中庸建议。明决让模型走六步流水线、把每步中间产物展示给用户、让用户认领可能性档位、自填 pre-mortem。差异不在能不能做，差异在**愿不愿意做完整**——多数模仿者不会做，因为它要求产品克制（不直接给答案）、要求 UX 教用户配合流水线、要求双层一致性的工程纪律。

**2. 双层叙事（原型 + 结构）**
通用模型说"建议你 X"，用户半信半疑。明决说"基于你的画像、偏好与你赋的可能性，A 的期望效用最高，前提是 Y、风险是 Z"——然后用心理原型语言再讲一遍同一个结论。**用户付费买的是"看得见怎么算的 + 感觉被看见"**，单独哪一件都不构成新颖产品。

**3. 用户档案的私域积累**
每个用户在产品里逐次积累自己的决策档案 + 原型画像演进。这不是 VC 级数据飞轮，是**对该用户**的服务复利：第二次推演比第一次更懂你。

## 10. 商业模式

### 10.1 模型选择

**国产高性价比模型**（候选：DeepSeek-V3 / Qwen / Doubao / Kimi 等），实测后选定一家为主一家为备。

**单次推演成本控制**：模板化中间产物 schema 减少自由文本生成；用户认领可能性档位 + 自选关键变量替代模型生成；长期预测只给原型层 token 量直接砍半。预估**完整高阶推演成本 ≤ ¥0.2**，**基础推演成本 ≤ ¥0.05**，**快速捕捉 ≤ ¥0.02**。

### 10.2 付费结构

分为**基础推演**（永久免费）和**高阶推演**（付费）两个产品，付费墙在两者之间，不在流程中间——用户不会被"话说一半收钱"。

**基础推演（永久免费、不限次数）**
- 4 分钟问卷；
- Step 1（决策框定 / 重述）+ Step 2（选项强制展开到 ≥3 条，含"延迟决定"路径）；
- 每个选项一句话原型标签（"看起来像探索者的远行"）；
- 一张"接下来该想清楚的 3 件事"卡片。

够用——它自己就能解决"我没意识到原来不止两条路"这个最常见的认知卡点。但**明显不够**——它不会告诉你每条路的不确定性变量、不会做偏差审计、不会出多路径画像、不会有 Pre-mortem。这个明显的差距是用户付费的驱动力。

**高阶推演（新用户 3 次免费 → 付费）**
- 完整六步流水线；
- 双层叙事（原型层 + 结构层）；
- 多路径画像（短 / 中 / 长 三时间尺度）；
- Pre-mortem；
- 决策回访 push（3 / 6 / 12 个月）；
- 思考流持久保存。

新用户**前 3 次完整高阶推演免费**——给足空间让用户体验完整价值。3 次后选择：

- **按次 · ¥9.9 / 推演**（主入口，匹配人生重大决策一年 1–3 次的真实频率）；
- **月度 · ¥39 / 月**含 8 次高阶推演 + 周期性"当下映照"轻量工具，适合同时多线纠结的用户；
- **年度 · ¥299 / 年**（约 ¥25 / 月）。

**为什么 3 次免费而不是 1 次**：1 次免费撞墙太硬，用户来不及体会复利价值。3 次让用户感受"它越来越懂我"再付费——产品的核心价值在于"系统逐步认识你"，这种价值需要不止一次的体验才能浮现。早期"撞墙式 1 次免费"是从占卜路线带过来的转化心理（占卜的付费时刻在好奇心被勾起的瞬间），与本产品作为事件驱动型工具的定位已不匹配。这是一次诚实的商业心理切换：从"挑起欲望-在欲望最高点收钱"切换到"让用户体验复利-觉得离不开了再收钱"——后者匹配产品真实的价值实现路径。

**留存的诚实假设**：本产品不是日活产品，是**事件驱动型**——用户在人生节点回来。一年用 2–4 次的用户即是健康用户。围绕事件做好"你回来时它还认识你 + 你的思考流还在"，比硬塞日推送好。

### 10.3 早期目标

1–2 年内 1000+ 下载、100+ 付费高阶用户、月流水稳定数千元——indie 小产品，不是 VC 故事。

## 11. 核心风险与对策

**风险 1 · 使用情境匹配**
明决服务决策酝酿期，不是崩溃时刻。
**对策**：onboarding 与首页文案明确——"崩溃时找朋友，思考时找明决"。"快速捕捉"作为低门槛入口承接灵感与碎片时刻。

**风险 2 · 合规边界（最关键）**
监管看产品视觉与行为，不看话术包装。
**对策（从一开始落地）**：
- 视觉层：**不出现塔罗牌图像、星盘图、卦象图**。原型层视觉用抽象自然意象。
- 词汇层：**不使用"愚人 / 高塔 / 死神 / 倒吊人"等塔罗专名，不使用"卦 / 爻 / 紫微 / 命宫"等命理专名**。原型层只用 Jungian 心理学词汇。
- 类目：iOS 上架"心理 / 自我提升"类，文案不出现"占卜""算命""塔罗""星盘"。
- 不依赖任何会被监管砍掉的元素——从一开始就把产品建在合规地基上，不留"应急降级"开关。

**风险 3 · 双层叙事一致性失控**
原型层和结构层冲突，用户立刻识别为"装神弄鬼"。
**对策**：双层各自独立生成后做一致性审查 pass，冲突时以结构层为准、原型层重写。早期可人工审查 + 模板约束，规模上来后再自动化。这是产品最大的不变赌注，也是与模仿者的核心差异点。

**风险 4 · 偏差审计被用户拒收**
若 AI 指认的偏差用户不认同，整次推演的信任感会崩。
**对策**：偏差审计永远以**假设**呈现，用户可驳回，画像即时更新。

**风险 5 · 用户画像收窄导致冷启动慢**
"读过《思考快与慢》也信塔罗"是真实存在的窄口子。前 100 用户从哪来要明确。
**对策**：早期不投放。集中在小红书 / 即刻 / 播客（《忽左忽右》《不合时宜》一类听众）+ 心理咨询师 / 塔罗师 KOL 社群。前期用产品本身的输出截图（用户授权后）做内容种子。

**风险 6 · 长期预测的预期管理**
若用户期望"算到 5 年后我有没有娃"，产品逻辑就崩。
**对策**：onboarding 文案明确管理预期——"明决不预言事件，明决帮你看清你正在选择什么样的故事。" 早期会过滤一部分用户，留下的精准度高。

## 综合判断说明

我在两个专家方案的张力里做的综合，经 P2A + P2B + P2C 三轮修正后稳定为：

> **借决策科学的骨架（六步流水线 + 期望效用 + 偏差审计 + Pre-mortem），借 Jungian 心理学的原型语言提供仪式感，不借占卜的视觉与词汇外观。**

**经 P2A 投资人批判修正过的**：
- 使用情境从"决策时刻"修正为"决策酝酿期"；
- 视觉与词汇层彻底去占卜化（原型层用 Jungian 心理学词汇而非塔罗牌名）；
- 单位经济按廉价国产模型 + 推演规模裁剪重算；
- 商业模式从订阅为主改为按次为主；
- 放弃 VC 级护城河叙事，定位为 indie 小产品。

**经 P2B 单盲反馈修正过的**：
- 加入完整推演样例（5.4 节），让原型层第一次有了具体面貌；
- 明确双层叙事的关系：用户体验上"不冲突"是产品目标（不是默认状态）；
- Step 4 UX 从"用户自填概率"改为"5 档可能性 + 滑块"——更准确实现 v1 的认知干预意图；
- Step 5 偏差审计从"判定"改为"假设"，用户可驳回；
- 加入视觉风格描述；
- 重写长期预测的措辞；
- 付费结构改为基础推演永久免费 + 高阶推演新用户 3 次免费 → 付费。

**经 P2C 知情复审修正过的**：
- 第 5.3 节双层关系描述补回工程纪律——用户体验"不冲突"是产品目标，实现它需要双层独立生成 + 一致性审查 pass + 冲突时原型层重写；
- 第 6 节 Step 4 加回认识论宣言文字——v1 的"被迫直面不确定性直觉"宣言不变，只是 UX 载体换成了真用户能用的语言；
- 第 8 节底线纪律强化——明确这是与套壳模仿者的差异点，模仿者倾向让两层共用生成；
- 第 10 节付费结构补出商业心理切换的诚实记录——从"挑起欲望-在欲望最高点收钱"切到"让用户体验复利-觉得离不开了再收钱"，后者匹配产品真实价值实现路径。

**关于"v3 / v4 是不是已经走上了 v1 警告过的路"——这是 P2C 提出的核心问题，也必须诚实回答。**

是，部分是。v1 综合判断里说"不能走纯决策科学路线"，理由有三：
- 通用 GPT 已能做决策框架（差异化弱）；
- 冷感输出留存差；
- 不够"被看见"。

v4 对这三条理由分别给出了新答案：
- **差异化不靠"做决策框架"，靠"双层叙事 + 推理过程对用户可见 + 用户被迫参与中间产物"**——这三件事 GPT 默认不做、模仿者做不完整，足以支撑 indie 规模的差异化（不主张 VC 级护城河）；
- **留存不靠"精神伴侣的复利"，靠"事件驱动型工具 + 思考流持久 + 画像随用精进"**——这是工具型产品的健康留存模型，不假装自己是日活；
- **"被看见"不靠"占卜的象征容器"，靠"Jungian 原型语言 + 慢节奏视觉 + 用户档案演进"**——同样的功能，合规地基。

v1 警告的"纯决策科学"是指**不带任何意义命名层、纯期望效用计算器**的产品。v4 不是这个——v4 保留了原型层作为意义命名的工具，只是把承载它的视觉与词汇从占卜换成了心理学。是结构性改变，不是骨架被掏空。

承认的事实：v1 设计中"占卜容器"承载的具体载体（塔罗大阿尔卡纳、易经卦象、紫微排盘、订阅 + 编年史复利、撞墙式付费转化心理）确实在 P2A + P2B 修正后被一一移除，原因不是它们都不好，而是**它们在合规、单位经济、使用情境三处都站不住**。v4 的产品形态比 v1 更小、更工具化、更 indie——这是这个产品在这个用户、这个规模、这个监管环境下的真实可行形态。

**没有改的核心立场**：
- 双层叙事（原型 + 结构）作为产品骨架；
- 长期只给故事核 + 方差形状、不预测具体事件的反 Barnum 纪律；
- "结构层是骨架、原型层是皮肤、冲突时以结构层为准"的底线纪律——并且这条纪律在 v4 中重新强化为工程现实，不是宣言挂着。

最大的不变赌注：**双层一致性约束做得到位**。在 indie 小规模 + 早期人工审查参与的前提下，这条赌注比 v1 设想的可控。
