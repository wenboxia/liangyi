# idea-v2 · 明决（Clear Choice）

## 1. 产品名

工作名：**明决**。后续可换正式名。

## 2. 一句话产品定义

明决是一款 C 端 AI 决策伴侣——在你为一个重要决策反复纠结的那段日子里，帮你用结构化的方式 + 心理原型的语言，看清自己在赌什么。

## 3. 核心价值主张

人生中段那些"想了两周还没决定"的事——要不要离职、要不要分手、要不要回老家——之所以难，是两件事同时发生：

- 用户被认知偏差、二元锚定、情绪噪声扭曲，看不清自己真正在选什么；
- 用户的理性防御又同时筑高，让任何冷冰冰的"决策框架"在情感层面被屏蔽掉。

明决的价值，是**用心理原型的语言，把结构化决策推演真正递到用户面前**。原型语言是让用户愿意慢下来、诚实面对自己的载体；结构推演是让原型不退化成自我安慰的骨架。

我们卖的是 **"在你为这件事纠结的那段日子里，帮你看清自己面对的真实选项与赌注"**——不是预言，不是占卜，不是当下崩溃时段的情绪急救。

## 4. 目标用户与使用情境

### 4.1 用户画像

**28–38 岁一线 / 强二线城市白领。**

更精准——"读过《思考，快与慢》也找人看过塔罗"的那批人。他们：

- 受过本科以上教育，能看懂"期望效用""路径依赖""认知偏差"这类概念；
- 但对纯理性方法已经感到疲惫——做过 SWOT、列过优劣表，发现还是决定不了；
- 在心理咨询、灵修工作坊、MBTI、塔罗上有过付费经历，对"被看见"的体验有支付意愿；
- 正面对人生级节点：转型、婚恋、生育、迁移、创业。

### 4.2 使用情境（这是 v1 错位的部分，必须重新明确）

明决**不是为决策崩溃时刻设计的**——凌晨 2 点哭、火锅店灌酒、HR 面前签字前 5 分钟，这些时刻用户要的是朋友 / 酒 / 哭一场，不是 12 分钟问卷。

明决服务的是 **"决策酝酿期"** ——从一个想法第一次冒出来、到最终签字之间的那段反复琢磨的日子。这段时间通常 2–8 周，用户会在地铁上、午休时、洗澡时、失眠时反复想同一件事。这段时间里：

- 用户**愿意花时间**、希望被认真对待；
- 用户**有能力反思**、不是纯情绪发泄状态；
- 用户**会重复打开**——不是一次决策一次推演，而是一次决策中多次回访（看完一次推演、过两天有了新信息再回来调整）。

为了同时容纳这段使用周期里的"重时刻"和"轻时刻"，产品提供两种入口：

- **深度推演**（30–40 分钟一次完整 session）：用于关键节点。
- **快速捕捉**（90 秒，无需问卷）：用于灵感时刻——把一个新想到的选项 / 一个新的担忧 / 一个晚上突然冒出的感受，扔进同一个决策的"思考流"里，下次深度推演时被纳入。

明决不假装能取代崩溃时刻的朋友。明决服务的是崩溃前后那段更长、更安静、用户更需要思考工具的日子。

## 5. 核心使用流程

### 5.1 "Create Yourself" 入会问卷——分两次完成，首次最短 4 分钟

v1 的 12 分钟一次问卷太重，撞上首次进入流失。改为**渐进式**：

**首次（4 分钟，解锁产品）**
- 处境锚点：年龄、城市、职业大类、婚育、家庭经济缓冲（可承受失业月数）；
- 价值张力快速排序（4 题 forced-choice）：自由 vs 稳定、成就 vs 关系、短期愉悦 vs 长期意义、掌控 vs 自由度；
- 当前主导原型快速识别（3 题意象题）：你此刻更觉得自己在 [深渊 / 迷宫 / 荒原 / 高塔 / 渡口] 中哪一个？

输出第一版"自我画像速写"——粗但够用，足以做一次推演。

**深化（在第一次推演后或第三天 push 唤回，6 分钟）**
- 风险与时间偏好题（5 题）；
- 行为式偏差测试（5 题，暗藏锚定 / 可得性 / base rate neglect 陷阱）；
- 原型补充题（4 题情境反应）。

输出完整"自我画像"。

**显式不采用**：出生年月时、生辰八字、星盘排盘——合规风险大、采集摩擦高、因果不自洽。原型层用 Jungian 心理学框架（被主流心理学接受），不用紫微 / 星盘 / 易经起卦。

### 5.2 决策输入

入口不强制仪式动作（v1 的"深呼吸 30 秒"删除——决策酝酿期用户不需要被教冥想）。

用户输入决策后，AI 主动做一件事：把"该不该 X"的二元提问，引导重构为探索式提问：
> "如果我选 X，我将要面对的课题是什么？我可能成为什么样的自己？"

这个改写动作本身就是认知干预——把用户从"是 / 否"的二元锚定里拉出来。

### 5.3 输出形式

输出两层叠加：

**外层 · 原型镜鉴**
用 Jungian 心理学的原型语言（英雄 / 照顾者 / 探索者 / 智者 / 创造者 / 反叛者 / 孤儿 / 寻道者……），把每个选项命名为一段成长课题：

> 选项 A 是一段"探索者的远行"：你将丢掉积累、在新地里重新做学习者，主要课题是承受不确定性。
> 选项 B 是一段"照顾者的深耕"：你将在已有体系里继续承担与累积，主要课题是辨识哪些责任是真实的、哪些是被内化的他人期待。

**显式不使用**：塔罗大阿尔卡纳 22 张牌的具体牌名（愚人 / 高塔 / 月亮 / 死神 / 倒吊人……）、易经卦名、紫微星名。这些名词的视觉与文化负载会触发应用商店审核与监管整改。Jungian 原型是**心理学**词汇，可用；塔罗是占卜物件，不可用。

**内层 · 结构化推演**（点开"看清这条路"展开）
六步流水线（详见第 6 节）的产物——选项树、不确定性、概率/效用、偏差审计、Pre-mortem。

**关键纪律**：原型层的诗化叙述与结构层的概率推演**不得互相冲突**——若原型层说"探索者的远行"，结构层就必须显示与之一致的"高方差、上下限拉大"的路径分布。

## 6. 决策建议生成机制

显式六步流水线，每步对用户可见。但**裁剪后的轻量版**——v1 的版本对小规模廉价模型部署是负毛利的，改为：

| 步骤 | 决策科学动作 | 原型层呈现 |
|---|---|---|
| 1. 决策框定 | 识别决策类型（一次性 / 可逆 / 链式）、双向门 vs 单向门 | "命名你正站在什么样的门槛上" |
| 2. 选项树展开 | 强制 ≥3 个选项（含"延迟决定，N 个月内收集 Y 信息"路径） | "看清面前不止两条路" |
| 3. 不确定性识别 | 每个选项 2–3 个关键变量（v1 是 3–5）、可控/不可控分类 | "辨认风从哪里来" |
| 4. 概率与效用估算 | 用户自填主观概率 × 问卷效用函数 → 期望效用 | "给每条路的可能性赋一个重量" |
| 5. 偏差审计 | 对照用户偏差档案，指出本次推演中可能的偏差痕迹 | "认出那个正在替你做决定的内在角色" |
| 6. Pre-mortem | "假设 18 个月后这个选择失败了，最可能的失败原因是什么" | "拜访那个 18 个月后失败的自己" |

**关键纪律**：Step 4 的概率必须由用户自己填——这本身就是认知干预，且大幅减少模型生成成本。

最终建议形态：**一份倾向性结论 + 边界条件 + 推理链**。永远不替用户拍板，但也不和稀泥。

## 7. 多路径人生预测生成机制

每个选项产出一份双层人生画像：原型层叙事 + 结构层情景。

**纪律一：分时间尺度区分颗粒度**

- **短期（0–6 个月）**：高颗粒度。具体行为、情绪、关系变化、典型挑战。两层都给出。
- **中期（1–3 年）**：中颗粒度。结构性变化（职业层级、家庭结构、财务状况）。两层都给出，并显式标注概率带（基线 / 上行 / 下行）。基线情景挂靠在公开数据 + 文献元分析估计的"画像相近人群中位结局"上，**诚实标注数据来源**。
- **长期（5+ 年）**：低颗粒度。**只给原型层**——这条路径的"故事核"和方差形状（"上限更高下限更低"），不预测具体事件。

为什么长期只给原型：长期具体预测必然是 Barnum 或证伪自杀，是产品的死亡区。原型层在这里**正好胜任**——它不假装预测事件，它命名一类人生形态。这是诚实的、有意义的、且不假装可证伪的。

**纪律二：路径之间显式做对比**
不出三份独立报告，出一张对比图：每条路径在用户标注的 3–5 个最重要效用维度上的相对位置。用户一眼看出"我选 A 是在赌 X，我选 B 是在赌 Y"。

## 8. 占卜与决策科学的取舍

明决的综合立场：

> **借决策科学的骨架，借心理学原型语言提供仪式感，不借占卜的视觉与词汇外观。**

具体取舍：

| 维度 | 取自 | 不取 |
|---|---|---|
| 决策六步流水线、期望效用、偏差审计、Pre-mortem、参考类预测 | 决策科学 ✓ | |
| Jungian 原型作为思考隐喻（英雄 / 照顾者 / 探索者……） | 心理学 ✓ | |
| 慢节奏、视觉留白、被认真对待的容器感 | 占卜的仪式感 ✓ | |
| 塔罗大阿尔卡纳具体牌名与图像 | | ✗ 合规与认识论双拒 |
| 易经卦名与起卦推演 | | ✗ 同上 |
| 紫微斗数 / 星盘 / 生辰八字 | | ✗ 同上 |
| 占卜式确定性预言、凶吉判断 | | ✗ 与价值主张直接冲突 |
| 冷冰冰的报告美学 | | ✗ 用户会屏蔽 |

**底线纪律**：原型层和结构层不冲突。冲突时**以结构层为准、原型层重写**。这是产品质量的生死线。

## 9. 差异化与可信度

不主张这是个有"VC 级护城河"的产品。这是个 indie 自洽产品，其差异来自三件具体的事：

**1. 推理过程对用户可见**
通用模型的默认反应是 helpful & harmless 的中庸建议。明决强行让模型走六步流水线、把每一步的中间产物展示给用户、让用户自填概率。这不是不可复刻——senior engineer 一周能搭出 orchestration——但**多数模仿者不会真做**，因为它要求产品克制（不直接给答案）、要求 UX 教育用户配合流水线、要求双层一致性的工程纪律。差异不在能不能做，差异在愿不愿意做完整。

**2. 双层叙事（原型 + 结构）**
通用模型说"建议你 X"，用户半信半疑。明决说"基于你的偏差档案、你的效用函数、你估的概率，期望效用最高的是 X，前提是 Y、风险是 Z"——然后用心理原型语言再讲一遍同一个结论。**用户付费买的是"看得见怎么算的 + 感觉被看见"**，两件事单独哪个都不构成新颖产品。

**3. 用户档案的私域积累**
每个用户在产品里逐次积累自己的决策档案 + 原型画像演进。这不作为"VC 级数据飞轮"来卖（回访率低本来就是行业事实），而是作为**对该用户**的服务复利：第二次推演比第一次更懂你。这是用户层面的体验改进，不是融资故事。

不主张：决策回访能转出统计意义上的"参考类数据资产"——回访率 5% 在小规模下没意义。决策回访 push 保留为产品功能，但只做用户感知（"产品在陪我"），不当数据壁垒卖。

## 10. 商业模式

按 indie 小产品的现实重设——目标 1–2 年内 1000+ 下载 / 100+ 付费用户 / 月流水稳定数千元，**不是 VC 估值故事**。

### 10.1 模型选择

**使用国产高性价比模型**（候选：DeepSeek-V3 / Qwen / Doubao / Kimi 等），按"在本产品的中文长文本推理 + 原型语言生成 + 结构化输出 + 偏差识别"四项能力做实测后选定一家为主、一家为备。

**单次完整推演的工程裁剪**：
- 推演规模控制在 5–15k token I/O（v1 的 50–100k 不可承受）；
- 通过模板化中间产物 schema（选项树 / 概率表 / 偏差审计）大幅减少自由文本生成；
- 用户自填的概率 + 自选的关键变量替代模型生成；
- 长期预测只给原型层，token 量直接砍半；
- 短期 + 中期路径用结构化输出 + 诗化壳子组合，不每次重生成长篇散文。

预估单次完整推演成本 ≤ ¥0.2（约一两毛）。轻量"快速捕捉"模式 ≤ ¥0.02。

### 10.2 付费结构

**免费层**
- 完整 4 分钟问卷；
- 1 次完整推演（lifetime，不是每月——一次性钩子）；
- 轻量"快速捕捉"模式不限次数。

**按次付费 · ¥9.9 / 推演（主入口）**
不强迫订阅。用户做完一次后，第二次直接掏 9.9。这与人生重大决策真实频率（一年 1–3 次）匹配，避免订阅续费断崖。

**月度订阅 · ¥39 / 月（含 8 次推演 + 周期性"当下映照"轻量工具）**
适合当下正在多线纠结（同时面对换工作 + 是否分手 + 要不要搬家）的用户。**不出"无限次推演"**——单位经济不允许，且无限次会鼓励冲动滥用。

**年度订阅 · ¥299 / 年**（约 ¥25 / 月）

**何时付费**：免费版给一次完整推演——用户在 Step 1–2 会被"决策框定"和"选项树展开"打开认知（"原来我以为的二元选项不是真二元"），到 Step 3 想看不确定性变量时撞上付费墙。次次付费而非订阅锁定，保留用户尊严。

**留存的诚实假设**：本产品不是日活产品，是**事件驱动型产品**——用户在人生节点找回来。一年使用 2–4 次的用户即是健康用户，不需要把他变成日活。围绕事件做好"你回来时它还认识你"，比硬塞日推送好。

## 11. 核心风险与对策

**风险 1 · 使用情境匹配**
明决服务的是决策酝酿期，不是崩溃时刻。如果用户在崩溃时刻打开 App、面对结构化流水线，立刻流失并留下"这东西不懂我"的印象。
**对策**：onboarding 与首页文案明确——"明决帮你看清你正在选什么。崩溃时找朋友，思考时找明决。"主动设定预期。"快速捕捉"模式作为崩溃时刻的低门槛入口（不强迫推演，只允许写下一个想法 / 一个担忧），等用户冷静后回来深度推演。

**风险 2 · 合规边界（最关键）**
中国大陆 + iOS 双轨监管。监管看的是产品视觉和行为，不是话术包装。
**对策（必须从一开始落地，不能依赖"应急降级"）**：
- 视觉层：**不出现塔罗牌图像、不出现星盘图、不出现卦象图**。原型层视觉用心理学风格的抽象意象（光影、地形、自然元素），不用占卜物件。
- 词汇层：**不使用"愚人 / 高塔 / 死神 / 倒吊人"等塔罗专名，不使用"卦 / 爻 / 紫微 / 命宫"等命理专名**。原型层用 Jungian 心理学词汇（英雄 / 照顾者 / 探索者 / 智者……）。
- 类目：iOS 上架"心理 / 自我提升"类，文案定位"AI 决策伴侣 + 心理映照工具"，不出现"占卜""算命""塔罗""星盘"字样。
- 删去 v1 的"理性版本降级开关"——这条等于承认核心价值脆弱。从一开始就让产品不依赖任何会被监管砍掉的元素。

**风险 3 · 双层叙事一致性失控**
原型层和结构层冲突时，用户立刻识别为"装神弄鬼"。
**对策**：双层各自独立生成后做一致性审查 pass，冲突时以结构层为准、原型层重写。早期可以用人工审查 + 模板约束，规模上来后再自动化。

**风险 4 · 用户画像收窄导致冷启动慢**
"读过《思考快与慢》也信塔罗"的人群是真实存在的窄口子。在 1000 下载量级这不是问题，但前 100 用户从哪来需要明确。
**对策**：早期不做投放。集中在小红书 / 即刻 / 播客（《忽左忽右》《商业就是这样》《不合时宜》一类节目的听众）+ 心理咨询 KOL / 塔罗师社群（这些 KOL 自己就是这个夹缝人群）做内容种子。前 100 用户用产品本身的输出截图做内容（用户授权后），是最自然的传播物料。

**风险 5 · 长期预测的预期管理**
长期路径只给原型不给具体事件，是设计纪律。如果用户期望"算到 5 年后我有没有娃"，这条产品逻辑就崩。
**对策**：onboarding 与首页文案明确——"明决不预言事件，明决帮你看清你正在选择什么样的故事。"早期会过滤掉一部分用户，但留下的精准度高。

## 综合判断说明（更新版）

我在两个专家方案的张力里做的综合，经 P2A 投资人批判后修正为：

> **借决策科学的骨架（六步流水线 + 期望效用 + 偏差审计 + Pre-mortem），借 Jungian 心理学的原型语言提供仪式感，不借占卜的视觉与词汇外观。**

**相对于 v1 的核心改动**：

1. **使用情境从"决策时刻"修正为"决策酝酿期"**——v1 把决策时刻当冥想时刻设计，是错位的。决策崩溃时刻用户要朋友不要流水线；决策酝酿期才是产品真正的服务对象。增加"快速捕捉"轻入口承接酝酿期里的灵感时刻。删除强制"深呼吸 30 秒"。

2. **彻底清洁视觉与词汇层的合规面**——v1 保留塔罗大阿尔卡纳和易经词汇是地雷。改为：所有视觉与词汇都收敛到 Jungian 心理学框架（英雄 / 照顾者 / 探索者……），删除塔罗牌名、卦象、星盘 / 紫微元素。原型层的仪式感保留，但承担仪式感的不是占卜物件，是心理原型本身的叙事重量 + 节奏 + 视觉抽象意象。删除"理性版本降级开关"——从一开始就不依赖会被监管砍掉的元素。

3. **单位经济按廉价国产模型 + 推演裁剪重算**——v1 的 50–100k token / 推演在国产廉价模型下也跑不通。砍到 5–15k token：模板化 schema、用户自填概率、长期只给原型层、不每次重生成长篇散文。单次成本控制在 ¥0.2 以内。

4. **付费结构从订阅为主改为按次为主**——人生重大决策一年 1–3 次，强推订阅必然续费断崖。¥9.9 / 推演按次为主，¥39 / 月含 8 次为辅，**取消"无限次推演"**。

5. **不主张 VC 级护城河叙事**——明决是 indie 小产品，目标 1000+ 下载 / 100 付费用户 / 月流水稳定。差异化降级为三件具体的事（推理过程可见、双层叙事、对个人用户的画像复利），不当融资故事卖。

**相对于 v1 没有改动的核心立场**：

- 双层叙事（原型 + 结构）作为产品骨架不变，因为这就是综合方案的灵魂。
- 长期预测只给原型不给具体事件，反 Barnum 反水军算命的纪律不变。
- "结构层是骨架、原型层是皮肤、冲突时以结构层为准"这条底线纪律不变。

最大的不变赌注：**双层一致性约束做得到位**。这是产品价值的根基，做不好两边不到岸。但在 indie 小规模 + 早期人工审查可参与的前提下，这条赌注比 v1 设想的要更可控。
