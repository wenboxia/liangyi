## 第二步 · 判定

**累积 1 个 kill shot**(#1)+ 4 个 fixable(K+M)。

按 Kill shot 分级规则:0 或 1 个 kill shot → 所有论据作为框架内修改、产出 r2-idea-v5。

**Claude-2 的诚实自检**:论据 #2-5 都仔细想过有没有强行降级的倾向。结论是它们都有真问题、但严重度都依赖一个具体性高于 M 的前提(Headspace 适用于 indie / 海外华语真有 7×500 天花板 / 用户参与等同于推理可视化 / 长期模糊真的等于自毁),这些前提的具体性都是中等以下。论据 #1 不一样——它的三个死亡产品 + 行为经济学模型 + 90% 数据累积起来 specificity 是 H、且直接打到产品定位的根。这是真 kill shot。

## 第三步 · 拆台响应方案(先与 Wenbo 讨论,不直接产出 r2-v5)

### 初版修改方案 ABCDEF(Wenbo 介入前)

**修改 A · 应对 #1(Kill shot)—— 重新框定酝酿期假设**

最重的一改、做三件事:

- A1 · §4.2 使用情境重写——承认"长期模糊不适 + 触发事件 → 短窗口决定 + 事后合理化"是真实模式;产品同时承接"真酝酿期用户"和"事后压力测试用户"
- A2 · 加"轻推演"作为 30-40 分钟流水线的替代——决策框定 + 选项展开 + Pre-mortem(对当前倾向选项)+ 一次偏差审计;定价 ¥4.9 / $0.99
- A3 · §11 风险 1 重写——加入"酝酿期假设的 validation milestone":首批 50 用户深访必问"你打开明决时,这件事在你心里处于哪个阶段?"

**修改 B · 应对 #2(双峰获客)—— 单一主轴 + 镜子层下沉**

- §9 + 综合判断里明确 marketing 主轴是"决策思考工具",镜子层降为 feature
- 反思派用户通过 onboarding / feature 页面发现镜子层、不通过获客 marketing
- §11 加新风险:"双峰获客在 scaling 时的 Headspace 问题"

**修改 C(初版)· 应对 #3(海外华语碎片化)—— 收窄首发市场**

- §4.1 主要覆盖部分明确首发优先级:北美华人留学 + 工作群体(语言、文化、决策类型最一致)
- 第二波港澳台、被动覆盖东南亚 / 欧洲 / ABCs
- 删除"海外华语市场"作为统一概念的暗示

**修改 D · 应对 #4(推理可见已商品化)—— 明确差异化是"用户参与"非"AI 展示"**

- 关键论点:用户走完一次推演不是因为 AI 算给他听、是因为他自己被迫想了 30 分钟

**修改 E · 应对 #5(格式自毁)—— 显式声明颗粒度梯度作为认识论位置**

## Wenbo 介入后的实际处理路径

Wenbo 没有直接批准,而是介入修正修改 C:

> "我补充一点,就是实际上我们面向的主要客户群体肯定还是中国大陆的客户,虽然我知道是被大陆禁止的,但是大陆很多人平时也都翻墙用vpn之类的而且也可以信用卡支付,所以我觉得定位的客户群体不应该选择为北美华人之类的,你觉得呢"

**对 Claude-2 处理的影响**:

Claude-2 承认 Modification C(收窄到北美华人)是对 P2D #3 的过度防御性回应——critic 说 7 碎片化、就缩到一个最同质的子市场。但这其实丢了产品最大的实际用户群体。

Claude-2 把"不进大陆"和"实际用户构成"明确拆成两件事:

| 维度 | 处理 |
|---|---|
| 官方对外定位 / ToS | "本服务面向中国大陆以外的全球用户"——保持不变(法律护盾) |
| 服务器 / 域名 / app store | 海外、不上大陆——保持不变 |
| 支付通道 | Stripe / Paddle / 信用卡 / 支付宝海外版 / 微信支付国际版——保持不变 |
| 大陆 SEO / 投放 | 不做——保持不变 |
| **实际用户构成的诚实预期** | **从"海外华人为主"修正为"大陆背景中文用户为主"**——包括大陆 VPN 用户、临时海外的、移民的;海外华人是其中一部分 |
| Marketing 渠道选择 | 改为小红书 + 即刻 + 微信公众号(被转载)+ 小宇宙——这些渠道天然覆盖大陆背景中文用户 |
| 产品的文化参照 | 改为大陆典型决策(体制内 vs 跳槽 / 一线 vs 老家 / 国内 vs 出国 / 婚恋节点 / 买房) |

新增 2 条诚实记录的风险:
- 风险新加 · 支付通道与域名风险(Stripe / Paddle 可能被施压)
- 风险新加 · 个别用户的合规暴露(大陆境内 VPN 用户的合规问题归用户、产品给最大数据保护)

**修改 C 重写**:撤回"收窄到北美华人留学+工作"。改为"大陆背景中文用户"——共享同一套决策语言与文化参照、无论当前物理位置。

**Wenbo 批准** → Claude-2 写 r2-idea-v5。

## 方法论备注(给 longterm-and-reference 的候选观察)

round-2 的 P2D-fix 判定路径**完全在变种 5.2 节设计内**——1 个 kill shot 直接框架内修改、不触发回 P1、终止条件不需要兜底。这与 round-1 的"3 个 kill shot 但用换战场消解"形成对照。

值得注意的是:round-1 的 P2D 产 3 个 kill shot 候选,round-2 的 P2D 只产 1 个 kill shot——这有两种可能的解释:
1. **方案真的更 solid 了**——v5 经过 round-1 4 轮修订后,确实把可被攻击的 K+H 面缩小了
2. **二次 P2D 不可能像首次那么狠**——某些原本会成为 K+H 的攻击面已被 round-1 处理过、二次 critic 拿不出新的 H 级具体证据

具体看本场景:round-2 P2D 论据 #2 / #3 / #4 / #5 的"具体性"被 Claude-2 评为 M——而 round-1 P2D 的 4 条论据具体性全部 H。这与"方案 solid 了"的解释一致——round-1 的 H 级证据(MBTI / Mooda / 监管法规)在 v5 已经被消化进 Barnum 护栏 + 不进大陆战略,二次拆台拿不出同等具体性的新攻击面。

跨场景值得验证:**二次 P2 验证轮的 P2D 通常会比首次更"框架内"**——这可能是新机制的稳定特征、而不是本场景的偶然现象。
