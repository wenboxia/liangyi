方向漂移暴露报告
v1 是什么，v3 是什么
v1 是一份风控智能体产品方案。通篇回答一个问题：怎么用规则 + GBDT + 序列模型 + LLM 编排出一条能经得起申诉的证据链？人在文档里出现，但出现的方式是"使用者与被影响方"——产品的用户。文档的重心压在判决机制、系统形态、模型对抗上。

v3 是一份组织变革立项书，里面嵌着一个风控智能体。整份文档的重心已经明显转移：FTE 释放比例与回收周期、岗位稳定性承诺、转岗通道、责任划分条款、绩效中立条款、工时承诺、申诉 SLA 归因规则、合规披露义务、Phase 04 跨 1824 月的 roadmap、转岗完成率作为阶段验收指标。核心判别机制基本没动，但占篇幅的是"怎么替代一线 FTE 而不激怒员工、不触劳动法、不被监管问询"。

每一步都合理，合起来换了一份文档
P2A-1 要 FTE 数字 → 预算审批确实需要锚点 ✓
P2A-2 拆三档 → 消掉了 v1 "替代绝大多数"与"双重高置信"的矛盾 ✓
P2A-4 合规披露 → 法务红线 ✓
P2A-5 保留情报小组 → 对抗黑产的硬约束 ✓
P2B-1 岗位稳定性承诺 → 员工接受度是产品接受度的地基 ✓
P2B-2 责任划分 → 没这条一线不会用 ✓
P2B-3 撤回"3~4 倍" → 诚实 ✓
P2B-4 绩效中立 → 合理 ✓
每一项单拎出来都站得住脚，而且回应的都是文档外部真实存在的压力（预算、法务、HR、员工焦虑）。但八项加总之后，文档回答的主问题从"这个智能体怎么判别刷单"变成了"这个替代项目怎么落地而不翻车"。v1 里 LLM 是"秘书与讲述者"，在 v3 里被明确踢出在线链路、只做异步报告——这本身是对的，但同时意味着原来被称作"智能体"的那个东西，在产品定位里的分量实际上在缩小。

留给读者的问题
v1 的标题是"证据为核心的风控智能体"，v3 的标题也是。但如果把两份文档交给两个不读标题只读正文的人，他们会给出两个不同的答案：一个说"这是风控产品"，一个说"这是 HR + 合规 + 工程的综合立项"。

方向从"做一个能用的风控智能体"漂到了"做一个 55%~70% FTE 替代项目并确保它上线时不炸"——这是想要的方向吗？

如果预算答卷、合规答卷、员工答卷本来就是立项必须同时交的三份卷子，那 v3 是正常收敛；如果立项的主语本来只是"风控智能体"，其余是外围约束，那 v3 的重心已经不在主语上了。这一步是读者判断，不是作者替读者判断。
