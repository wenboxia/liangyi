# 实验 · 美团风控场景 · 无人工决策版方法论

## 时间
2026-04-23

## 实验目的
在不改本体的前提下，把方法论里所有人工决策点全部去除，跑一次"全自动化"变体，观察效果。是对立场三（"人的核心价值是做出最终决策"）和红线五（"不让 AI 替代做出最终决策那个动作"）的一次正面压力测试。

## 场景
美团（大众点评 / 外卖）商家恶意刷单识别——内部工具型产品（降本逻辑，非盈利逻辑；用户是被迫使用的风控员工，不是付费客户）。方法论本体不变，改的只是各步骤输入的参数：
- P2A 投资人视角 → 美团风控部门负责人视角（FTE 替代比、误杀率、合规成本）
- P2B 单盲对象 → 被迫使用的风控员工（P3.1.1 增跑一轮被误杀商家视角）
- P3 PRD 评估指标 → 准确率 / 召回率 / FTE 替代比例 / 误杀申诉率

## 人工决策点的替代策略（自动化变体核心设计）

| 原人工决策点 | 位置 | 自动化替代 |
|---|---|---|
| 审 P0 精炼 | P0 末尾 | 跳过 |
| 综合两份专家方案 + 写执笔指令 | P1.3 | Claude-2 读两份方案自行综合 |
| 批判取舍（响应 / 忽略） | 2A-fix / 2B-fix / 2D-fix | Claude-2 自行判断，默认"能改则改" |
| 是否回退 | 2C-rollback | Claude-2 自行判断，默认"P2C 指出漂移就回退" |
| P2D 触发条件 | P2D 入口 | 强制触发 |
| 框架内 vs 框架级判定 | 2D-fix | 规则化："强否定 + 实质支撑 → 回 P1"，否则框架内修改 |
| idea.md 锁定 | P2/P3 边界 | 2D-fix 跑完自动锁 |

保留的硬规则：AI 窗口独立（Claude-1~4、DeepSeek-1/2、Qwen-1）、底模坐标跨维度（Claude A1·B1 + DeepSeek A4·B3 + Qwen A3·B3）、单盲零上下文 + prompt 纪律、拆台由 A3/A4 模型扮演。

## 实际执行路径
P0 → P1.1 → P1.2 → P1.3+1.4（合并） → P2A → P2A-fix → P2B → P2B-fix → P2C → P2C-rollback → P2D → **P2D-fix 规则判定触发回 P1** → **实验人工退出** → 在另一个 Cowork 对话里通过 Claude 给前提级调整指令 → Claude-2 续窗口产出 v5

**注意**：v5 不是无人工决策跑出来的。到 P2D-fix 回 P1 判定之后是人工介入产出的——v5 的两条前提级调整（产品重定位为"人工裁决加速器"、废除基于规模的 tier 分流）是在另一个对话里由 Claude 在 prompt 里明确给的方向。

## 结论摘要（详见 meta-observations.md）

1. **v5 作为产品方案质量不错**——定位重写得干净，响应拆台充分，遗留局限说明诚实
2. **v5 里关键的前提级调整不是 AI 自动推出来的**——是人工介入给的方向指令，Claude-2 做的工作是"基于人的综合指令做修改"，本质就是正常方法论里 Claude-2 的角色
3. **P2D-fix 死循环是结构性的**——P2D prompt 预设方向错 + P2D-fix 规则"强否定+实质支撑→回 P1"，两者叠加必然触发回 P1；无自动终止条件
4. **严格的无人工决策在这个方法论下跑不通**——至少 P2D-fix 那个点不可委托；方法论立场三被反向印证，不是被推翻
