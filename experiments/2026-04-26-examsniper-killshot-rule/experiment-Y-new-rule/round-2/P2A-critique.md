# Round 2 · P2A · 投资人批判(实验 Y)

读完了。下面这 7 条,按"杀伤力 × 你说不清"排序。

1. "脉冲式使用 + 不和日活拧巴" 不是商业模式,是 LTV 自戕的话术

第 102 行你写"每学期两次 (期中+期末),天然高复购",再加上第 119 行"接受考期高峰+平时低谷"。算一下:期中很多学校根本没有,文科几乎都只有期末,实际触发 = 一年最多 2 次。¥19.9 周卡 × 2 = 极限 ARPU ¥40。学期套餐 ¥99 是你定的乐观锚,但你给免费层"考点矩阵 Top 5 + 3 道题"的钩子,自然行为是反复白嫖周卡而不是直接上学期套餐。这意味着在抖音/小红书学生侧 CAC 哪怕只有 ¥30-50,你都打不正——而你全文没有一个 CAC 数字、一个 LTV 数字、一个 payback 月数。"接受脉冲"只是把"我没解决留存"翻译成体面话。

2. "课件优先 + 联网补 + 明示来源" 这个真空地带,12 个月前就被填了

第 9-18 行那张表是整篇方案的定位地基,但它把 NotebookLM 钉死在"课件外拒答",把 ChatGPT 钉死在"无溯源"。事实是:NotebookLM 已经支持 Web Sources;豆包学习模式、夸克学习、Kimi、秘塔都做溯源 + 课件 grounding;Doubao/DeepSeek 国内学生场景已经在打"上传 PPT 出考点"。你描述的"真空地带"在 2025 年实际上是红海。整个差异化论证基于一张过时对比表,这是定位级硬伤,不是改一改文案能救的。

3. "学科 × 题型 × 答题模板预置库" 是 PPT 词,不是壁垒

第 80 行你把它列为护城河第一条,第 123 行又拿它兜底"通用模型一个 Prompt 复刻不了"。但全篇没有任何一句话回答:覆盖几个学科?每个学科多少题型?谁来写——校招教研一年 ¥15-25 万,文/社科/医学主流学科盘下来至少 20 人编制,首年人力 ¥400 万级别,而你定价 ¥19.9 周卡。更要命的是:踩分模板这种东西,GPT-4 / Claude / Doubao 让一个学过几年的助教写 prompt + few-shot,3 天能复刻 80% 质量。你说"不是 Prompt 能复刻的",请举一个具体的踩分点是 prompt 复刻不出来的——方案里举不出来,所以这条是信仰陈述,不是壁垒论证。

4. "高频考点 Top 30" 把"课件出现频次"偷换成"考试出现频次"

第 28 行场景 A、第 39 行 P0 第 1 模块,核心交付都是"高频考点预测"。但你的输入只有课件——课件里是知识点频次,不是考试频次。老师讲课的频次 ≠ 老师出题的频次,常常正相反 (基础内容讲得多但考得少,前沿/经典案例讲得少但年年考)。要做真正的考频预测必须有该校该课该老师的真题样本——而单门课每年就 1-2 套真题,样本量根本支撑不了"预测"二字。第 82 行你又说真题数据"为下一届学生的考点预测精度添砖"——可课程换老师、换大纲是高校常态,这个所谓的网络效应在每门课的样本数 < 5 时根本不成立。整个 P0 第一功能在统计意义上是站不住的,你卖的是占卜,不是预测。

5. 合规风险被"营销口径绕开"四个字打发,但版权和学术诚信是产品形态本身的问题,不是文案问题

第 110-112 行风险 2 的应对全是话术——"定位为复习辅助"、"不做摄像头识题"、"营销口径围绕备考效率"。但实际产品形态是:用户上传第三方 PPT (老师享有著作权) → 你的服务器存储 + 用于商业模型训练/检索 → 输出"可直接誊抄的结构化解答"。前半段是直接的著作权法侵权,且是平台主动诱导用户上传——这是 B 站早期视频侵权、网易云盘的同款雷,只是规模更小所以暂时没人告。后半段第 5 行你自己写"可直接誊抄",这五个字就是任何高校学术委员会判定作弊辅助工具的板上钉钉证据。一份头部 985 的内部通报就能让你在小红书的所有 KOL 投放当天熄火。"营销口径"绕不开产品形态本身的定性。

6. 单位经济整篇方案零数字,而它是这门生意能不能存在的前提

19.9 元周卡的目标用户是:7 天内上传 80 页课件 (长上下文 OCR + 切片 + 向量化)、5 套真题全解 (每题结构化输出 5 段含联网检索)、反复变式题生成、自动判分。保守估算单用户 7 天 token 消耗 = 几百万 token 量级,加联网检索 API,单用户推理成本 ¥3-8 起步,重度用户 ¥15+。叠加支付通道 (微信 6%) + 退款 + 客服 + 7 天免费试用拉来的薅羊毛流量,毛利空间被掐死在个位数百分比甚至负数。你全篇没有一个 COGS 数字、没有一个 token 预算、没有一个限频策略——这意味着你要么没算过 (致命),要么算过但不敢写进方案 (更致命)。

7. 用户行为路径假设违反"考前 3 天"用户的真实心理

第 28 行场景 A 是整个产品的灵魂场景:考前 3 天、80 页没看完。但你设计的流程是: 注册 → 付费 → 上传课件 → 等模型处理 → 看考点矩阵 → 再输入题目 → 看结构化答案。这是 6-7 步。临考 3 天的学生真实行为是:截图丢豆包 / DeepSeek,问"这题怎么答",2 步。你的"结构化答案 + 踩分点 + 课件溯源 + 延伸标灰 + 置信度"——对一个考前 3 天的人来说全是噪音,他只想要那个红字答案。你把一个焦虑驱动的冲动消费场景做成了结构化的工具产品体验,这是认知错位。第 129 行你自己评 B 派"要的是分数不是顿悟"——同一句话原封不动适用于你自己的 P0:学生要的是答案,不是矩阵。

最后一句不是建议,是观察:这份方案最危险的不是某一条单点站不住,而是它在"差异化"、"壁垒"、"合规"、"单位经济"四条上用相同的修辞模式回避问题——先承认风险标题,然后用一段话术兜底。投资人读到第三个"风险 X · 应对"的时候就会意识到:这不是风险评估,是免责声明。
