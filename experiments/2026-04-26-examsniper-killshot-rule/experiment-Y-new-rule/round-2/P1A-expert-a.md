# Round 2 · P1.1 · 专家 A · 应试效率派方案(实验 Y)

ExamSniper · 应试效率派产品方案
一、核心定位
ExamSniper 是大学生的"考前 72 小时提分引擎"。

我们不卖"学习"，我们卖"分数"。产品的唯一 KPI 是——让学生在考前最短时间内，把卷面上能拿的分尽可能拿到手。课件是锚点，延伸补全是火力支援，但所有功能最终都要回答同一个问题：这道题怎么写才能拿分？

二、目标用户与典型场景
目标用户：临近期末、面对几十页课件 + 历年真题、时间已经不够系统复习的大学生。尤其是文科类、社科类、医学类、工科原理类等"靠背 + 靠套路"得分的科目。

典型场景：

场景 A · 临阵磨枪：考前 3 天，课件 80 页没看完，真题 5 套没刷。打开 ExamSniper，上传课件，直接输出"本科目高频考点 Top 30 + 每个考点的标准答题模板"。
场景 B · 真题速通：拿到一套历年真题，逐题输入，产品直接给出"踩分点拆解 + 标准答案 + 老师可能改的变式"。
场景 C · 考前夜审：考前一晚，用"考点闪卡 + 模拟自测 + 自动判分"做最后一轮过筛，定位还没记住的考点。
三、核心功能模块与优先级
P0 · 必须有，决定产品能不能卖
1. 考点雷达（课件 → 考点矩阵）
上传课件，自动输出考点-题型矩阵：每个考点标注预测题型（名词解释 / 简答 / 论述 / 计算 / 选择）、预测分值权重、考频等级（高频 / 中频 / 低频）。学生一眼看到"哪些必考、哪些可放弃"。

2. 解题狙击（题目 → 结构化答案）
输入考题，输出固定结构：【踩分点清单】→【标准答题模板】→【完整答案示范】→【课件出处溯源】→【延伸补全标注】。延伸内容明确标灰区分，让学生知道哪些是课件原文、哪些是模型补的"老师可能想要的额外得分点"。

3. 答题模板库
按学科 × 题型预置标准答题套路（如"论述题三段式"、"简答题踩分点结构"、"计算题步骤分模板"）。每道题的输出都套用对应模板，学生抄上去就是阅卷老师想看到的样子。

P1 · 拉开差距，决定产品能不能赢
4. 真题闪击包
上传历年真题，自动输出"全卷解析 + 踩分点拆解 + 高频考点反向标注（这道题对应课件第几页）"。一套真题 5 分钟出全解。

5. 变式题生成器
针对每个高频考点，自动生成 3-5 道老师可能换皮出的变式题，附标准答案。这是"延伸补全"的主战场——不是延伸知识，是延伸题目。

6. 自测判分
学生写完答案后，系统按踩分点逐条判分，给出"得分 / 失分 / 失分原因 / 如何补救"。模拟阅卷老师视角。

P2 · 锦上添花
7. 考点闪卡：高频考点自动转艾宾浩斯节奏的速记卡。
8. 提分预测：根据已掌握考点 × 考频权重，预测当前能拿多少分，距离及格 / 优秀还差哪几个考点。

六、关键风险与应对
风险 1 · 课件覆盖不全，延伸答案出错被学生写上卷面丢分
应对：所有延伸内容强制标灰 + 标注"延伸补全"标签 + 给出置信度；同时在答题模板里把"课件原文得分点"放在最前，"延伸得分点"放在末尾——保证学生即使只抄前半段也能拿基础分。

风险 2 · 学校 / 老师认定为作弊工具
应对：产品定位明确为**"考前复习辅助"而非"考场实时作弊"**，不做手机端考场快速识题、不做摄像头识题。营销口径全部围绕"备考效率"，规避监管敏感点。

风险 3 · 学科覆盖不均，理工类计算题、证明题输出质量差
应对：第一阶段集中打文科 / 社科 / 医学背诵类科目——这是答题模板化收益最大、产品体验最稳的战场。理工硬核计算题 P2 阶段再啃，不在主战线分散火力。

风险 4 · 学生只在考前一周用，留存差
应对：不强求日活，接受"考期高峰 + 平时低谷"的脉冲式使用形态。商业模式直接按考期订阅设计，不和留存指标拧巴。考期结束自动到期，下学期再激活。

风险 5 · 通用大模型 + 一个 Prompt 就能复刻
应对：壁垒不在模型，在于学科 × 题型 × 答题模板的结构化资产——预置答题模板库、踩分点判分规则、变式题生成逻辑、真题数据沉淀。这些是工程 + 教研活，不是 Prompt 能替代的。

总结：ExamSniper 不做"更好的学习工具"，做"更狠的提分工具"。课件是锚，模板是枪，考点是靶——上传课件、输入题目、抄上答案、拿到分数。这就是全部产品逻辑。
