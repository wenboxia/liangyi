# ExamSniper · 大学生 AI 考点狙击手 — 产品方案 v1

## 一、核心定位

ExamSniper 是大学生的**考前提分搭子**：上传课件即自动提取考点、输入考题即给出可直接誊抄的结构化解答。

产品的唯一交付承诺是——在考前有限的时间里，把卷面上能拿的分尽可能拿到手。课件是锚点，模型与联网检索是火力支援，所有功能最终都回答同一个问题：**这道题怎么写才能拿分？**

产品定位卡在 NotebookLM 与通用 ChatGPT 中间的真空地带：

| 维度 | NotebookLM | ChatGPT | ExamSniper |
|------|-----------|---------|-----------|
| 知识边界 | 严格 Grounding，课件外拒答 | 自由发挥，无溯源 | 课件优先召回，不足以模型与联网补全，并明示来源 |
| 输出形态 | 通用问答 | 通用问答 | 结构化踩分答案 + 答题模板 |
| 核心交付 | 文档摘要 | 对话回答 | 考点矩阵、真题全解、变式题、自动判分 |
| 用户心智 | 读书助手 | 万能助手 | 考前提分搭子 |

一句话：NotebookLM 让你"读懂课件"，ChatGPT 让你"获得回答"，ExamSniper 让你"在卷面上拿分"。

---

## 二、目标用户与典型场景

**目标用户**：临近期中 / 期末考试、面对几十页课件 + 数套历年真题、复习时间已经吃紧的大学生。优先覆盖文科、社科、医学、工科原理类等"靠理解 + 靠模板 + 靠记忆"得分的科目。

**典型场景**

- **场景 A · 临阵磨枪**：考前 3 天，课件 80 页没看完，真题 5 套没刷。上传课件，直接获得"本科目高频考点 Top 30 + 每个考点的标准答题模板 + 课件页码溯源"。
- **场景 B · 真题速通**：拿到一套历年真题，逐题输入，产品给出"踩分点拆解 + 标准答案 + 老师可能改的变式"。
- **场景 C · 考前夜审**：考前一晚，用"考点闪卡 + 自测判分"做最后一轮过筛，定位还没记牢的考点。

## 三、核心功能模块及优先级

### P0 — 必须有，决定产品能不能卖

**1. 考点雷达（课件 → 考点矩阵）**
上传课件，自动输出考点-题型矩阵：每个考点标注预测题型（名词解释 / 简答 / 论述 / 计算 / 选择）、预测分值权重、考频等级（高频 / 中频 / 低频）、对应课件页码。学生一眼看到"哪些必考、哪些可放弃"。

**2. 解题狙击（题目 → 结构化答案）**
输入考题，输出固定结构：
- 【踩分点清单】
- 【标准答题模板】
- 【完整答案示范】
- 【课件出处溯源】（精确到页与段）
- 【延伸补全标注】（明确标灰区分哪些是模型 / 联网补的"可能多得分的延伸点"，并附置信度）

**关键约束**：课件原文得分点必须排在前面，延伸得分点排在末尾——保证学生即使只抄前半段也能拿基础分。

**3. 答题模板库**
按学科 × 题型预置标准答题套路（如"论述题三段式"、"简答题踩分点结构"、"计算题步骤分模板"）。每道题的输出都套用对应模板，使学生抄上去就是阅卷老师想看到的样式。

### P1 — 拉开差距，决定产品能不能赢

**4. 真题闪击包**
上传历年真题，自动输出"全卷解析 + 踩分点拆解 + 高频考点反向标注（这道题对应课件第几页）"。一套真题 5 分钟出全解。

**5. 变式题生成器**
针对每个高频考点，自动生成 3-5 道老师可能换皮出的变式题，附标准答案。这是"延伸补全"的主战场——延伸的是题目，不是漫无边界的知识。

**6. 自测判分**
学生写完答案后，系统按踩分点逐条判分，给出"得分 / 失分 / 失分原因 / 如何补救"，模拟阅卷老师视角。

**7. 易错点诊断（轻量化）**
针对学生反复答错的考点，系统在解析中插入"常见混淆提示"，简短指出 90% 学生在此处的典型错法。**只提示不发问、不阻塞答案输出**——目的是让学生记牢，而不是让学生再花一小时思考。

### P2 — 锦上添花

**8. 考点闪卡**：高频考点自动转为艾宾浩斯节奏的速记卡。
**9. 提分预测**：根据已掌握考点 × 考频权重，预测当前能拿多少分，距离及格 / 优秀还差哪几个考点。
**10. 跨章节考点关联图**：在同一门课中将相关考点串成依赖图，便于宏观复习时快速定位薄弱链。

## 四、产品差异化

ExamSniper 的核心壁垒不在模型，而在以下三层结构化资产：

1. **学科 × 题型 × 答题模板的预置库**：每个学科、每种题型对应的踩分点与答题骨架，由教研沉淀而成，不是 Prompt 能复刻的。
2. **课件优先召回 + 延伸明示的双层引用机制**：让学生既拿到课件外的得分点，又能清楚知道"哪一句不是老师讲过的"，把"AI 误导上卷"的风险压到最低。这一点是相对 ChatGPT 的核心防御，也是相对 NotebookLM 的核心进攻。
3. **真题 + 变式题数据沉淀**：用户每上传一份真题、每完成一次自测，都在为下一届学生的考点预测精度添砖。这是冷启动后逐步加厚的网络效应。

## 五、商业模式

**主线：考期订阅制**

- **狙击周卡 ¥19.9 / 7 天**：覆盖单科考前一周冲刺。主力 SKU。
- **狙击月卡 ¥39.9 / 30 天**：覆盖整个期末考期。次主力。
- **学期套餐 ¥99 / 学期**：包含期中 + 期末两轮考期。

**增值：高价值单点付费**

- **真题闪击包 ¥9.9 / 套**：单科历年真题一键全解。
- **考前急救包 ¥29.9**：考前 24 小时，针对单科生成"必背考点 Top 20 + 万能答题模板 + 提分预测"。

**免费层只给钩子**：上传课件可免费看考点矩阵 Top 5、免费解 3 道题。看完整考点榜、解更多题、生成变式题、自动判分——付费。

**复购逻辑**：期末本身就是周期性事件，每学期两次（期中 + 期末），天然高复购。商业模式直接按考期脉冲设计，不和日活留存指标拧巴。

## 六、关键风险与应对

**风险 1 · 延伸答案出错被学生写上卷面丢分**
应对：所有延伸内容强制标灰 + "延伸补全"标签 + 置信度评分；课件原文得分点放在答案前段，延伸得分点放在末尾；置信度过低时直接坦白"此处课件未覆盖、模型不确定，建议跳过"，宁可少答，不出幻觉。

**风险 2 · 学校 / 老师认定为作弊工具**
产品定位明确为**"考前复习辅助"**而非"考场实时作弊"。不做手机端考场快速识题、不做摄像头识题。营销口径全部围绕"备考效率"，规避监管敏感点。

**风险 3 · 学科覆盖不均，理工类计算题、证明题输出质量差**
第一阶段集中打文科 / 社科 / 医学等模板化收益最大的科目，理工硬核计算题留到 P2 再啃，不在主战线分散火力。

**风险 4 · 课件质量差、锚点失效**
当课件锚点置信度低于阈值时，产品坦白告知："本节课件推导跳跃过大，无法可靠提取考点，建议先自行阅读教材或上传补充资料。" 宁可承认无能，也不用幻觉内容充当答案地基。这是对"延伸补全"机制的兜底。

**风险 5 · 学生只在考前一周用，留存差**
不强求日活，接受"考期高峰 + 平时低谷"的脉冲式使用形态。订阅制按考期到期，下学期再激活。

**风险 6 · 通用大模型 + 一个 Prompt 就能复刻**
壁垒不在模型，在学科 × 题型 × 答题模板的结构化资产、踩分点判分规则、变式题生成逻辑、真题数据沉淀。这些是教研 + 工程的长期活，不是一句 Prompt 能替代的。

## 自动综合日志

**判断过程**：两派的根本张力是"给不给答案"。B 派坚持苏格拉底式追问、拒绝喂答案，立场漂亮但与目标场景严重错配——P0 描述明确指向"几十页课件 + 历年真题 + 时间不够"的临考用户，这群人要的是分数，不是顿悟；要求他们在考前 3 天回头读书并完成三层追问，等于把绝大多数自然流量推向 ChatGPT。A 派的"考期订阅 + 模板化输出"匹配真实用户行为路径与付费意愿，PMF 显著更强。

**最终立场**：以 A（应试效率派）为主。**不选 B 为主**的原因是：B 的"拒绝给答案"在商业上等同于自我筛掉 95% 的潜在用户，且其留存假设（"学生会因为知识敬畏感而留下"）在期末压力场景下缺乏行为支撑。

**从 B 吸收的点**：(1) 课件锚点置信度兜底——锚不稳时坦白拒答，作为对 A 派"延伸出错"风险的强化兜底；(2) "易错点诊断"以轻量化、不阻塞的形式保留，让产品在拿分之外仍能沉淀一点理解价值；(3) 概念依赖图思路下放到 P2 的"跨章节考点关联图"，作为锦上添花。

**放弃的点**：苏格拉底式追问引擎、反答案审查模型、对话冻结机制、"拒绝考点预测报告"的商业洁癖、把"回溯课件次数"作为留存指标——这些与"考前提分搭子"心智正面冲突，全部砍掉。
