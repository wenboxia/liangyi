# ExamSniper · 大学生 AI 考点狙击手 — 产品方案 v4

> **关于本文档的读者**：第一至四节面向所有读者；第五节"经营内部"小节为团队与投资人参考，学生读者可跳过 5.3-5.5。

---

## 一、核心定位

ExamSniper 是大学生的**考前提分搭子**。

产品骨架：**以课件为锚 → 自动提取本课重点 → 围绕重点解题、变式、自测**。课件不是修饰，是产品的中心——所有功能都建立在"这门课的课件被深度解析过"这件事之上。

核心机制：**课件优先召回，课件不足时以模型学科知识与联网检索补全，并明示来源与置信度**。延伸内容必须能挂靠在课件的某个章节上，不做无锚的自由发挥。

我们卖的是**单题被解到能拿分的程度** + **整门课的复习能被结构化导航**。两者都依赖课件这个锚——只有把这门课的课件吃透，输出才能像"这位老师想看到的样子"。

## 二、什么是"评分员视角的解答"

直接看示例。

**题目**：分析在流动性陷阱下增加政府支出的挤出效应。

**ExamSniper 的输出**（已上传《宏观经济学》课件）：

> **① 评分员会扣分的地方**（踩分点 = 评分标准里的得分要点）
> - 没有定义"流动性陷阱"和"挤出效应" — 扣 2 分
> - 没有结合 IS-LM 图分析机制 — 扣 3 分
> - 没点明"挤出效应近似为零" — 扣 2 分
> - 没有讨论价格弹性这一隐含假设 — 扣 1 分
>
> **② 答题结构**（这种论述题的标准骨架）
> 1. 定义两个核心概念
> 2. 用 IS-LM 模型说明传导机制
> 3. 给出结论 + 一个反直觉点
>
> **③ 完整解答示范**
> [约 250 字解答正文 — 建议改写为自己的表达后誊抄]
>
> **④ 易错警示**
> 90% 的同学会把"挤出效应为零"等同于"财政政策完全有效"。要注意：放松价格固定的假设后结论可能反转。
>
> **⑤ 课件出处**
> 引自本课课件第 14 页 LM 曲线推导、第 22 页流动性陷阱定义。
>
> **⑥ 延伸补全**（标灰，置信度中）
> 课件未展开"利率走廊下限"，但近年同类高校真题涉及，建议补充阅读。

输出的前五段全部锚定课件；第六段是延伸补全，明确标灰、注明置信度——学生可以自行决定是否采用。这是 NotebookLM 不肯做（出了课件就拒答）、ChatGPT 做不好（无法标注哪句来自课件）的中间地带。

## 三、目标用户与典型场景

**目标用户**：临近期中 / 期末、面对几十页课件 + 数套真题、复习时间已经吃紧的大学生。优先文科 / 社科 / 医学 / 工科原理类等"靠理解 + 靠结构 + 靠记忆"得分的科目。

**主入口场景 · 上传课件，进入本课工作区**
打开 App，上传本课课件（PDF / PPT / 图片），1-2 分钟解析完成后进入"本课工作区"。工作区里有三件事可以做：看本课重点导航、问任意题、过历年真题。

**场景 A · 临阵磨枪**
考前 3 天，课件 80 页没看完。上传课件后，看"重点导航"快速判断哪些章节投入产出比高，再用拍题功能解决具体题目。

**场景 B · 真题速通**
拿一份历年真题逐题问，每道题的解答都引用课件页码、复用老师讲过的术语和推导步骤。

**场景 C · 考前夜审**
用闪卡 + 自测判分做最后一轮过筛。

**轻量入口 · 不传课件直接拍题**
对于没时间上传课件的极临考用户，也支持直接拍题——但输出不引用课件页码、不对齐特定老师的术语，相当于"通用解题模式"。我们诚实告知用户："上传课件后此题输出会更准。"这是一个降级体验，不是主推路径。

## 四、核心功能模块及优先级

### P0 — 决定产品能不能跑起来

**1. 课件深度解析与本课重点导航**
上传课件后输出本课工作区，包含：
- **章节地图**：自动切分课件章节，标注每章页数与核心概念
- **重点导航**：基于课件本身的章节篇幅、概念依赖关系，加上同类高校该课程的公开真题题型分布，输出"建议优先复习的章节"
- **题型预判**：每个章节标注可能出现的题型（名词解释 / 简答 / 论述 / 计算 / 选择），但**不承诺押题**，明确说明这是"该类型概念在同类课程里常见的考查方式"

**关于"不卖预测"的边界**：我们告诉你"流动性陷阱在同类课程的论述题里反复出现，建议重点复习"，不告诉你"明天卷子第 3 题会考流动性陷阱"。前者是统计描述，后者是占卜，我们只做前者。

**2. 解题狙击（拍题 / 输入题目）**
输入考题，输出第二节示例的六段结构：踩分点 → 答题结构 → 完整解答示范 → 易错警示 → 课件出处 → 延伸补全（标灰 + 置信度）。

**关键约束**：课件原文得分点必须排在前面，延伸补全排在末尾，置信度过低时直接坦白拒答——保证学生即使只采用前段也能拿基础分。

**3. 答题模板库**
按学科 × 题型预置标准答题骨架（论述题三段式、简答题踩分点结构、计算题步骤分模板）。每道题输出都套用对应模板，学生改写后誊抄即是阅卷老师想看到的样式。

### P1 — 拉开差距

**4. 真题包**
上传整份真题（一份 = 一张完整试卷），分题出全解 + 反向标注课件页码（即从答案出发查找课件中讲过的位置）+ 自测判分。¥9.9 / 份。

**5. 变式题生成器**
针对每个核心考点生成 3-5 道变式题（变式 = 换数字、换场景、换提问角度，但考的是同一个知识点），附解答。

**6. 自测判分**
学生写完答案后按踩分点逐条判分，给出失分原因与补救建议。

**7. 易错点诊断（轻量化）**
针对学生反复答错的考点，在解析中插入"常见混淆提示"，简短指出 90% 学生在此处的典型错法。**只提示不发问、不阻塞答案输出**。

### P2 — 锦上添花

**8. 考点闪卡**：核心考点转艾宾浩斯节奏速记卡。
**9. 跨章节关联图**：同课内相关考点串成依赖图。
**10. 教师端**：向合作高校老师开放学生卡点匿名报告，作为合规背书与教研增值入口。

## 五、产品差异化与商业模式

### 5.1 差异化

ExamSniper 的差异化建立在三层：

1. **课件锚定 + 延伸明示的双层引用机制**
   通用模型（ChatGPT / Doubao / Kimi）能做课件 grounding，但它们做的是"问答型 grounding"——回答你的问题时引用课件。ExamSniper 做的是**"考试场景的课件应用"**：把课件解析为章节地图 + 重点导航 + 题型预判 + 解题模板的组合产品，并保证每道题的解答前段必须命中课件、延伸补全必须标灰且可关闭。这是一个面向考试形态的工程组合，不是"也支持上传课件"的通用助手能直接对位的。

2. **评分员视角的输出格式**
   竞品给的是"知识点解释段落"，我们给的是"踩分点 + 答题骨架 + 易错警示"。第一题对比就能感知。诚实承认：让一个有几年助教经验的人写 prompt + few-shot，3 天能复刻 80% 质量——所以这一条单独不构成壁垒，它的价值在与上一条 + 下一条组合。

3. **校级数据沉淀**
   按学校 × 课程 × 老师颗粒度沉淀本校学长上传过的真题与答题样本。**冷启动期间**（学校 / 课程未覆盖时），系统使用同类高校公开真题语料兜底，并在解答顶部明确告知"本课暂未沉淀本校数据，输出基于通用题型库"——避免用户付了钱不知道差在哪。

### 5.2 SKU 与付费规则

**主线：考期订阅制**

| SKU | 价格 | 配额 | 课件锚定 | 适用场景 |
|-----|------|------|---------|---------|
| 免费层 | ¥0 | 5 题 / 天 | 课件可上传但解答不引用页码 | 试用 |
| 狙击周卡 | ¥19.9 | 200 题 / 7 天，每日上限 50 | ✅ | 单科考前一周 |
| 学期套餐 | ¥69 | 90 天，每日上限 30 | ✅ | 整个考期多门课，**主推 SKU** |

**增值：单点付费**

| SKU | 价格 | 说明 |
|-----|------|------|
| 真题包 | ¥9.9 / 份 | 单份完整真题全解 |
| 解题包 | ¥9.9 | 50 题 / 30 天，适合只剩 3 天考试不想买周卡的用户 |
| 补题包 | ¥4.9 | 10 题，当日有效，超出每日上限时使用 |

**几个边界规则**：
- 5 题免费按设备 + 账号双重计数
- 数据隔离：每个用户上传的课件仅自己可见，不与其他用户混用，不进入模型训练集，可一键删除
- 免费用户上传课件可看章节地图与重点导航的前 30%，但解题输出不引用页码（这是付费转化的核心钩子）
- 答案缓存基于语义匹配（题干高度相似 + 同一学科），用户感受不到差异

**复购逻辑**：期末是周期性事件，目标 1.2-1.5 次 / 年，靠学期套餐拉高 ARPU。

### 5.3 经营内部 · 单位经济

单题成本拆解：
- 输入 ~3K token，输出 ~1.5K token
- **模型分层**：约 80% 题量用快速廉价模型（~¥0.02 / 题），约 20% 复杂题用旗舰模型（~¥0.15 / 题），加权约 **¥0.05 / 题**
- 单份课件预处理（OCR + 切片 + 向量化）一次性约 ¥0.3，对该用户后续题目可复用
- 联网检索仅在课件命中失败时触发（约 30% 题目），约 ¥0.02 / 次

毛利测算：

| 用户类型 | 收入 | 通道扣费 | 推理成本 | 毛利率 |
|---------|------|---------|---------|------|
| 周卡 · 平均（80 题 + 1 课件） | ¥19.9 | ¥1.2 | ¥4.3 | ~72% |
| 周卡 · 重度（200 题封顶 + 1 课件） | ¥19.9 | ¥1.2 | ¥10.3 | ~42% |
| 学期套餐 · 平均（150 题 + 2 课件） | ¥69 | ¥4.1 | ¥8.1 | ~83% |

封顶 + 模型分层 + 课件向量复用 + 答案缓存四件套是毛利安全的关键。

### 5.4 经营内部 · CAC / LTV

- CAC 目标 ¥30-50
- 复购预期 1.2-1.5 次 / 年（承认相当一部分文科课只有期末）
- 目标年 LTV ¥50-80
- Payback ≤ 1 个考期

### 5.5 经营内部 · 早期渠道

校园渠道为冷启动主战场——学长学姐分销返佣（10-15%）、专业群裂变。投放仅在小规模可控场景做单元测试。前 6-12 个月没有结构性壁垒，靠数据沉淀速度跑赢通用工具。

## 六、关键风险与应对

**风险 1 · 延伸答案出错被学生写上卷面丢分**
应对：所有延伸内容强制标灰 + "延伸补全"标签 + 置信度评分；课件原文得分点放在答案前段，延伸得分点放在末尾；置信度过低时直接坦白"此处课件未覆盖、模型不确定，建议跳过"。

**风险 2 · 版权与学术诚信**
产品形态层面（不靠营销话术绕）：
- 用户上传内容默认仅自用、用户间完全隔离、不进入训练集、随时一键删除——写入用户协议首段
- 解答示范段加显著提示："建议改写为自己的表达"
  - **改写边界**：核心论点与得分要点可保留（这些是知识本身），但句式、连接词、举例应替换为自己的语言。直接 100% 复制粘贴有学术诚信风险，自行改写后写入卷面属于正常复习成果
- 启动页与每次解答底部标注"复习辅助工具，禁止考场使用"
- 提供 DMCA 投诉通道，上传协议明确版权责任由用户承担
- 远期教师端（P2）作为主动合规姿态——把"对抗性工具"叙事翻转为"教研辅助平台"

诚实承认：这是行业灰色地带，靠"主动合作 + 用户协议 + 输出措辞"把法律和声誉风险压到行业平均水平以下。

**风险 3 · 学校 / 老师认定为作弊工具**
产品定位明确为"考前复习辅助"而非"考场实时作弊"。不做手机端考场快速识题、不做摄像头识题。营销内容做敏感词审查，不投放任何含"答案 / 作弊 / 代写"的素材。准备 24 小时内可执行的通报响应预案。

**风险 4 · 学科覆盖不均，理工类计算题输出质量差**
第一阶段集中打文科 / 社科 / 医学等模板化收益最大的科目，理工硬核计算题留到 P2。

**风险 5 · 课件质量差、锚点失效**
课件锚点置信度低于阈值时，产品坦白告知："本节课件推导跳跃过大，无法可靠提取重点，建议先自行阅读教材或上传补充资料。" 宁可承认无能，不用幻觉内容充当答案地基。

**风险 6 · 单位经济崩盘**
应对：见 5.3。封顶、模型分层、课件向量复用、答案缓存四件套缺一不可。

**风险 7 · 通用大模型 + 一个 Prompt 就能复刻**
壁垒不在模型，在课件锚定的工程组合 + 校级数据沉淀。承认输出格式 80% 可被 prompt 复刻，所以护城河押在"课件锚定的考试形态产品组合"和"校级数据飞轮速度"上。窗口预估 6-12 个月——必须在此期间完成至少 30 所目标高校的真题数据沉淀。

**对学生的承诺**：购买学期套餐期间，本校数据始终未覆盖、且体验未达预期，可在套餐到期前申请按未使用天数比例退款。

**风险 8 · 学生只在考前一周用，留存差**
不强求日活，接受"考期高峰 + 平时低谷"的脉冲式使用形态。学期套餐按考期到期，下学期再激活。

## P2C 回退日志

**承认漂移**。v1→v3 在响应 P2A 投资人和 P2B 单盲读者过程中，把 v1"以课件统摄考点"的产品骨架累积抽掉了。每条响应单看合理，累积起来产品品类已迁移。v4 朝 v1 方向部分回退。

**回退项**：
- 副标题："AI 解题搭子" → **"AI 考点狙击手"**
- 核心定位首句：课件从"增强项"恢复为**"产品的中心 / 锚"**
- P0 第 1 项：v3 的"拍题狙击"降为 P0 第 2 项；**"课件深度解析与本课重点导航"恢复为 P0 第 1 项**（合并 v1 考点雷达精神 + v3 诚实的"重点解析"语言）
- 主入口场景：从"打开 App → 拍题"恢复为**"上传课件 → 进入本课工作区"**；不传课件拍题降为"轻量入口 / 降级体验"
- 差异化第 1 条：从"评分员视角"恢复为**"课件锚定 + 延伸明示的双层引用机制"**，并明确这是"考试场景的课件应用"而非泛化"也支持课件"
- SKU 主推：从"解题包 / 周卡"恢复为**"学期套餐"**为主推；解题包 / 补题包降为增值
- 答题模板库：恢复为 P0 第 3 项（v3 中已淡化）
- 第二节示例：补充第六段"延伸补全（标灰 + 置信度）"，恢复 v1 的双层引用机制可视化

**保留 v3 的合理修复**（不回退）：
- 删除 v1 的"可直接誊抄"等措辞（合规底线）
- 删除 v1 的"高频考点 Top 30 / 押题 / 预测"占卜措辞（统计学诚实）
- 删除过时三方对比表（红海事实）
- 保留单位经济、SKU 边界规则、术语注释、样例输出、改写指引、退款承诺、冷启动兜底、读者说明

**未回退理由**：v1 的考点占卜叙事和误导誊抄措辞是真问题，回退会触发新一轮 P2A / P2B 批判。v4 = v1 的产品骨架 + v3 的运营诚实。
