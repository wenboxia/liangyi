# ExamSniper · 大学生 AI 解题搭子 — 产品方案 v2

## 一、核心定位

ExamSniper 是大学生的**拍题解题搭子**：拍一道题，2 步拿到"评分员视角"的结构化解答。可选上传课件后，解答会贴合本课老师的术语、推导链与重点章节。

我们不卖"考点预测"——课件里只有讲课频次、没有出题频次，预测两个字不诚实。我们卖的是**单题被解到能拿分的程度**：踩分点拆开、答题结构铺好、易错点点出来。

---

## 二、目标用户与典型场景

**目标用户**：考前 3-14 天、面对几十页课件 + 数套真题、时间已经吃紧的大学生。优先文科 / 社科 / 医学 / 工科原理类等"靠理解 + 靠结构 + 靠记忆"得分的科目。

**主入口场景 · 拍题速答**
考前 3 天，学生掏出手机拍一道历年真题，10 秒内得到：踩分点清单 → 答题结构 → 完整解答示范 → 易错警示。从启动到看到答案 = 2 步。

**增强场景 · 课件锚定**（订阅用户）
学生上传本课课件后，再次问题时，答案自动引用课件页码、对齐课件术语与记号、复用老师的推导路径。同一道题对没传课件 vs 传了课件的用户，输出有可见差异。

**深度场景 · 真题练手**
上传整套历年真题，分题出解答 + 自测判分 + 变式预演。

## 三、核心功能模块及优先级

### P0 — 决定产品能不能跑起来

**1. 拍题狙击（主入口）**
截图 / 拍照 / 输入题目 → 输出固定 4 段结构：
- **踩分点清单**（评分员会看哪几条）
- **答题结构**（这种题型的标准骨架）
- **完整解答示范**（学生需在此基础上改写为自己的表达）
- **易错警示**（90% 学生在此处的典型错法）

**关键约束**：从打开 App 到看到答案 ≤ 2 步。课件 / 注册 / 付费墙都不挡在这条路径上（前 5 题 / 天免费）。

**2. 课件锚定增强**
上传课件后，解题输出自动引用课件页码、对齐术语；联网或模型补全的内容明确以"课件未覆盖"标注，并按置信度排序：高置信延伸放上方，低置信内容坦白拒答。课件不上传也可用，上传后是可见的体验跃迁——这是订阅转化的核心钩子。

**3. 付费墙与限频**
- 免费：5 题 / 天，无课件锚定
- 付费用户：按 SKU 配额（见第五节）
- 所有套餐均带每日上限——不卖"无限"，守毛利下限

### P1 — 拉开差距

**4. 真题包**
上传整套真题，分题出全解 + 反向标注课件页码 + 自测判分。

**5. 变式题生成器**
针对每个核心考点生成 3-5 道老师可能换皮出的变式题，附解答。

**6. 自测判分**
学生写完答案后，按踩分点逐条判分，给出失分原因与补救建议。

**7. 重点解析**（替代过时的"高频考点 Top 30"）
基于课件重要性信号 + 同类高校公开真题语料，输出"建议优先复习的章节与考点"。**明确不承诺押题、不使用"高频"措辞**——它是结构化的复习导航，不是占卜。

### P2 — 长期生态

**8. 考点闪卡**：核心知识点转艾宾浩斯节奏速记卡。
**9. 跨章节关联图**：同课内相关考点串成依赖图，用于宏观复习。
**10. 教师端（远期）**：向合作高校老师开放"学生卡点热力图"匿名报告，作为合规背书与教研增值入口。

## 四、产品差异化

NotebookLM / 豆包学习模式 / 夸克 / Kimi 在 2025 年都已支持课件 grounding + 联网溯源——"课件优先召回 + 联网补全 + 标注来源"已是行业基础设施，不是差异化。ExamSniper 的差异化重新建立在三层：

1. **评分员视角的输出格式**
   不输出"知识点解释"，而输出"评分员会扣分的地方 + 标准答题结构 + 完整解答示范"。这是教研沉淀。诚实承认：让一个有几年助教经验的人写 prompt + few-shot，3 天能复刻 80% 质量——所以这一条单独不构成壁垒，它的价值在与下两条组合。

2. **校级数据飞轮**
   按学校 × 课程 × 老师颗粒度沉淀真题 / 学长笔记 / 答题样本。颗粒度越细，输出越像"该校该老师想看到的样子"。这是 NotebookLM / 豆包等通用工具因数据隔离与场景泛化而做不到的——也是 ExamSniper 6-12 个月内唯一可能的结构性护城河。

3. **极短路径触达**
   主入口对标 ChatGPT 拍题体验（2 步），不是 NotebookLM 的"先组建 notebook 再问"（6+ 步）。结构化输出在后台默认开启，前台对学生只呈现"那个红字答案"。

## 五、商业模式与单位经济

### 5.1 SKU 设计

| SKU | 价格 | 配额 | 课件锚定 |
|-----|------|------|---------|
| 免费层 | ¥0 | 5 题 / 天 | 否 |
| 解题包 | ¥9.9 | 50 题 / 30 天 | 是 |
| 狙击周卡 | ¥19.9 | 200 题 / 7 天，每日上限 50 | 是 |
| 学期套餐 | ¥69 | 90 天，每日上限 30 | 是 |
| 真题包 | ¥9.9 / 套 | 单套真题全解 | 是 |

**取消之前的 ¥99 学期套餐**——锚定过高、转化阻力大。¥69 对标"一本教辅"，进入心理账户更容易。

### 5.2 单题成本拆解

- 输入 ~3K token（题目 + 检索片段），输出 ~1.5K token
- **模型分层**：Haiku 4.5 处理 80% 题量（~¥0.02 / 题），Sonnet 4.6 处理 20% 复杂题（~¥0.15 / 题），加权约 **¥0.05 / 题**
- **课件预处理**：单份课件 OCR + 切片 + embedding 一次性 ~¥0.3，对该用户后续题目复用
- **联网检索**：仅在课件命中失败时触发（约 30% 题目），~¥0.02 / 次
- **缓存层**：同校 / 同课的相同题目首次解算后写入答案缓存，命中率预估 15-25%，进一步压成本

### 5.3 毛利测算

| 用户类型 | 收入 | 通道扣费 | 推理成本 | 毛利 |
|---------|------|---------|---------|------|
| 周卡 · 平均（80 题 + 1 课件） | ¥19.9 | ¥1.2 | ¥4.3 | ~72% |
| 周卡 · 重度（200 题封顶 + 1 课件） | ¥19.9 | ¥1.2 | ¥10.3 | ~42% |
| 学期套餐 · 平均（150 题 + 2 课件） | ¥69 | ¥4.1 | ¥8.1 | ~83% |

**封顶 + 模型分层 + 课件向量复用 + 答案缓存**是毛利安全的四件套。任意一项失守，重度用户毛利会跌入个位数，必须监控。

### 5.4 CAC / LTV / Payback

- 假设 CAC（小红书 / 抖音学生侧）¥30-50
- **下调复购预期**：承认期中很多文科课没有，从"2 次 / 年"下调到 **1.2-1.5 次 / 年**
- 目标 LTV：单年 ¥50-80（解题包 + 周卡组合，少数转学期套餐）
- Payback ≤ 1 个考期；考期外不做付费投放，仅靠学长学姐分销维持获客

### 5.5 渠道：早期不靠投放

校园渠道是冷启动主战场——学长学姐分销返佣（10-15%）、学生会代理、考期前 2 周专业群裂变。投放只在数据可控的小渠道做单元测试，不做大规模买量。承认前 6 个月没有结构性壁垒，靠渠道速度跑赢同类工具。

## 六、关键风险与应对

**风险 1 · 已是红海，差异化窗口短**
应对：放弃"课件溯源"作为差异化叙事，靠"评分员输出 + 校级数据飞轮 + 极短路径"组合突围。窗口预估 6-12 个月——必须在此期间完成至少 30 所目标高校的真题 / 笔记数据沉淀，否则差异化会被通用工具抹平。这是一道明确的死线，不是话术。

**风险 2 · 版权与学术诚信**
产品形态层面的调整（不靠营销口径绕）：
- 用户上传内容**默认仅自用、不进入训练集、随时一键删除**，写入用户协议首段
- 输出措辞中**移除"可直接誊抄"等表达**；解答示范段加显著提示"建议改写为自己的表达"
- 启动页与每次解答底部显著标注"复习辅助工具，禁止考场使用"
- 提供 DMCA / 著作权投诉通道，上传协议明确版权责任由用户承担
- 远期教师端（P2）作为主动合规姿态：让老师能看到自己课程的学生卡点报告，把"对抗性工具"叙事翻转为"教研辅助平台"

诚实承认：这是行业灰色地带（NotebookLM / 夸克 / 豆包都在同一条线上），ExamSniper 不靠规避走出灰色，靠"主动合作 + 用户协议 + 输出措辞"把法律和声誉风险压到行业平均水平以下。

**风险 3 · 单位经济崩盘**
应对：见 5.2-5.3。封顶、模型分层、课件向量复用、答案缓存四件套缺一不可。每月监控重度用户毛利，跌破 30% 即调整配额或迁移更多请求至 Haiku。

**风险 4 · 模板被通用模型 prompt 复刻**
承认 80% 可被复刻，所以不押模板。押校级数据沉淀的速度——同校同课同老师颗粒度的真题与答题样本，是通用工具在数据隔离架构下短期拿不到的。

**风险 5 · "重点解析"统计上站不住**
功能命名与产品文案中**全部移除"高频"、"预测"、"押题"措辞**。改用"建议优先复习的章节"等结构化导航语言。学生预期被正确设定后，反而能减少"押错题"的负面口碑。

**风险 6 · 头部高校通报**
应对：早期下沉至二三线高校先跑量；同步主动接触 1-2 所合作高校，争取教师端试点（P2）作为合规背书。考前 2 周内对营销内容做敏感词审查，不投放任何含"答案"、"作弊"、"代写"的素材。准备一份可在 24 小时内执行的"通报响应预案"（暂停涉事学校账号、提供卡点报告给教务、声明配合调查）。

**风险 7 · 用户路径焦虑错位**
主入口已改为拍题 2 步出答案。课件上传、考点矩阵、自测判分等深度功能默认折叠在二级菜单，仅对订阅用户主动展示。"考前 3 天的学生只想要那个红字答案"——这是 v2 的主路径设计原则，不是噱头。

- 批判 3 · 模板非壁垒 → **部分响应**。承认 80% 可复刻；护城河迁移到校级数据飞轮。
- 批判 4 · 考点频次偷换 → **响应**。功能改名"重点解析"；全文移除"高频 / 预测 / 押题"措辞。
- 批判 5 · 版权与学术诚信 → **部分响应**。删"可直接誊抄"；新增训练集隔离、用户协议、考场禁用标注、DMCA 通道、教师端合规叙事；坦承行业灰色地带。
