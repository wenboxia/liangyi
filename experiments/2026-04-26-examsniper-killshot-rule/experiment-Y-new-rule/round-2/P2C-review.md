# Round 2 · P2C · 知情复审 · 方向漂移分析(实验 Y)

我从产品形态、价值主张、P0 优先级三个维度对比了 v1 和 v3,看到一条比较清晰的漂移轨迹。下面是我作为新进入者读到的两个版本之间的方向位移——不替你下判断,只把它暴露出来,最后向你提问。

一、最初是什么产品 / 现在是什么产品
v1 的产品:「考点狙击手」——以课件为锚的考前整体复习方案。

副标题:大学生 AI 考点狙击手
核心承诺:"上传课件 → 自动提取考点矩阵 → 看到本科目高频考点 Top 30 + 模板 + 页码溯源"
P0 第 1 项是「考点雷达(课件 → 考点矩阵)」,第 2 项才是「解题狙击」
卡位叙事:NotebookLM("读懂课件")和 ChatGPT("获得回答")中间的真空地带,差异化抓手是课件优先召回
心智词:考前提分搭子
v3 的产品:「解题搭子」——拍题即出答案的单题解题工具,带评分员视角的输出格式。

副标题:大学生 AI 解题搭子
核心承诺:"打开 App → 拍题 → 10 秒得到评分员视角的解答。不传课件也能用,课件是增强项"
P0 第 1 项是「拍题狙击(主入口)」,第 2 项「课件锚定增强」明确写作"增强"
卡位叙事:5.1 自己承认"课件 grounding + 联网溯源已是行业基础设施";差异化抓手换成评分员视角 + 极短路径 + 校级数据
心智词:拍题解题工具
二、累积漂移的方向
把每次响应单看,每条都言之成理;但累积起来,产品的重心明显移动了:

副标题从「考点」→「解题」——这是品类心智的迁移,不只是文案。
课件从「锚点」降为「增强项」——v1 第一句"课件是锚点,所有功能最终回答这道题怎么写才能拿分";v3 第一节就明说"不传课件也能用"。
「考点雷达 / 课件 → 考点矩阵」从 P0 第 1 项消失——v1 中那个让用户"一眼看到哪些必考、哪些可放弃"的功能,在 v3 中只在 P1 第 7 项以「重点解析」的弱化形式残留,且被严格限定为"统计描述,不是占卜"。
主入口的物理动作变了——v1 是"上传课件";v3 是"拍单题"。
差异化叙事的 anchor 变了——v1 的护城河叙事本来就站在"课件锚定"上;v3 的 5.1 主动把"课件锚定"让出去交给行业,把差异化重压到「评分员输出格式」+「校级数据沉淀」上。
付费承诺单位变了——v1 卖"考期复习包"(周卡 / 月卡 / 学期);v3 SKU 表新增「解题包 50 题」和「补题包 10 题」,计价单位明显下沉到"题",套餐反而成了次主力的感觉。
把这 6 条连起来看,漂移的方向是:

从「以课件为锚的考前整体复习方案(类 NotebookLM Pro for 考试)」漂到「拍题即出答案的单题解题工具(类 ChatGPT 拍题 + 评分员格式)」

每一步响应日志都很合理:

LTV 自戕 → 加封顶、加题数计费 → 计价被推向"按题"
红海 → 删 NotebookLM/ChatGPT 三方对比 → 失去"课件锚定"的卡位叙事
路径过长 → 主入口改拍题 2 步、课件下放为可选增强 → 课件被解构
单盲读者看不懂"考点矩阵"、术语难 → 改用"拍题"作为直观入口 → 考点雷达进一步被边缘化
每一条单看都对,但累积之后,v1 的"以课件统摄考点"那条产品骨架,在 v3 里基本被抽掉了。v3 仍然提"课件",但它不再是产品的中心,只是一个能让答案"更像本课老师想看到的样子"的修饰。

三、向你提问
这次漂移真实存在。但漂移本身不一定是错的——P2A 投资人和 P2B 单盲读者都在指向"用户进来的第一个动作要简单",拍题确实比上传课件低门槛得多。所以我不替你判断,只问你三个问题:

你最初想做的,究竟是「考点狙击手」还是「解题搭子」? v1 的副标题是前者,v3 的副标题是后者。这两个产品的护城河、留存逻辑、运营动作都不同——「考点矩阵」做出来是教研产品,「拍题答题」做出来是工具产品。你现在拿到的是后者,这是你想要的吗?

课件现在是"可选增强",这个降级你接受吗? v1 的核心壁垒第 2 条就是"课件优先召回 + 延伸明示的双层引用机制",这是 v1 拒绝被通用模型复刻的主要论据。v3 把这个让出去后,差异化只剩「评分员输出格式」(承认 80% 可复刻)+「校级数据沉淀」(承认 6-12 个月才能沉淀出来)。你愿意把短期防御交给一个还没建起来的数据飞轮吗?

你是被批判推着走,还是你本来就想往这个方向走? P2A 的 LTV 批判和 P2B 的"看不懂"反馈,都是合理输入,但它们各自都不要求你把课件降级——是你在响应过程中累积出了这个降级。如果你倒带回去,只想保留"加封顶、改名重点解析、加冷启动兜底"这些技术性修复,但保住 v1 的考点雷达 P0 地位 + 课件作为锚点的叙事,产品会变成什么样?这是不是更接近你最初想要的?

如果第 1 题答案是「解题搭子」,第 2 题答案是「接受」——那 v3 方向稳定,只是品类发生了主动迁移。
如果第 1 题答案是「考点狙击手」——那 v3 已经漂离原意,需要回拉。
