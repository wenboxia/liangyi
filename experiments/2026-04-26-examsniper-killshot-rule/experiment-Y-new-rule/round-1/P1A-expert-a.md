# Round 1 · P1.1 · 专家 A · 应试效率派方案(实验 Y)

ExamSniper · 应试效率派产品方案
一、核心定位
ExamSniper 是大学生的"考前提分加速器"。

产品的唯一价值，是在考前 72 小时内，把这门课考试要考的考点、题型、答案、得分点，以最短路径交付到学生手里。我们不做"学习陪伴"，不做"知识理解"，不做"长期能力培养"——我们做的是让学生上考场前，手里握着一份押中率最高、答得最规范、拿分最多的应试弹药库。

一句话：上传课件 + 真题 → 输出考点矩阵 + 题型模板 + 标准答案 → 考场拿分。

二、目标用户与典型场景
目标用户
大学本科生 / 硕士生，期末周、补考、考研专业课、期中突击的应试场景
核心画像：课没怎么听、课件几十上百页没翻过、距离考试 3–7 天、目标是"过"或"刷高分绩点"
不是学霸（学霸不需要），不是学术党（学术党用 NotebookLM），是典型的考前突击型学生
典型场景
场景 1：考前 3 天突击
学生丢进 5 个 PPT + 2 套历年真题，30 秒内拿到一份"本课考点清单 + 高频题型 + 每个题型的答题模板"，按清单逐个击破。

场景 2：真题刷题
学生把一道历年真题甩进来，ExamSniper 给出：标准答案 + 得分点拆解 + 这道题对应课件第几页 + 老师可能怎么变式 + 变式题 3 道。

场景 3：考场前夜冲刺
学生打开"考点速记卡"，按出题概率从高到低过一遍，每张卡片：考点 + 一句话定义 + 必背公式 / 模板 + 一道例题。

三、核心功能模块与优先级
P0 · 必须有，决定产品生死
1. 考点矩阵自动生成
上传课件后，自动产出一张二维表：考点 × 题型。每个交叉格标注出题概率（高 / 中 / 低）、分值预估、所属课件页码。这是整个产品的骨架。

2. 真题 → 考点反推引擎
上传历年真题，自动反推出题规律：哪些章节是高频考区、哪些题型反复出现、老师的出题偏好。真题权重 > 课件权重——老师考过的，比课件写过的重要十倍。

3. 结构化解题器（带得分点拆解）
输入一道题，输出严格分层的答案：

【题型识别】 → 这是什么类型的题
【解题模板】 → 这类题的标准答题套路
【标准答案】 → 分点作答，每点标注得分权重
【课件溯源】 → 答案的每一部分对应课件第几页
【延伸补全】 → 课件没覆盖但老师可能要的内容，明确标注来源（学科知识库 / 联网）
4. 答题模板库
按学科 × 题型预置模板：简答题三段式、论述题总分总、计算题步骤分、案例分析题 SWOT/PEST……学生套模板答题，保证不丢格式分。

P1 · 强化提分效率
5. 变式题生成器
针对任一考点或真题，一键生成 5–10 道老师可能出的变式题，带答案。把"押题"做成可量产的功能。

6. 考点速记卡（考场模式）
按出题概率排序的极简卡片流，每张卡 30 秒内能过完。专为考前夜 / 考场外 10 分钟设计。

7. 自动判分
学生写完答案丢进来，对照标准答案的得分点逐项判分，输出"你这题大概能拿 X/Y 分，丢分在第 N 个得分点"。

P2 · 规模化壁垒
8. 学科题型模板库（沉淀型资产）
按高校 × 课程 × 老师沉淀考点矩阵和真题库，越用越准。同一老师带的同一门课，第二年的学生能直接复用上一年沉淀的押题数据。

9. 押题命中率追踪
考完后让学生反馈，反向校准模型的出题概率预测。对外公布命中率作为营销硬通货。

四、相对 NotebookLM / ChatGPT 的差异化
维度	NotebookLM	ChatGPT	ExamSniper
产品目标	阅读理解辅助	通用对话	考场拿分
课件外内容	拒答	自由发挥、无溯源	结构化补全 + 明确标注来源
输出形态	散文式回答	散文式回答	考点矩阵 + 题型模板 + 得分点
真题处理	当普通文档	当普通问题	反推出题规律、生成变式
应试组织	无	无	按"考点 × 题型 × 出题概率"组织
用户路径	问答式	问答式	上传 → 矩阵 → 套模板 → 判分
核心一句话：NotebookLM 让你"读懂课件"，ChatGPT 让你"得到一个回答"，ExamSniper 让你"考试拿分"。前两者交付的是信息，我们交付的是分数。

五、商业模式
主线：考前订阅制（学生付费的核心场景就是考试周）

1. 单课付费 · ¥19.9 / 课
按一门课买断 30 天使用权。匹配学生"一门课突击一次"的真实付费意愿。

2. 期末季会员 · ¥49 / 学期
覆盖整个期末周，不限课程数。客单价杀手锏，期末季集中转化。

3. 考研专业课包 · ¥199–399 / 科
高客单价市场。考研学生付费意愿最强、复购最稳定，是利润大头。

4. 命中率营销驱动增长
押题命中率公开化，命中一道题的传播价值 >> 任何投放素材。让"我用 ExamSniper 押中了 3 道大题"成为社交货币。

5. B 端不碰
不做高校合作、不做老师端、不做"学习平台"叙事。学生 C 端付费才是这个模式的命脉，B 端会稀释定位、拖慢节奏。

六、关键风险与应对
风险 1：押题不准 / 考点矩阵失灵 → 口碑崩盘
应对：真题权重压倒性高于课件权重；同一课程沉淀多届数据持续校准；命中率公开追踪，差的课程下架不硬撑。

风险 2：学科覆盖不均（理工科 vs 文科答题逻辑差异大）
应对：先单点打透文科论述题、商科案例题这两个"模板化收益最高"的品类，再横向扩张。理工科计算题模板化难度高，放后期。

风险 3：被定性为"作弊工具 / 应试机器" → 政策与平台风险
应对：定位明确为"备考效率工具"，不碰考试中实时作答场景；输出始终带课件溯源，强调"基于公开课程材料的复习辅助"。

风险 4：学生季节性付费，淡季现金流差
应对：考研专业课包打全年市场（考研全年备考）；期末季 + 考研季双周期对冲；淡季做次年期末季的题库沉淀和获客蓄水。

风险 5：通用大模型厂商下场做同样的事
应对：壁垒不在模型，在真题数据 + 高校 × 课程 × 老师维度的考点沉淀。第一年抢规模，第二年靠数据复用形成换用成本，让后来者补不上历届真题这一课。

一句话收束：ExamSniper 不教你学会，ExamSniper 让你考过、考高。
