# ExamSniper · 大学生 AI 考点狙击手 — idea-v2.md

## 一、核心定位

ExamSniper 是大学生期末备考的**结构化复习工具**：上传课件与历年真题，输出"考点 × 题型 × 出题概率"矩阵，配套结构化解题、得分点拆解、答题模板与变式题，把考前 72 小时的复习路径压缩成可执行清单。

我们交付的是**结构化的复习路径与弹药**，不是分数。分数是学生、老师、试卷、临场状态的复合函数——我们能负责的是把复习从"翻一百页 PPT 找重点"压缩成"按概率清单逐个击破"，把答题从"散文式发挥"约束成"按得分点分层作答"。

底层工程要求是课件溯源（每条答案标课件页码、课件外内容标外部来源）。这不是差异化，这是 2025 年应试场景的合格线——我们把它当地基，不当卖点。真正的差异化在产品形态：把答案组织成应试结构（考点矩阵 + 题型 × 得分点），而不是散文式问答。

## 二、目标用户与典型场景

**目标用户**：大学本科生，期末周 / 补考 / 期中突击的应试场景。核心画像：课没怎么听、几十上百页课件没翻过、距考试 3–7 天、目标是过 / 高绩点。

**明确不做的用户**：考研专业课用户（决策周期 6–12 月、对内容权威性敏感、对手是粉笔/文都这类重运营机构，与本科突击是两套获客和组织能力）；学术党（用 NotebookLM）；K12（合规与赛道完全不同）。

**典型场景**：

- **考前 3 天突击**：丢进 5 个 PPT + 2 套真题，30 秒内拿到考点清单 + 高频题型 + 题型模板，按清单逐个击破。
- **真题刷题**：上传一道历年真题 → 标准答案 + 得分点拆解 + 课件溯源页码 + 老师可能的变式 + 3 道变式题。
- **考场前夜冲刺**：考点速记卡按出题概率从高到低过一遍，每张卡 30 秒。
- **跨学期回归**："个人考点档案"延续上学期的弱项标签和答题模板偏好——不是高频留存，是降低下个考试季的冷启动成本。

## 三、核心功能模块及优先级

### P0 · 决定产品生死

**1. 考点矩阵自动生成**
课件上传 → 二维表（考点 × 题型），每格标出题概率（高/中/低）、分值预估、课件页码。这是用户上手 30 秒看到价值的核心交付物。

**2. 真题 → 考点反推引擎 + 老师偏好建模**
真题权重压倒性高于课件。从历年真题反推：高频考区、反复出现的题型、老师的出题偏好（爱考边界条件 / 案例 / 推导）。"老师偏好"是单纯 RAG 做不出来的——它需要跨届真题对比 + 课程描述 + 用户反馈三方耦合，是本产品 prompt 工程难度最高也最难被竞品 12 个月内追平的部分。

**3. 结构化解题器（分层输出 + 课件溯源）**
输入题目 → 题型识别 / 解题模板 / 标准答案分点（每点标得分权重）/ 课件溯源页码 / 课外延伸（明确标来源）。课件溯源是地基不是卖点；产品形态上的差异在于"分点 + 得分权重"这种应试结构化，而非散文式回答。

**4. 答题模板库**
按学科 × 题型预置模板：简答三段式、论述总分总、计算步骤分、案例 SWOT/PEST。先打透文科论述与商科案例（模板化收益最高），再扩理工科。模板库是 prompt 工程 + 教学设计经验的复合资产，不是模型能力的单一函数。

### P1 · 提分效率强化

**5. 变式题生成器**
针对任一考点或真题，一键生成 5–10 道变式题，带答案与得分点。

**6. 考点速记卡（考场模式）**
按出题概率排序的极简卡片流，30 秒一张，专为考前夜 / 考场外 10 分钟设计。

**7. 自动判分与丢分点诊断**
学生写完答案上传 → 对照得分点逐项判分 → 输出"丢分集中在第 N 个得分点，对应课件第 P 页这个概念"。下一道同类题不再丢同一个点。

**8. 考点关系图（轻量版）**
课内考点之间的前置 / 延伸关系图谱。作用是辅助"先攻哪几个性价比最高"的决策——这是应试工具，不是知识图谱产品。

**9. 个人考点档案（跨学期沉淀）**
用户跨学期沉淀的弱项标签、答题模板偏好、易丢分模式。本科 4 年内每次回归时，新课程的引导可以基于历史档案预热（"你过去在'相关 vs 因果'这类边界条件题上反复丢分，本课中第 3、7 章涉及类似结构"）。

这不是高频留存机制——本生意季节性强，DAU/MAU 在考试季外天然低。这是降低下个季度冷启动成本的轻量沉淀，让 LTV 不只是"一个学期"。

### P2 · 规模化沉淀

**10. 高校 × 课程 × 老师维度的考点沉淀（含分级置信度）**
跨届复用同高校 × 同课程 × 同老师的考点矩阵与命中率反馈。但承认两件事：(a) 大学老师轮岗、合班、大纲改版每年都在发生，"上届数据有效复用率"远低于直觉，每个 SKU 标置信度等级（基于真题年份覆盖、老师连续性、用户反馈量）让用户自己判断；(b) 跨用户沉淀的不是课件原文，是去原文化的考点抽象 + 题型分布 + 命中率，规避课件版权风险（详见风险 1）。

**11. 命中率追踪（内部用，不做营销话术）**
学生考完反馈，校准模型出题概率预测。命中率是产品迭代的内部指标和 SKU 置信度评级输入，**不**作为对外营销话术——"押中 3 道大题"在《广告法》框架下接近"提分""保过"承诺，平台限流封号风险高。

## 四、产品差异化

老实说，2025 年没有一项功能可以单独构成 12 个月以上的护城河。强制溯源是 RAG + 引用，NotebookLM、Kimi、豆包都能做。差异化建立在三个 prompt 工程 + 产品形态难复制的复合点上：

**1. 应试组织形态而非问答形态**
竞品的产品形态都是问答（输入问题、输出回答）。ExamSniper 的形态是"先看矩阵、再做模板、再判分"的工作流。一个学生在 NotebookLM 里得到"信息"，在 ChatGPT 里得到"回答"，在 ExamSniper 里得到"按概率排序的执行清单"。这是 UI/UX 和工作流的差异，不是模型能力的差异。

**2. 老师偏好建模 + 出题概率预测**
跨届真题对比 + 课程描述 + 用户反馈三方耦合的概率模型，是 prompt 模板加 RAG 复制不出来的东西。这是先发窗口的核心。

**3. 答题模板库（教学设计资产）**
按学科 × 题型预置的得分点结构化模板，是教学设计经验沉淀，不是模型即开即用的能力。

**关于先发窗口**：诚实地说，Kimi/豆包明天上线"考试模式"prompt 模板能复制掉前端体验的 50–60%。我们的 12 个月窗口取决于：(a) 用户行为反馈数据飞轮转起来（命中率 + 丢分点 → 概率模型迭代）；(b) "高校 × 课程 × 老师"维度的真实使用积累，让重启成本由用户档案承担。这个窗口不是无限的，融资和增长节奏都按"窗口内做出 NPS 和品牌认知"来设计，不假装做永久护城河。

## 五、商业模式

**定价（重构）**：
- **免费基础版**：1 门课限额、考点矩阵 + 基础解题、不开放变式题与判分。降冷启动门槛，让用户在考前 3 天先用上。
- **单课 ¥29 / 30 天**：匹配本科生考前 3–7 天冲动消费心智，单门课突击场景的主力档位。
- **学期会员 ¥69 / 学期**：覆盖整个期末周不限课程数，对>2 门课的用户经济。¥69 锚点设在"约等于一次重修费的 1/30"，强调一门课挂科代价。

去掉了 v1 的 ¥19.9 单课档（与 ¥49 学期档死锁）和考研专业课包（赛道切换非留存）。

**单位经济估算（早期假设，需上线后验证）**：
- 单用户单课全周期 API 成本：5–8 次重型调用，长上下文输入 + 结构化输出。用 Haiku 4.5 / 国产小模型承担 70% 流量、Opus 4.7 等顶配只做考点矩阵和判分关键节点，估算 API + RAG 检索 ≈ ¥2–4 / 课。
- 单课 ¥29 → 扣支付通道 1% + 内容审核 + API ≈ 毛利率 80–85%，单课贡献利润 ≈ ¥22–24。
- CAC 假设：小红书 KOC + 学校群裂变 ¥8–15 / 付费用户。单课用户净贡献 ≈ ¥7–16，学期会员用户 ≈ ¥45–55。
- 关键变量是**付费率**：参考国内大学生付费工具历史数据（百词斩、考虫等），3–8% 是合理区间。在这个区间内，期末季单批次需 5–10 万 MAU 才能撑起健康单位经济。这是需要在 v2 上线后第一个期末季验证的最关键数字。

**不做的事**：
- 不做"押中 X 道题"营销话术（合规雷）。
- 不做考研专业课包（合规 + 赛道切换）。
- 不做高校 / 老师端 B2B（稀释 C 端定位、拖慢节奏）。
- 不在投放素材里使用"提分""保过""考场拿分"字样。

## 六、关键风险与应对

**风险 1 · 课件版权**
学生上传的 PPT 是任课老师 / 出版社的著作权作品。应对：默认课件原文仅服务该用户的会话生命周期，不跨用户沉淀；跨届复用只保留"考点抽象 + 题型分布 + 命中率"，去课件原文化；用户协议明确告知并要求勾选；与重点高校建立 opt-in 合作通道。这是合规设计，不是免责声明。

**风险 2 · 营销合规**
"押中 X 道题""提分""保过"在《广告法》教育培训类条款下属高风险表达，微信/抖音/小红书会限流封号。应对：营销话术统一为过程性描述（"30 秒看到考点清单""按得分点结构作答"），命中率仅作为内部指标和 SKU 置信度评级输入；UGC 内容做关键词过滤，"押中"类素材不参与官方传播。

**风险 3 · 季节性现金流（不靠考研包对冲）**
诚实承认这是季节性强的工具型生意，DAU/MAU 在考试季外天然低。应对：(a) 控制固定成本——团队精简、API 成本随流量伸缩；(b) 跨学期个人考点档案降低下季度冷启动成本，让 LTV 不只一学期；(c) 期中考、补考、小学期等次级窗口拉平部分波动；(d) 不向 VC 讲"全年高频"故事，按季节性工具的估值倍数管理融资节奏。

**风险 4 · 数据连续性远低于直觉**
大学老师轮岗、合班、大纲改版、教材换版每年发生。应对：每个 SKU 标置信度等级（A 级=同老师连续 3 届真题 + 50+用户反馈；C 级=老师不连续 / 真题年份不足 / 反馈不足），让用户自己判断而非系统单方面"下架"。承认良率不均不是"我们真诚"，是产品事实。

**风险 5 · 通用大模型厂商下场**
壁垒不在模型，也不在溯源（这是工程标配）。在三件事的复合：应试组织形态 / 老师偏好建模 / 答题模板库 + 用户行为反馈飞轮。诚实判断：先发窗口 12–18 个月，目标是窗口期内做出 NPS 与品牌，不假装做永久护城河。

**风险 6 · 押题不准导致口碑崩盘**
应对：真题权重压倒性高于课件；分级置信度披露；上线前每门课至少 3 届真题验证；上线后命中率持续追踪并反向调整概率模型。差的 SKU 标 C 级而非下架，让用户带着预期使用。

**风险 7 · 学科覆盖不均**
理工科计算题模板化难度高于文科论述。应对：先打透文科论述 / 商科案例 / 经管类题型，理工科作为 P1.5 引入，化学/医学等强专业领域留待 P2 后期。

**风险 8 · 幻觉答案毁口碑**
应对：所有答案分"课件可溯""课外可溯（标来源）""模型推断（建议人工核查）"三级标注，第三级在 UI 上显式提示。宁可写"建议核查"，不冒静默幻觉风险。

---

**收束**：ExamSniper 不承诺让你考好——分数不是 AI 能交付的物。我们交付的是把考前 3 天压缩成"按概率清单逐个击破"的结构化路径，每条路径都站在课件上。这件事做扎实了，分数会自然跟过来；做不扎实，再漂亮的话术也救不了。
