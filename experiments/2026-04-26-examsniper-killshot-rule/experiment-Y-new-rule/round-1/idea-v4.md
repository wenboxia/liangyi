# ExamSniper · 大学生 AI 考点狙击手 — idea-v4.md

## 一、核心定位

ExamSniper 是大学生的**考前提分加速器**。

唯一目标：在考前 72 小时内，把这门课要考的考点、题型、答案、得分点，以最短路径交付到学生手里——上传课件 + 真题 → 考点矩阵 + 题型模板 + 标准答案 + 得分点 → 考场拿分。

我们不做学习陪伴、不做长期能力培养、不做"认知深化"。我们做的是：让你上考场前，手里握着一份押中率最高、答得最规范、拿分最多的应试弹药库。

这个目标的实现机制是把"翻 100 页 PPT + 自己琢磨答题套路"的 8–12 小时，压缩到按概率清单逐题攻克的 2–3 小时。但目标本身是分数，机制只是机制——别把机制当成承诺锚点。

底层工程要求是课件溯源（每条答案标课件页码、课件外内容标外部来源）。这是 2025 年应试场景的合格线，不是差异化卖点。真正的差异化在产品形态：把答案组织成"考点矩阵 × 题型 × 得分点"的应试结构，而不是散文式问答。

## 二、目标用户与场景

**核心画像**：大学本科生，期末周 / 补考 / 期中突击。课没怎么听，几十上百页课件没翻过，距考试 3–7 天，目标是"过"或"刷高绩点"。

**v1 上线先聚焦的学科**（这是产能边界，不是永久边界）：

- 文科论述（文学、历史、哲学、社科）
- 商科案例（管理、市场、战略）
- 法学（案例分析、法条理解）
- 经管类（计量、政经）
- 计算机基础（数据库、软工等概念课程）
- 医学背诵密集型（病理、药理、解剖）

这些品类的共同点是题型可模板化、得分点结构化收益高。

**v2 扩展（12 个月内）**：理工科计算题、考研专业课包。

**v3 远期**：高度计算类（理论物理推导、奥数级数学）、艺术设计类。

学生上传课件时系统识别学科类型，超出当前覆盖范围会明确告知"本课程暂不在我们的强势品类内，效果可能打折"，让用户自己决定要不要继续——不上线即拒，但也不藏边界。

**典型场景**：

- **考前 3 天突击**：丢进 5 个 PPT + 2 套真题，30 秒拿到考点矩阵，按清单逐个击破。
- **真题刷题**：上传一道历年真题 → 标准答案 + 得分点拆解 + 课件溯源 + 老师可能的变式 + 3 道变式题。
- **考场前夜冲刺**：考点速记卡按出题概率从高到低过一遍，每张卡 30 秒。
- **考后复盘 → 次年弹药**：学生反馈考中了哪几题，沉淀进同高校 × 同课程 × 同老师的押题数据，下一届直接复用。

## 三、核心功能

### 必备功能（决定产品能不能用）

**1. 考点矩阵自动生成**

课件上传 → 二维表（考点 × 题型），每格标出题概率（高 / 中 / 低）、分值预估、课件页码。考前 3 天的学生上手 30 秒就能看到价值。

**示例：《管理学原理》上传 5 个 PPT 共 187 页 + 2 套历年真题后**：

| 考点 | 简答（6 分） | 论述（15 分） | 案例（20 分） | 课件页 |
|---|---|---|---|---|
| 委托代理理论 | **高**（近 3 年考 3 次） | 中 | 低 | P34–41 |
| 信息不对称 | **高** | **高**（去年大题） | 中 | P18–29 |
| SWOT 分析 | 低 | 中 | **高**（重复出现） | P95–110 |
| 公司治理结构 | 中 | 低 | 低 | P145–158 |

每个概率标签可以点开看依据（"近 3 年真题中出现 4 次"），不是黑盒打分。

**关于无页码 PDF / 板书照片**：OCR 文字识别 + 章节定位（"第三章 第 2 节"），无法精确定位时标"课件中相关位置（系统未能精确定位）"，不假装精确。

**2. 真题反推 + 老师偏好建模**

老师考过的，比课件写过的重要十倍。系统对比多届真题反推：高频考区、爱考的题型、出题习惯（爱考边界条件 / 案例 / 推导）。

**关于跨届真题来源**（产品内完全透明）：
- (a) 同课用过的同学主动选择共享（用户 opt-in，可随时撤回）
- (b) 学校公开题库（如有）
- (c) 网络可检索的公开资源

每道真题点开都能看到来源标记。某课只有 1 套真题时，系统明确告知"真题样本不足，出题规律预测置信度低"。

**3. 结构化解题器（带得分点拆解 + 强制溯源）**

输入题目，输出分层答案：题型识别 / 解题模板 / 标准答案分点 + 每点得分权重 / 课件溯源 / 课外延伸（标来源）。

**关于题型识别错误**：识别结果显示判断依据，用户一键改成正确题型，系统按指定题型重组答案。

**4. 答题模板库**

按学科 × 题型预置：简答三段式、论述总分总、案例 SWOT/PEST、法学 IRAC、医学症状—诊断—治疗结构。模板是教学经验沉淀，不是凭空生成，是 prompt 工程难复制的资产。

### 增强功能（提分效率强化）

**5. 变式题生成器**

针对任一考点 / 真题，一键生成 5–10 道变式题，带答案与得分点。把"押题"做成可量产的功能。

**关于变式题质量**：双模型交叉校验，分歧的题降档展示并标"系统不确定"。用户可标错，标错被确认时获免费课程兑换码补偿。

**6. 考点速记卡（考场模式）**

按出题概率排序的卡片流，30 秒一张。用户完全控制翻页：可暂停、可回看、可收藏、可筛选只看高概率卡片。专为考前夜 / 考场外 10 分钟设计。

**7. 自动判分与丢分点诊断**

学生写完答案丢进来，对照得分点逐项判分："你这题大概拿 12/15 分，丢分集中在第 3 个得分点（公司治理结构那一段），对应课件 P150。"

**关于 OCR 失败 / 评分尺度**：拍照识别后用户可逐字编辑文字再判分。判分**作为参考定位丢分点**，不是权威打分——这点在结果旁醒目提示。

**8. 考点关系图**

课内考点的前置 / 延伸关系图，辅助"先攻哪个性价比最高"。是应试工具，不是知识图谱产品。

**9. 个人考点档案（跨学期沉淀）**

跨学期沉淀用户的弱项标签、答题模板偏好、易丢分模式。

**对你具体有什么用**：
- 同学期跨课最有用：本学期上的《管理学》和《组织行为学》共享"信息不对称""激励理论"等考点，档案即时复用。
- 大一到大三跨学期：下学期回归时新课程基于历史档案预热（"你过去在'相关 vs 因果'类边界题反复丢分"）。
- 大四毕业后效用衰减——除非考研 / 考公复习政经 / 法律 / 管理类基础课。这是诚实的局限。

### 规模化沉淀

**10. 高校 × 课程 × 老师维度的考点沉淀（含分级置信度）**

跨届复用同高校 × 同课程 × 同老师的考点矩阵。每门课展示置信度等级：

- **A 级**（同老师连续 3 届真题 + 50+ 用户反馈）：出题概率预测可信，按矩阵分配复习时间。
- **B 级**（数据中等）：矩阵参考用，关键考点建议自己再核对真题。
- **C 级**（老师新换 / 新开课 / 数据不足）：**矩阵概率预测不可信，但答题模板、结构化解题、变式题、判分等基础功能仍完全可用**。买之前能看到本课级别。

跨用户沉淀的不是课件原文，是去抽象化的考点列表 + 题型分布 + 命中率（即"只保留考点列表，不保留课件原文"），规避版权风险。

**11. 押题命中率追踪 + 用户口碑增长**

考完用户反馈，校准模型预测。

**对内、对用户、对外的三层处理**：
- **对内**：命中率是产品迭代和 SKU 评级的核心指标。
- **对用户**：每门课的 SKU 详情页显示历史命中数据（"过去 3 学期，本课高频考点的真实命中比例：68%"）——你能看到具体数字再决定要不要买。
- **对外（公司官方投放）**：不使用"押中""提分""保过"等《广告法》风险话术。但用户自发 UGC（"我用 ExamSniper 押中了 3 道大题"在小红书 / 朋友圈传播）是真实社交货币，公司不参与制作但也不抑制——这是产品力转化为口碑的最强通路。

## 四、产品差异化

诚实说，2025 年没有任何一项功能可以单独构成 12 个月以上的护城河。课件溯源 = RAG + 引用页码，是工程标配。差异化建立在三件事的复合上：

**1. 应试组织形态而非问答形态**

NotebookLM 给"信息"，ChatGPT 给"回答"，ExamSniper 给"按概率排序的执行清单"。这是 UI 与工作流的差异，不是模型能力的差异。

**2. 老师偏好建模 + 出题概率预测**

跨届真题对比 + 课程描述 + 用户反馈三方耦合的概率模型，是 prompt 模板加 RAG 复制不出来的东西。

**3. 答题模板库（教学设计资产）**

按学科 × 题型预置的得分点结构化模板。

| 维度 | NotebookLM | ChatGPT | ExamSniper |
|---|---|---|---|
| 产品目标 | 阅读理解辅助 | 通用对话 | 考场拿分 |
| 课件外内容 | 受限补全 | 自由发挥 | 结构化补全 + 标来源 |
| 输出形态 | 散文式回答 | 散文式回答 | 考点矩阵 + 题型模板 + 得分点 |
| 真题处理 | 当普通文档 | 当普通问题 | 反推规律 + 生成变式 |
| 应试组织 | 无 | 无 | 考点 × 题型 × 出题概率 |

**关于先发窗口**：12–18 个月。我们不假装永久护城河，目标是窗口内做出口碑、品牌、数据飞轮。

## 五、商业模式

主线是**考前订阅制**——学生付费意愿集中且高峰明确。

- **免费基础版**：1 门课限额、考点矩阵 + 基础解题。降冷启动门槛。
- **单课 ¥29**：覆盖该课考期。计费规则：购买时填考试日期，从考前 30 天到考后 7 天有效。考完前 24 小时内可全额退款。
- **学期会员 ¥69**：覆盖整个期末周不限课程数，>2 门课用户经济。¥69 锚点设在"约一次重修费的 1/30"，强调一门课挂科代价。

去掉了 v1 的 ¥19.9 死档（与 ¥49 学期档锁死）。

**12 个月 roadmap 内的扩展**：
- **考研专业课包 ¥199–399 / 科**：v2 上线。本科期末 + 考研双周期是合理的全年生意结构，但 v1 不做——考研用户 6–12 月备考、对内容权威性敏感、对手是粉笔/文都，需要不同的获客和组织能力。先把本科期末做扎实，再用沉淀的考点数据和品牌资产切考研。

**押题命中率作为增长引擎**：用户产品内可见命中率 + 用户自发 UGC 的复合体。"我用 ExamSniper 押中了 3 道大题"是真实存在的社交货币，公司官方话术合规化（不主动制作"押中"素材），但 UGC 通路不抑制——这是这个生意最强的口碑传播。

**B 端不碰**：不做高校 / 老师端、不做"学习平台"叙事。学生 C 端付费是命脉。

## 六、关键风险与应对

**风险 1 · 押题不准 → 口碑崩盘**：真题权重压倒性高于课件；同课程多届数据持续校准；命中率公开追踪；SKU 置信度等级让用户带预期使用。强制溯源让模型即便押错也不至于编造，损失止于"没押中"，不至于"瞎答案"。

**风险 2 · 课件版权**：默认课件原文不跨用户沉淀，跨届复用只保留去抽象化的考点列表 + 题型分布 + 命中率（不保留课件原文）；用户协议明确告知；与重点高校 opt-in 合作。这是合规设计而非免责声明。

**风险 3 · 营销合规**：公司官方投放话术不使用"押中""提分""保过"；但用户自发 UGC 不抑制——这是产品力的自然外溢，与公司广告行为有法律边界。

**风险 4 · 学科覆盖不均**：v1 先聚焦文科论述、商科案例、法学等模板化收益最高的品类，理工科计算题作为 v2 扩展，超高难度计算 / 艺术类留待 v3。学生上传时系统识别学科并诚实告知预期效果。

**风险 5 · 通用大模型厂商下场**：壁垒不在模型也不在溯源（工程标配），在三件事复合：应试组织形态 / 老师偏好建模 / 答题模板库 + 用户行为反馈飞轮。先发窗口 12–18 个月，目标是窗口期做出 NPS 与品牌。

**风险 6 · 季节性现金流**：本科期末季 + 考研季（v2 起）双周期是合理的全年结构。v1 期间承认是季节性生意，控固定成本、跨学期个人档案降冷启动、不向投资人讲"全年高频"故事。

**风险 7 · 被定性为"作弊工具"**：定位明确为"考前备考效率工具"，不碰考试中实时作答场景；输出始终带课件溯源，强调"基于公开课程材料的复习辅助"。

**风险 8 · 幻觉答案**：三档可信度标注：
- 课件可溯（可直接用）
- 课件外延伸 + 来源已标（可用，建议看一眼来源）
- 模型推断 + 建议核对（少数边缘情况，频率 <10%。具体核对动作=翻一下课件对应章节看一眼，2 分钟）

## 七、数据、隐私与质量兜底

**你上传的课件**：默认仅服务你自己的会话，不进入跨用户库，不被用于训练。

**跨届真题**：用户主动选择共享 + 学校公开 + 网络公开三类来源，每条来源在产品内可见。你自己上传的真题默认私有，除非主动勾选匿名分享。

**社交关系**：不读取通讯录、微信好友、QQ 群，不做强制邀请才能解锁的拉人头机制。学校群裂变指自然口碑分享（你愿意发给室友），不是强制传播。

**变式题质量兜底**：双模型交叉校验 + 用户标错反馈 + 人工抽查队列 + 标错被确认时的免费兑换补偿。

---

**收束**：ExamSniper 不教你学会，ExamSniper **让你考过、考高**——但每一分都站在课件上。

把考前 8–12 小时压缩到 2–3 小时只是机制，不是目的。目的是分数。机制只是这个目的最高效的实现路径。

## 附录：单位经济假设（团队 / 投资人视角）

- 单用户单课全周期模型成本：5–8 次重型调用，Haiku 4.5 / 国产小模型承担 70% 流量，Opus 4.7 等顶配只做关键节点，估算 ≈ ¥2–4 / 课。
- 单课 ¥29 → 扣支付通道 + 内容审核 + 模型成本 ≈ 毛利率 80–85%，单课贡献利润 ≈ ¥22–24。
- 获客：小红书 KOC + 学校群自然传播 + 用户自发"押中"UGC，¥8–15 / 付费用户。单课用户净贡献 ≈ ¥7–16，学期会员用户 ≈ ¥45–55。
- 关键变量是付费率：参考国内大学生付费工具历史数据（百词斩、考虫等），3–8% 合理区间。该区间内期末季单批次需 5–10 万月活才能撑起健康单位经济。
- v1 上线第一个期末季的最关键验证数字：付费转化率 + 用户自发 UGC 数量。后者决定 CAC 的下限。

## P2C 回退日志

**承认漂移**。P2C 的诊断正确：v1 → v3 是系统性收缩，不是抖动。回到原始 P0（"考点狙击手""解题搭子"），v1 的应试人格更接近原意，v3 是过度妥协。

**部分回退**：

- **核心定位句**回到 v1："考前提分加速器"+"考场拿分"。v3 的"我们不承诺分数"被删除——分数是产品的目的，时间压缩只是机制，不能本末倒置。
- **收束**回到 v1："让你考过、考高——但每一分都站在课件上"。
- **考研包**从 v3 的"永久不做"改为"v2 产品 roadmap"——本科期末 + 考研双周期是合理的全年结构，v1 不做是组织能力问题，不是赛道边界。
- **学科范围**从 v3 的"白名单 + 黑名单永久写死"改为"v1/v2/v3 渐进 roadmap"。
- **押题命中率**作为增长引擎部分恢复——区分"公司官方投放话术合规"与"用户自发 UGC 不抑制"，后者是这个生意最强的传播通路，不能因为前者的合规风险一起砍掉。

**保留 v3 工艺**（这些是真改进，不回退）：

- mock 矩阵示例、典型场景具体化
- 真题来源透明、SKU 置信度等级、命中率对用户产品内可见
- 容错机制（OCR 可编辑、题型可手改、变式题双模型校验 + 标错补偿）
- 个人档案 + 大四衰减承认
- 定价绑定考期 + 24 小时退款
- 数据隐私章节
- 三档可信度标注 + 具体核对动作
- 单位经济抽到附录、术语降级
- 版权设计（去抽象化沉淀，不沉淀原文）

**判断**：P2A/P2B 反馈中真问题（合规、表达清晰、容错）保留为工艺标准；它们附带的"产品人格收缩"作为副作用回退。最终人格 = v1 的刀 + v3 的工艺。
