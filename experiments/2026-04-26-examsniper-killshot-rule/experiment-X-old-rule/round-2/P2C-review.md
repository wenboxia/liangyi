# Round 2 · P2C · 知情复审 · 方向漂移分析

我没参与过这两版的讨论,通读 v1 和 v3 之后,有一个明确的方向漂移要暴露给你。

核心定位:从 X 漂到了 Y
v1 是什么产品(你自己写的话):

"考前 72 小时提分外挂"
"阅卷老师反向训练出来的押题机器"
服务对象:"课没怎么听、PPT 没怎么仔细看"的通宵党、补考党、"从未上过课"的学生
核心心理学:"焦虑本身就是最大的付费引擎","19.9 买一晚上安心"
立场宣言:"不教学生学习,只帮学生考试","考前提分,不谈学习"
v3 是什么产品(同样是你自己写的话):

"课件理解 + 真题分析 + 考点结构化交付工具"
服务对象:"听过课、买过教材,但临考发现复习不充分的中等投入学生"
核心承诺:"把已有的知识基础变成稳定分数"
付费驱动:"不讲 19.9 买一晚上安心",改成"信任学科顾问审校过的模板"
关键产物:"被人审校过的考点和模板"
漂移方向:从"为临考焦虑的救命稻草用户卖押题机器"漂到"为有基础的中等投入学生卖合规审校的备考交付物"。

累积漂移:单独看都合理,加起来换了产品
每一条修改单看都站得住:

删"狙击/押题"对外话术 → 响应作弊定性 ✓
涨价到 39.9 → 响应 unit economics ✓
删"用户上传跨届复用" → 响应护城河批判 ✓
改口"押考点不押题" → 响应押题口径冲突 ✓
场景 C 改远期 / 场景 D 删除 → 响应冷启动现实 ✓
但叠加之后,有四条隐性的同向漂移:

目标用户上移了一个段位。v1 说不服务"自驱深度学习者",但核心服务对象是没听课的救命党;v3 说不服务"只想要原题答案的极端用户",核心服务对象变成中等投入有基础的学生。两端都被砍掉,留下了中间。

付费心理学换了引擎。v1 押的是焦虑/救命,v3 押的是信任/确定性。这是两种不同的人在两种不同的状态下买两种不同的东西。

承诺从结果转成过程。v1 承诺"把分数交付到手";v3 承诺"考点命中率 ≥70% Top-30 出现"。后者更可交付,但用户买的东西也变了。

品牌人格被分裂为内外两套。v1 的"狙击手"是结构性立场(你自己说"产品名字里的狙击二字本身就交代了立场");v3 把它降级为"内部产品语言",对外是"考点结构化"。这个名字现在和产品对外人格已经不匹配了。

几个问题留给你判断
当 v1 的核心用户("课没听 PPT 没看的通宵党"、"从未上过课的补考党")遇到 v3 的产品页("中等投入学生 / 学科顾问审校 / 结构化交付"),他们会觉得这是给自己的吗?你是有意把他们让出去,还是没注意到他们被让出去了?

v1 的反叛人格("不讨好教育情怀派"、"焦虑就是付费引擎"、"不谈学习")是产品的氛围资产,v3 几乎全部撤回了。这是你认了"那种话术不合规所以不能讲",还是你也认了"那种立场本身是错的"?这两件事不一样。

产品名还叫 ExamSniper / 考点狙击手,但对外文案、目标用户、付费心理都已经不是狙击手了。你是要换名字,还是要把产品拉回到名字代表的立场?

场景 C(考研)从 P0 退到远期、场景 D(校园资产沉淀)被删除,产品边界从"四波峰全覆盖 + 校园复用闭环"收缩到"公共课急救 + 标准档"。这是 MVP 聚焦,还是野心被批判磨平了?

我不替你判断这是漂移还是正确的转向——P2A 提的是真问题,P2B 提的也是真问题,响应它们没有错。但响应完之后产品已经不是原来那个产品了,这件事值得你显式确认一次,而不是从修改日志里逐条勾完就默认事情没变。
