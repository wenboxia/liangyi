# ExamSniper · 大学生 AI 考点狙击手 · 产品文档 v1

## 一、核心定位

**考前 72 小时，把"这门课会考什么、怎么答、能拿几分"直接交付到学生手里的 AI 考点狙击手。**

ExamSniper 不是学习工具，是应试交付工具。学生上传课件那一刻，系统目标只有一个——通过考试，分数最大化。课件是锚点，不是镣铐；延伸补全是为了多拿分。所有功能、定价、留存策略，只服务一个动作：让学生走进考场时，手里握着最锋利的那把枪。

差异化的一句话锚定：NotebookLM 是忠实但保守的图书馆员，ChatGPT 是博学但散漫的学长，ExamSniper 是带过几届学生、押题精准、模板成熟的考前冲刺老师。

---

## 二、目标用户与典型场景

### 目标用户

大学在校生中"考前突击型"群体——平时投入有限、考前一到两周才打开课件、目标是"稳过 + 尽量多拿分"的学生。期末周、补考、重修是核心战场。这是大学生群体里付费意愿最集中、付费窗口最锐利的一档。

### 典型场景

**场景 A · 考前 3 天，水课速通**
开闭卷无所谓，学生扔进 12 个 PPT + 2 套历年真题，3 小时内拿到「考点清单 + 高频题型 + 答题模板」，背完上考场。

**场景 B · 考前 1 周，专业核心课冲 85+**
学生需要"考点-题型矩阵"定位老师高频出题区，配套变式题刷穿，每道题都有得分点拆解，知道每个采分点值几分。

**场景 C · 考中实时狙击（开卷 / 线上）**
拍照或粘贴题目，30 秒内出结构化答案 + 课件溯源 + 得分点标注。

## 三、核心功能模块及优先级

### P0 · 考点狙击核心链路（上线即必须有）

**1. 课件考点自动提取**
上传 PPT/PDF，自动输出考点清单。每个考点标注：
- 重要度（高频 / 中频 / 低频）
- 预测题型（名词解释 / 简答 / 论述 / 计算 / 选择）
- 预估分值

重要度判定以"历年真题命中率"为主权重，"课件强调频次"为辅。无真题样本时 UI 明确降级提示。

**2. 历年真题反向锚定**
上传真题后，自动把每道题映射回课件考点，生成**考点-题型矩阵热力图**：哪些考点反复考、以什么题型考、近三年趋势。这是应试效率的命门，必须是 P0 而非 P1。

**3. 题目结构化解答（四段式）**
输入考题，输出固定结构：
- 得分点拆解：这题有几个采分点，每个几分
- 标准答案：按采分点组织，背诵友好
- 答题模板：同类题套路化
- 课件溯源：哪一页讲过；课件未覆盖时明确标注"延伸补全"来源

**4. 三色来源等级标注（产品红线）**
所有输出内容强制可视化区分三种来源：
- 🟢 课件原文（可点击跳转到具体页码）
- 🟡 学科常识（模型知识库，未在课件中找到）
- 🔵 联网检索（附可点击的检索证据链）

延伸补全的题目不允许"裸答"。学生始终知道：哪些是老师课件里写过的，哪些是老师可能问但课件没写的。

### P1 · 应试加速器（核心链路稳定后两周内）

**5. 变式题生成器**
针对每个高频考点，自动生成 3-5 道变式题（同考点不同问法），附标准答案与得分点拆解。直接对标老师"换个壳再问一遍"的出题习惯。

**6. 答题模板库**
按学科 × 题型沉淀模板（如"马原论述题三段式""微观经济学计算题五步法""数据结构算法题伪代码框架"）。学生套模板填考点即可成文。

**7. 自动判分 & 错题诊断**
学生写答案 → 系统按采分点逐条比对 → 给出失分点 + 补救建议。考前最后一晚的练手必备。

### P2 · 留存与扩张（验证 PMF 后）

**8. 考前倒计时复习计划**
输入考试日期，按"高频考点优先 + 艾宾浩斯节奏"自动排出每日任务清单。

**9. 同校同课程考点共享池**
同一所学校同一门课的考点提取结果聚合（自动脱敏后），新用户上传课件即可继承历史考点库与真题库——网络效应核心。

**10. 战绩系统**
押中率、模板命中率、判分进步曲线。让学生有"我的备考资产"沉淀，考完即推下学期续费。

## 四、产品差异化

| 维度 | NotebookLM | ChatGPT | ExamSniper |
| --- | --- | --- | --- |
| 内容边界 | 严格 Grounding，课件外拒答 | 自由发挥，无溯源 | 课件为锚 + 延伸补全 + 三色来源标注 |
| 输出形态 | 通用问答 / 总结 | 通用对话 | 考点清单 / 题型矩阵 / 得分点拆解 / 答题模板 |
| 核心动作 | 阅读理解 | 自由对话 | 狙击考点 → 套模板 → 拿分 |
| 评价指标 | 回答是否忠实 | 回答是否流畅 | 学生考完是不是真的拿到了预期分数 |

**真正的产品壁垒不在模型，而在三件事的复利：**
1. 考点-题型矩阵的结构化封装能力（通用模型做不出这种输出形态）
2. 答题模板库的沉淀深度（按学科 × 题型 × 院校长期积累）
3. 同校同课程数据沉淀（用户上传 + 脱敏共享形成的本地化考点密度）

三个月内必须跑出 50 所目标高校 × 高频课程的考点库密度，否则窗口关闭。

## 五、商业模式

### 定价结构

| 档位 | 价格 | 定位 |
| --- | --- | --- |
| 免费版 | ¥0 | 每月 2 份课件提取 + 10 道题解答，"试一次水课"够用 |
| 学期会员（主力） | ¥39 / 学期 | 无限课件 + 无限题解 + 变式题 + 自动判分 |
| 考试季冲刺包 | ¥19 / 7 天 | 专攻"考前一周才开始紧张"的最高价值窗口 |
| 期末周特供包 | ¥99 / 月 | 含人工审校的"押题报告"，覆盖高数 / 线代 / 政治 / 英语等头部高价值课程 |

学期会员定价低于"一顿食堂饭 × 4"，精准卡在期末周前两周大促开启。

### 付费触发点

- 免费额度卡在"提取 1 份课件后想看完整考点清单" → 付费解锁
- "得分点拆解 + 答题模板"锁在付费墙后，免费版只给标准答案
- 考前 7 天倒计时推送"还有 X 天考试，你的考点矩阵已就绪" → 转化窗口

### 留存策略

1. **学期制订阅而非月度**：天然绑定整个考试周期，单次决策买完一学期。
2. **考完即推下学期**：考后 3 天推"上学期你押中 XX 个考点 / 模板命中率 XX%"，把成功体验转成续费。
3. **同课程考点共享池形成切换成本**：用得越久，本校本课程的考点库越厚，换工具就要从零开始。
4. **战绩系统沉淀**：押中率、模板命中率、进步曲线作为"我的备考资产"留存。

## 六、关键风险与应对

**风险 1：考点提取不准 → 学生考完发现压根没考这些**
应对：把"历年真题反向锚定"作为 P0 的硬约束，重要度判定以真题命中率为主权重。无真题课程在 UI 上明确降级提示，不允许"裸出"高自信考点。

**风险 2：延伸补全的模型幻觉反噬信任**
应对：三色来源等级标注是产品红线，强制可视化。延伸补全题目必须附可点击检索证据链，不允许裸答。"未经验证"内容在结尾强制提示"建议向老师二次确认"。

**风险 3：学校 / 老师对"AI 押题"的舆论风险**
应对：产品话术全程定位"复习辅助 / 考点梳理"，禁用"押题""透题"等敏感词。不主动抓取、不分发任何盗版真题——真题仅接受用户上传。同课程共享池强制二次脱敏（去除老师姓名、学号、个人批注）+ 用户主动授权。

**风险 4：通用 AI 工具（ChatGPT、Kimi、豆包）顺手做掉这件事**
应对：壁垒不在模型，而在结构化输出封装 + 模板库沉淀 + 同校数据密度。三个月内冲到 50 所高校的考点库密度是生死线。

**风险 5：上传内容的版权与隐私**
应对：用户上传内容默认仅本人可见。进入共享池需主动勾选 + 自动脱敏。隐私协议明确"不向第三方分发，不用于模型训练"。

## 七、收尾立场

ExamSniper 不教学生"理解知识"，而是让学生在考前最短时间内，知道考什么、怎么答、能拿几分。课件是锚点，延伸补全是为了多拿分，一切只服务一个动作——让学生走进考场时，手里握着最锋利的那把枪。

## 自动综合日志

**最终立场：以"应试效率派"为主，吸收"学习深化派"在溯源严谨性上的细节，放弃其核心交互逻辑。**

**判断过程：** PMF 强弱看付费窗口锐度。考前 72 小时是大学生付费意愿最集中的时刻，此时学生要的是"答案 + 模板 + 分数"，不是"我反问你这道题考的是什么概念"。"学习深化派"承认自己的产品要"筛掉只想刷题的用户"——但这部分用户恰恰就是付费主体，把核心客群定义为流失对象，是 PMF 的自我否定。¥49/课/学期的 Socratic 引导产品在大学生市场是窄众理想主义，竞争对手是免费 ChatGPT + 教辅书，缺乏锐利付费理由。

**为什么不选学习深化派：** 强制引导违反"考前焦虑学生选择阻力最小路径"这一行为底层规律，知识图谱构建对低质量课件（手写扫描件、混乱 PPT）极度脆弱，8 轮对话上限在期末周前一晚是反人性的。"慢就是快"是教育者的话术，不是 18-22 岁学生在期末周的语言。

**吸收的点：** 三色来源等级标注的强制可视化（A 也有，B 表述更严谨，采用 B 的红线表述）；"未经验证"延伸内容的二次确认提示。

**放弃的点：** 课件概念图谱引擎（过重，对低质课件不鲁棒，与"考前 72 小时交付"节奏冲突）；Socratic 解题引导（与产品定位根本冲突）；学期理解档案（不是付费学生关心的交付物）；学习圈互教验证（在期末周不可能跑起来）；¥49/课定价（按课定价天花板低，¥39/学期覆盖全部课程更符合突击型用户决策模型）。
