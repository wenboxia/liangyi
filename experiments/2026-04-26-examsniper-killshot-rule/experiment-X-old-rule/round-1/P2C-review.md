# Round 1 · P2C · 知情复审 · 方向漂移分析

我把 v1、v3 都通读了一遍，下面是中立观察。

一、核心定位是否变了
v1 是什么产品：考前 72 小时的"狙击枪"。一句话承诺三件事——会考什么 / 怎么答 / 能拿几分。主力 SKU 是 ¥39 学期会员（一次决策绑定整个考试周期），P0 命门是"历年真题反向锚定"，差异化卖点是"考点-题型矩阵热力图 + 押中率"，野心是"三个月 50 所高校生死线"，文案锐利到底——"最锋利的那把枪"。

v3 是什么产品：覆盖大学 4 年"每一个要拿分时刻"的结构化解答工具。承诺收敛为结构化考点解答 + 答题模板（"会考什么"减弱，"能拿几分"删除）。主力 SKU 变成 ¥19/7 天包，留存逻辑承认"考完即流失是设计预期"，第一阶段从 50 所变成 3-5 所水课做透，文案改为"想拿分、不想花太多时间"，自承"季节性消费品 + 平时拿分辅助的混合体，不假装是 SaaS"。

变了。

二、单看都合理、加起来产生的累积漂移
每个修改单独看都站得住，但叠加效应让方向位移：

单点修改	单点理由	累积效应
删"历年真题反向锚定"（P2A#4）	法律合规	"会考什么"的核心证据链塌掉
删"押中率"（P2A#5）	监管/话术风险	锐利的结果承诺被换成"覆盖率"过程指标
不杜撰分值（P2A#6 → P2B#6）	不能瞎编	"能拿几分"从产品承诺里消失
拓展到平时作业/周测（P2A#7）	抬使用频次	"考前 72 小时"的时间锐度被稀释
主力 SKU 改 ¥19/7 天（P2A#2）	季节性现实	学期绑定的留存设计被放弃
50 校→3-5 校（P2A#3）	不吹牛	野心规模显著收敛
删"最锋利的枪"叙事	合规/务实	整体调性从狙击式转向节制式
三、漂移方向
从：考前 72 小时极度锐利、以"押中 + 拿分"为价值承诺、靠真题密度建壁垒、学期绑定的应试狙击枪

漂到：覆盖学期全场景、以"结构化解答 + 模板"为价值承诺、靠模板库 + 同校共建建壁垒、按次消费的应试瑞士军刀

——还是工具，但锐度换成了通用度，结果承诺换成了过程交付，押题感换成了辅助感。

四、需要你判断的事
漂移本身不一定错。P2A#4（真题合规）和 P2A#5（押中率话术）是硬约束，不让步会撞墙。但你需要确认两件事：

v1 那句"考前走进考场，手里握着最锋利的枪"——这是修辞，还是产品魂？ 如果是魂，v3 已经把它折掉了：没有押中率、没有分值、不绑定考前 72h、不再说"狙击"。如果只是修辞，v3 的"诚实工具"路线没问题。

场景从"考前 72h"扩展到"4 年 N 个拿分时刻"——这是抬频次的策略调整，还是定位重构？ 在 v1 里这是被明确拒绝过的方向（自动综合日志写着"放弃学习深化派……以应试效率派为主"），v3 虽然没改成学习派，但场景泛化的方向，事实上稀释了"考前突击窗口"这个 v1 最锐利的判断。

这是你想要的方向吗？ 如果你的本意就是"在合规边界内能跑多远跑多远，锐度让步给可持续"——v3 是对的，方向没漂错只是收敛了。如果你的本意是"哪怕只有一个 72 小时窗口也要把它做到极致"——v3 已经偏离了那个产品。
