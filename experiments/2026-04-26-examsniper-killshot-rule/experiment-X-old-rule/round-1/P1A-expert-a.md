# Round 1 · P1.1 · 专家 A · 应试效率派方案

ExamSniper 产品方案 · 应试效率派
一、核心定位
考前 72 小时，把"这门课会考什么、怎么答、能拿几分"直接交付给学生的 AI 考点狙击手。

不是学习工具，是应试交付工具。学生上传课件那一刻，目标只有一个——通过考试，分数最大化。

二、目标用户和典型场景
目标用户
大学在校生中"考前突击型"群体——平时没怎么听课、考前一周才打开课件、目标是 60 分万岁或冲刺高分但没时间系统复习的学生。期末周、补考、重修是核心战场。

典型场景
场景 A：考前 3 天，水课速通 开卷或闭卷无所谓，学生扔进 12 个 PPT + 2 套历年真题，要在 3 小时内拿到"考点清单 + 高频题型 + 答题模板"，背完就上考场。
场景 B：考前 1 周，专业核心课冲刺 学生想拿 85+，需要"考点-题型矩阵"定位老师高频出题区，配套变式题刷穿，每道题都有得分点拆解。
场景 C：考中实时狙击（开卷 / 线上考） 拍照或粘贴题目，30 秒内出结构化答案 + 课件溯源 + 得分点标注。
三、核心功能模块和优先级
P0 · 考点狙击核心链路（上线即必须有）
课件考点自动提取
上传 PPT/PDF，自动输出考点清单：每个考点标注「重要度（高频/中频/低频）」「预测题型（名词解释/简答/论述/计算/选择）」「预估分值」。重要度判定结合课件强调频次 + 历年真题命中率。

历年真题反向锚定
上传真题后，自动把每道题映射回课件考点，生成考点-题型矩阵热力图：哪些考点反复考、以什么题型考、近三年趋势。这是应试效率的命门。

题目结构化解答
输入考题，输出固定四段式：

得分点拆解（这题有几个采分点，每个几分）
标准答案（按采分点组织，背诵友好）
答题模板（同类题套路化）
课件溯源（哪一页讲过 / 课件未覆盖时明确标注"延伸补全"来源）
延伸补全策略
课件优先召回；课件没覆盖的考点，用模型学科知识 + 联网检索补全，但必须标注来源等级（课件原文 / 学科常识 / 联网检索），让学生知道哪些是"老师课件里的"，哪些是"老师可能问但课件没写的"。

P1 · 应试加速器（核心链路稳定后两周内）
变式题生成器
针对每个高频考点，自动生成 3-5 道变式题（同考点不同问法），附标准答案与得分点。直接对标"老师可能换个壳再问一遍"的出题习惯。

答题模板库
按学科 × 题型沉淀模板（如"马原论述题三段式""微观经济学计算题五步法"），学生套模板填考点即可。

自动判分 & 错题诊断
学生写答案 → 系统按采分点逐条比对 → 给出失分点 + 补救建议。考前练手必备。

P2 · 留存与扩张（验证 PMF 后）
考前倒计时复习计划 输入考试日期，自动按"高频考点优先 + 艾宾浩斯节奏"排出每日任务清单。
同课程考点共享池 同一所学校同一门课的考点提取结果聚合（脱敏后），新用户上传课件即可继承历史考点库与真题库——网络效应。
四、关键产品差异化
维度	NotebookLM	ChatGPT	ExamSniper
内容边界	严格 Grounding，课件外拒答	自由发挥，无溯源	课件为锚 + 延伸补全 + 来源等级标注
输出形态	通用问答 / 总结	通用问答	考点清单 / 题型矩阵 / 得分点拆解 / 答题模板
核心动作	阅读理解	自由对话	狙击考点 → 套模板 → 拿分
评价指标	回答是否忠实	回答是否流畅	学生考完是不是真的拿到了预期分数
一句话差异化：NotebookLM 是"忠实的图书馆员"，ChatGPT 是"博学但散漫的学长"，ExamSniper 是带过几届学生、押题精准、模板成熟的考前冲刺老师。

五、商业模式
定价结构
免费版：每月 2 份课件提取 + 10 道题解答，足够"试一次水课"。
学期会员（主力）：¥39 / 学期（约 4 个月），无限课件 + 无限题解 + 变式题 + 自动判分。精准卡在期末周前 2 周开启大促，定价低于一顿食堂饭 × 4。
考试季冲刺包：¥19 / 7 天，专攻"考前一周才开始紧张"的学生，覆盖 ExamSniper 最高价值窗口。
考研 / 期末周特供包：¥99 / 月，含人工审校的"押题报告"，针对头部高价值课程（高数、线代、英语、政治、专业课核心几门）。
付费触发点
免费额度卡在"提取 1 份课件后想看完整考点清单" → 付费解锁
"得分点拆解 + 答题模板"功能直接锁在付费墙后，免费版只给标准答案
考前 7 天推送"还有 X 天考试，你的考点矩阵已就绪" → 转化窗口
留存策略
学期制订阅而非月度，绑定整个考试周期
考完即推下学期：考后 3 天推"上学期你押中 XX 个考点 / 模板命中率 XX%"，把这次的成功体验转成下学期续费
同课程考点共享池形成切换成本：用得越久，本校本课程的考点库越厚，换工具就要重头来
战绩系统：押中率、模板命中率、判分进步曲线，让学生有"我的备考资产"沉淀
六、关键风险与应对
风险 1：考点提取不准 → 学生考完发现压根没考这些
应对：把"历年真题反向锚定"做成 P0 而不是 P1。考点重要度判定必须以真题命中率为主权重，课件强调频次为辅。无真题样本的课程，UI 上明确降级提示"本课程暂无历年真题，考点重要度仅基于课件"。

风险 2：延伸补全的"模型幻觉"反噬信任
应对：来源等级标注是产品红线——课件原文 / 学科常识 / 联网检索三色标记，强制可视化。延伸补全的题目必须附可点击的检索证据链，不允许"裸答"。

风险 3：学校 / 老师对"AI 押题"的舆论风险
应对：产品话术全程定位"复习辅助 / 考点梳理"，不使用"押题""透题"等敏感词。功能上不主动抓取、不分发任何盗版真题——真题只接受用户上传，且仅供该用户使用（同课程共享池需明确二次脱敏 + 用户授权）。

风险 4：通用 AI 工具（ChatGPT、Kimi、豆包）顺手做掉这件事
应对：壁垒不在模型，而在**"考点-题型矩阵 + 答题模板库 + 同校同课程数据沉淀"**。前两者靠产品化封装通用模型做不出的结构化输出，第三者靠时间和用户量积累。三个月内必须跑出 50 所目标高校 × 高频课程的考点库密度，否则窗口关闭。

风险 5：学生上传课件 / 真题的版权与隐私
应对：用户上传内容默认仅本人可见；进入共享池需用户主动勾选 + 自动脱敏（去除老师姓名、学号、个人批注）。隐私协议明确"不向第三方分发，不用于模型训练"。

收尾立场
ExamSniper 不教学生"理解知识"，ExamSniper 让学生在考前最短时间内，知道考什么、怎么答、能拿几分。课件是锚点，不是镣铐；延伸补全是为了多拿分，不是为了拓展视野。一切功能、一切定价、一切留存策略，只服务一个动作——让学生走进考场时，手里握着最锋利的那把枪。
