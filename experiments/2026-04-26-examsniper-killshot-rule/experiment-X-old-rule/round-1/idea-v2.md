# ExamSniper · 大学生 AI 考点狙击手 · 产品文档 v2

## 一、核心定位

**为大学生在"要拿分"的每一个时刻——期末、期中、月考、周作业——交付结构化的考点解答与答题模板。**

ExamSniper 是应试交付工具，不是学习工具。课件是锚点，延伸补全是为了多拿分。产品诚实地承认自己是季节性消费品 + 平时拿分辅助的混合体，不假装自己是 SaaS。

差异化锚定：NotebookLM 是忠实但保守的图书馆员，ChatGPT 是博学但散漫的学长，ExamSniper 是带过几届学生、模板成熟、节奏精准的考前冲刺老师。

---

## 二、目标用户与典型场景

### 目标用户

**"想拿分、不想花太多时间"的大学在校生。** 核心人群仍以期末突击型为主，但产品有意识地把使用场景拓展到平时作业、期中、月考、随堂测验，把使用频次从一年两次的峰值，抬到学期内周级触达。这是诚实的扩展——不假装这群人会因为产品深度变成终身学习者，但争取在他们读大学的 4 年里，从"考前用一次"变成"作业卡壳时也用一下"。

### 典型场景

**场景 A · 考前 3 天，水课速通**
学生扔进 12 个 PPT + 2 套老师授权的练习题或公开教辅题，3 小时内拿到「考点清单 + 高频题型 + 答题模板」。

**场景 B · 考前 1 周，专业核心课冲 85+**
"考点-题型矩阵"定位高频出题区，配套变式题刷穿，每道题给出采分点位置（不杜撰分值）。

**场景 C · 平时作业 / 周测**
单题输入，30 秒内出结构化答案 + 课件溯源 + 答题模板。这是日常使用频次的来源。

**场景 D · 考中实时狙击（开卷 / 线上）**
拍照粘贴，秒级返回结构化答案 + 三色来源标注。

## 三、核心功能模块及优先级

### P0 · 拿分核心链路

**1. 课件考点自动提取**
上传 PPT/PDF，输出考点清单。每个考点标注：
- 重要度（高频 / 中频 / 低频）
- 预测题型（名词解释 / 简答 / 论述 / 计算 / 选择）
- 重要度判定权重 = 课件强调频次 + 同课程已积累的"考点-练习题映射"密度（来源见 P0-3）

**2. 题目结构化解答（四段式）**
- **采分点拆解**：标注题目里"哪几处是采分点"，但不杜撰分值数字。仅当题目本身已有显式赋分（如真题原卷标注的"5 分"）时，才透传该分值；否则只标"采分点"位置。
- **标准答案**：按采分点组织，背诵友好。
- **答题模板**：同类题套路化。
- **课件溯源**：跳转到具体页码。

**3. 合规题库 + 考点反向锚定**
重要度判定的"映射数据"来源限定为以下三类，**不依赖学生上传的历年真题**：
- 教师 / 助教授权合作渠道提供的练习题（教师署名 + 授权协议）
- 已购买授权的公开教辅题库（电子版权许可）
- 用户自有的、由本人完成的作业题（用户勾选授权 + 平台二次审核）

学生可上传内容仅供其本人使用；进入共享池的内容必须通过版权来源声明 + 自动去除可识别信息 + 教师/学校异议下架流程三道关。这是一条比 v1 慢、但法律地基稳的路径。

**4. 三色来源等级标注（产品红线）**
- 🟢 课件原文（点击跳转页码）
- 🟡 学科常识（模型知识库，未在课件中找到）
- 🔵 联网检索（附检索证据链）

延伸补全题目不允许裸答；🟡🔵 内容在结尾强制提示"建议向老师二次确认"。

### P1 · 壁垒构建期（与 P0 同步推进，不延后）

**5. 答题模板库**
按学科 × 题型沉淀模板（"马原论述题三段式""微观经济学计算题五步法""数据结构算法题伪代码框架"）。这是真正的产品差异化资产之一，从 v1 的 P2 提前到 P1，同步推进。

**6. 同校同课程考点共享池（题面不共享）**
共享对象明确限定为**考点提取结果 + 答题模板调用记录 + 学生主动标注的难点**，**不共享原始题面**。规避真题版权问题。新用户上传课件即可继承本校本课程已积累的考点结构与模板适用情况。这是数据密度护城河。

**7. 变式题生成器（带使用上限）**
针对高频考点生成 3 道变式题（不是 v1 的 3-5 道），附标准答案与采分点。免费版每月 5 题，付费版每月 50 题——这是单位经济学约束下的硬上限，不是产品功能问题。

**8. 自动判分 & 错题诊断（带使用上限）**
按采分点逐条比对 → 失分点 + 补救建议。付费版每学期 100 次，超出按次计费 ¥0.5 / 次。

### P2 · 留存与扩张

**9. 考前倒计时复习计划**
按"高频考点优先 + 艾宾浩斯节奏"自动排出每日任务清单。

**10. 学习成效仪表盘（不是"押中率"）**
展示**考点覆盖率**（你练过的考点占课程考点池的比例）、**模板适用率**（系统模板在你练习题里的命中比例）、**判分进步曲线**——所有指标基于产品自身可观测数据，不涉及"押到老师没考过的题"这类需要先验未公开信息的指标。

## 四、产品差异化（诚实版）

| 维度 | NotebookLM | ChatGPT | ExamSniper |
| --- | --- | --- | --- |
| 内容边界 | 严格 Grounding | 自由发挥，无溯源 | 课件为锚 + 三色来源标注 |
| 输出形态 | 通用问答 | 通用对话 | 考点清单 / 题型矩阵 / 采分点拆解 / 答题模板 |
| 核心动作 | 阅读理解 | 自由对话 | 抓考点 → 套模板 → 拿分 |

### MVP 阶段的诚实判断

MVP 阶段没有结构性技术壁垒。"考点清单 + 答题模板"的输出形态，工程师一周可以用通用大模型 + structured output 复刻。**ExamSniper 的赌注不是"通用模型做不出"，而是"通用工具不会专门为大学生应试场景做"——做得早、做得专、把模板库和本地化数据密度跑在前面。**

可累积的、通用工具不会做的资产是两条：

1. **答题模板库**：按学科 × 题型 × 院校长期积累的结构化套路。这是人工 + 用户行为反馈共建的，不是 prompt 一段就能复刻的。
2. **同校同课程考点结构密度**：用户上传课件 + 主动标注 + 共享池聚合形成的本地化考点结构。这是冷启动慢但越用越厚的资产。

### GTM（替换 v1 的"50 所高校三个月"口号）

- 第一阶段：3-5 所目标高校的高频水课（思修、马原、毛概、大学英语）做透——这些课全国通用、版本相对稳定，模板库一次构建多校复用。
- 第二阶段：校园合伙人（每校 2-3 个学生兼职），CAC 控制在 ¥5-8 / 注册用户。
- 第三阶段：从"水课全国通用"扩展到"专业核心课校内深耕"。

## 五、商业模式

### 定价结构（重构后）

| 档位 | 价格 | 上限 | 定位 |
| --- | --- | --- | --- |
| 免费版 | ¥0 | 1 门课，3 份课件，10 道题，5 道变式，不含自动判分 | 完整价值闭环体验 |
| 考前 7 天冲刺包（**主力 SKU**） | ¥19 / 7 天 | 3 门课，无限题解，30 道变式，10 次判分 | 真正承担转化的 SKU |
| 学期通行证 | ¥59 / 学期 | 5 门课，500 道题，50 道变式 / 月，100 次判分 / 学期 | 给重度用户用的，不再叫"无限" |
| 押题报告（人工审校） | ¥99 / 课程 | 高数 / 线代 / 概率统计 / 政治 / 大学英语等头部高价值课 | 高 ARPU 单点 |

**和 v1 的关键差异**：v1 的 ¥39 无限学期会员在单位经济学上不可持续。v2 的所有 SKU 都带硬上限，主力转向"考前 7 天包"——这是与产品季节性使用模式真实匹配的 SKU。

### 单位经济学（v1 缺失，v2 补上）

单用户单次峰值消耗的近似上限：12 份课件解析（约 30 万 tokens）+ 50 道题解答（每题 4-6k tokens 输入 + 1-2k 输出）+ 30 道变式生成 + 10 次自动判分 + 联网检索调用 ~20 次。按当前主流模型 API 价格，**单次密集使用的推理 + 检索成本约 ¥6-12**。考前 7 天 ¥19 包毛利约 35-60%，扣除支付通道（约 1%）+ 退款率（约 5%）+ 服务器成本，目标净毛利 30%+ 可控。¥59 学期通行证按全学期 4-5 次密集使用估算，毛利结构相近。

**关键约束**：变式题和自动判分必须有硬上限。这不是产品体验缺失，是商业可持续性的前提。

### 留存策略（诚实版）

承认这是季节性 + 平时辅助的混合产品，留存逻辑按真实使用模式设计：

1. **考前 7 天包是主力**：考完即流失是这个 SKU 的设计预期，不假装它要"绑定整个学期"。
2. **平时作业触点**：把单题解答 + 模板调用做成低门槛日常工具，让学生在期中 / 月考 / 周作业时也想得起来。这是把使用频次从 2 次/年抬到周级的核心。
3. **学期通行证锁定重度用户**：而不是用来"卡食堂饭 × 4"的心理学伎俩。
4. **跨学期数据沉淀**：本校本课程的考点结构 + 学生历史模板调用记录，构成真实的切换成本。
5. **考完即推下学期**：基于"考点覆盖率""模板适用率"等可观测数据生成结业报告，不使用"押中率"这类法律 + 信任双重风险的指标。

## 六、关键风险与应对

**风险 1 · 单位经济学（v1 漏掉的硬约束）**
应对：所有 SKU 强制上限封顶，主力 SKU 改为短周期 ¥19 包匹配真实使用密度。每月做单用户成本审计，模型成本占收入超 40% 时立刻调阈值。

**风险 2 · 数据合规（真题侵权 + 学生违纪连带）**
v1 把"历年真题反向锚定"作为 P0 数据飞轮是法律地基不稳。
应对：彻底放弃以学生上传真题为核心数据源。题库来源限定教师授权 + 教辅授权 + 用户自有作业题三类。同校共享池只共享考点提取结果与模板调用记录，**不共享原始题面**。建立教师 / 学校异议下架的明示流程。

**风险 3 · 采分点分值的杜撰风险**
模型不知道老师真实评分标准，v1 直接给"每个采分点几分"是核心交付物里的硬编造。
应对：默认仅标采分点位置，不标分值。仅当题目原卷已显式赋分时才透传。结业报告用"考点覆盖率""模板适用率"，避免"押中率"这种暗示先验信息的指标。

**风险 4 · 话术合规（押题 vs 禁用押题）**
v1 内部存在"押中率指标"与"全程禁用押题语义"的冲突。
应对：删除"押中""押题"全部语义，对外对内话术统一为"考点覆盖""模板适用""结构化解答"，与功能描述一致。

**风险 5 · 没有结构性壁垒（MVP 阶段）**
应对：诚实承认 MVP 没有壁垒，把模板库 + 同校数据密度从 P2 提到 P1 同步推进。不再写"否则窗口关闭"的口号，给出可执行的三阶段 GTM 路径。

**风险 6 · LTV 极低 / 季节性流失**
应对：不假装是 SaaS。财务模型按 ARPU 年化建模——考前 7 天包贡献峰值收入，平时作业触点贡献使用频次。把"4 年大学生命周期内被打开几次"作为留存核心指标，而非"日活"或"月留存"。

**风险 7 · 学校 / 老师对 AI 押题的舆论风险**
应对：产品话术统一在"复习辅助 / 考点梳理 / 答题模板"。不主动抓取分发任何盗版资料。教师可申请将本校本课程的所有衍生数据从共享池移除。

## 七、收尾立场

ExamSniper 是给大学生在"要拿分"的每个时刻提供结构化交付的工具，不是 SaaS，不是学习深化产品。它不需要假装能改变任何人的学习习惯——它只需要在学生想拿分的那一刻在场，并且足够好用、足够便宜、足够合规可持续。
