# Round 1 · P2A · 投资人批判

读完了。下面是 7 条最有杀伤力的批判，按致命程度排序。

1. 单位经济学一眼就负，¥39/学期 是凭感觉拍的，不是算出来的

第 111 行写"学期会员 ¥39 / 学期 = 无限课件 + 无限题解 + 变式题 + 自动判分"，第 116 行还洋洋得意"低于一顿食堂饭 × 4"。问题是你 P0 第 4 项的"🔵 联网检索附可点击证据链"是每次输出都要跑的，第 5 项变式题生成器要"3-5 道变式 × 每个高频考点"，第 7 项自动判分要"按采分点逐条比对"——这些全是长上下文 + 多轮调用。期末周一个学生 12 个 PPT + 2 套真题 + 几十道变式 + 反复判分，单用户单学期推理 + 检索成本极易冲到 ¥30-50 量级，再扣支付通道、退款、获客，毛利结构性为负。整个文档没有一行成本测算，直接跳到"卡食堂饭 × 4"的零售心理学，是 founder 自我催眠级的定价。

2. 学期制订阅 vs 季节性使用，直接自相矛盾

第 17 行自己承认"期末周、补考、重修是核心战场",第 126 行又说"学期制订阅天然绑定整个考试周期，单次决策买完一学期"。这两句话是打架的——学期制只在考前 2 周有用，3 月份的学生回头看会觉得交了智商税，续费率灾难是写在产品定义里的。你要么承认这是季节性快消(那就别提"绑定整个学期"),要么承认这其实是"考前 7 天 ¥19 包"是真主力,¥39 学期会员是用来给人安全感的烟雾弹——但你又把它叫"主力档",自己都没想清楚 ARPU 来自哪个 SKU。

3. "通用模型做不出这种输出形态"是幻觉，你说的护城河全是 prompt 工程

第 96 行三件复利第 1 条:"考点-题型矩阵的结构化封装能力(通用模型做不出这种输出形态)"。这句话是错的。ChatGPT/Kimi/豆包 加一段 system prompt + structured output schema,一个工程师一周就能复刻"考点清单 + 题型矩阵 + 得分点 + 课件溯源"的输出形态。你真正的护城河候选是第 2 条模板库 + 第 3 条同校数据密度——但这两个全在 P2(第 73 行),意味着你 MVP 阶段没有任何壁垒,只是一个比 ChatGPT 多了几个按钮的壳。"三个月跑到 50 所高校"(第 100 行)是没有 GTM、没有 CAC、没有渠道方案的口号,VC 听到"否则窗口关闭"这种话只会觉得 founder 在吓自己。

4. P0 数据壁垒(历年真题反向锚定)的来源是学生违纪行为 + 平台版权连带责任

第 45 行把"历年真题反向锚定"定为 P0 的命门,第 141 行解释"真题仅接受用户上传"。这是把违纪+侵权当成核心数据飞轮。一,绝大多数高校明确禁止真题外传,学生上传 = 违反学生手册;二,真题版权归出题老师/学校,"脱敏去除老师姓名"(第 141 行)解决的是隐私不是版权,用户上传不构成平台免责(参考网盘判例)。第 79 行同校共享池"自动脱敏后聚合"——一旦上规模,一封学校发来的律师函就够你删库重启。你把整个产品最关键的数据资产建在一个法律地基会塌的地方,而文档里完全没有应对,只有第 141 行那句话术上的回避。

5. "押中率"战绩系统直接踩自己设定的话术红线

第 82 行战绩系统第一个指标就是"押中率",第 141 行又要"产品话术全程禁用押题、透题等敏感词"。这是同一份文档里两条直接打架的红线。你要么承认你卖的就是押题(那合规风险按真实风险定价),要么真的禁用押题语义(那"押中率"这个核心留存抓手就废了)。第 161 行你自己写"PMF 强弱看付费窗口锐度"——大学生愿意付 ¥39 的真实理由就是"押中",一旦你把这个词从产品里抠掉,转化漏斗最大那一段直接漏没。这不是文案微调问题,是产品价值主张和合规话术不能共存。

6. 得分点分值是模型瞎编的,这是信任系统的核心 bug

第 49 行"得分点拆解:这题有几个采分点,每个几分"被定为 P0 输出的第一项。**问题是高校老师的评分标准是非公开的、不透明的、每年不同的、每个老师不同的。**模型说"这题 3 个采分点每个 2 分"——这个分值是哪来的?是模型基于一般经验编出来的。但 UI 上是确定语气展示给学生看的。学生考完拿到卷子一对比,"我押中了考点但分数对不上"——第 82 行你引以为傲的"押中率"指标会立刻穿帮。这不是延伸补全幻觉的问题(那个还能用第 58 行三色标注挡一下),这是核心交付物里的硬编造,而你没有任何机制去校准或退让。

7. 把"考前突击型"定义为核心客群,等于主动选了 LTV 最低的人群

第 17 行:"平时投入有限、考前一到两周才打开课件、目标是稳过 + 尽量多拿分。这是付费意愿最集中、付费窗口最锐利的一档。"付费窗口锐利的另一面是 LTV 极低:这群人考完就走,一年两次峰值,毕业后 100% 流失,且本身就是对学习投入最少的人群——他们的付费天花板就是"今晚不挂科"那一瞬间的应激消费,不会沉淀任何深度使用。第 161 行的自我辩护"承认筛掉只想刷题的用户是 PMF 的自我否定"是双向适用的——你筛掉了所有可能产生持续 LTV 的用户,留下了最高 churn 最低 ARPU 的那群,然后管这叫 PMF。这不是 PMF,是高峰期高 GMV 的季节性消费品定位,投资回报模型完全不同,文档里全程混淆了这两件事。

最后一句:第 161 行那句"PMF 强弱看付费窗口锐度"是整份文档最危险的一句话——这是把"愿意付钱"等同于 PMF,刻意忽略了留存维度。一个考前 3 天才用、考完即弃、一年用 2 次、毕业即流失的产品,无论付费窗口多锐利,在 VC 模型里都是个礼品卡生意,不是 SaaS。
