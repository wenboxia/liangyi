# P2D-fix · 老规则 prompt(实验 X 用)

本 prompt 沿用 `experiments/2026-04-24-agent-eval-platform-no-human-decision/prompts/P2D-fix-rule.md` 同款规则——"强否定 + 实质支撑 → 回 P1"+ 第二次 P2D-fix 终止条件兜底强制框架内修改。

给 Claude-2(续 idea.md 执笔窗口)使用。

---

```
下面是拆台者的反馈。按以下规则判断并处理,产出 idea.md 最终版(v5)或宣布回 P1。

判断规则:
- 如果拆台文本出现"前提不成立"/"假设错"/"根本不该做"/"方向错"类强否定措辞,且这些论据有实质支撑 → 宣布"回 P1 重做",停止产出 v5
- 否则 → 所有拆台论据都作为框架内修改,更新方案为 v5

终止条件(关键):
- 如果这是第一次 P2D-fix → 按上面规则执行
- 如果这是第二次(即上一轮已回过 P1、刚刚又跑完一遍 P1→P2D)→ 不论 P2D 说什么,一律走框架内修改产出 v5,不得再回 P1

硬性要求:
- 自己判断,不反问
- v5 末尾加"拆台响应日志",注明这是第几次 P2D-fix、以及如果是第二次,原 P2D 里的强否定论据如何被框架内消化

【本次是第几次 P2D-fix】
[手动填:1 或 2]

【P2D 拆台】
[贴入 P2D 产出]
```

---

## 规则结构性特点(参考)

- **第一次 P2D-fix**:几乎必然触发回 P1(P2D prompt 预设方向错、找证据支撑;一旦拆台论据带"前提不成立 / 方向错"措辞 + 一两条具体反证,就同时满足"强否定 + 实质支撑")
- **第二次 P2D-fix**:终止条件兜底强制框架内修改,代价是 v5 可能保留内部矛盾(强否定拆台被框架内消化,意味着方案里可能并存"原方向 + 对原方向的部分让步")

本实验里实验 X 跑两轮、Round 1 + Round 2 的 v5(命名为 v5-旧)就是终止条件兜底的产物。
