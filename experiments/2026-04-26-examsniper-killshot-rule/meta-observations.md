## 比较一 · 议题敏感度（D1 vs D2 是否 60% 重叠）

`liangyi-auto-variant.md` 6.2 节"P2D 议题敏感度"假设：同一 seed 在不同 round 跑出的 P2D，核心议题应有 ≥60% 重叠。

### D1 vs D2 维度对照

| 议题维度 | D1 | D2 | 重叠强度 |
|---|---|---|---|
| 监管定性 | ⑤ 教育部 AI 考试禁令 + 韩国 AI 教材崩溃 | ③ 教育部禁令 + 拍照搜题封禁先例 + 双减传导 | **强**（同一组政策文件 + 同一类历史先例） |
| 免费替代品 | ③ NotebookLM 1.2 亿用户 + LearnLM | ① NotebookLM Plus + 免费 LLM 单次 prompt + 大学免费学科顾问网络 | **中**（D2 比 D1 多了"免费 LLM 单次 prompt 整链路 + 大学既有专家网络"两条新攻击节点） |
| 用户付费意愿 | ① "用户不为作弊工具付费" | ④ "目标用户画像自毁、viral 为负" | **弱**（D1 攻击付费动机正当性，D2 攻击传播链条；同向但不同节点） |
| AI 幻觉 | ② 标注系统不能识别幻觉 | —— | 无 |
| 单位经济 | ④ 长上下文 + 多链路成本 vs ¥19 / 7 天无限题解 | —— | 无 |
| 分发与支付通道 | —— | ② 应用商店 + 微信生态 + 支付通道 + 校园渠道四环全封 | 无 |

### 判定

去重维度共 6 个：监管、免费替代品、用户付费意愿、AI 幻觉、单位经济、分发支付。共有维度 3 个（强 1 + 中 1 + 弱 1）。

按强重叠 + 中重叠计 2/6 ≈ **33%**；按所有共有维度计 3/6 = **50%**。两种算法都低于 60% 重叠门槛。

### 议题敏感度假设的反例

D2 引入的"分发支付通道封堵"是 D1 完全未触及的攻击维度——D1 时（Round 1）拆台专家把火力集中在"用户/产品/AI能力/竞品/监管"五个维度，D2 时（Round 2）才意识到产品上线必经的渠道审查链路本身就是断的。这种角度跨 round 的位移不是细节调整，是攻击坐标轴换了一根。

**结论**：60% 重叠假设在 ExamSniper 场景下不成立。P2D 的议题选择对 round 的输入 idea 状态（v4 的具体细节）相当敏感——D2 看到的是 v4 写出的"内外人格分裂"策略，于是攻击点直接落在"内外两套话术在平台审查面前必然暴露"上；D1 时 v4 还没写到这一层，攻击点就只能落在更上游的"用户/产品/监管"维度。

议题维度的可重叠性比假设乐观，本身可能不是 P2D 设计的缺陷——拆台专家本就该跟着方案的具体形态调整火力，而不是无视方案变化重复 D1 的攻击。这意味着"议题敏感度"或许应该被改写为"议题随方案演化"而非"议题应稳定"。

### 跨实验扩展观察

把 Y-R1 / Y-R2 也纳入对比：

| 对比 | 共有维度 / 总维度 | 比例 |
|---|---|---|
| D1 vs D2 | 3 / 6 | 50% |
| D1 vs Y-R1 | 3 / 7（共有：监管、竞品、付费意愿） | 43% |
| D2 vs Y-R2 | 2 / 7（共有：监管、免费替代/课件锚定） | 29% |
| Y-R1 vs Y-R2 | 2 / 6（共有：合规、数据飞轮） | 33% |

四对比对中**最高 50%、最低 29%**，全部低于 60% 假设。议题敏感度假设在这个场景下被一致性反驳。

## 比较二 · Kill shot 4 格判定矩阵

### 4 格

| | **老规则** | **新规则** |
|---|---|---|
| **D1** | 回 P1（强否定 ✓ + 实质支撑 ✓） | 回 P1（3 kill shot：一/三/五） |
| **D2** | 回 P1（拆台一 + 三达标）→ 终止条件兜底 | 回 P1（3 kill shot：一/二/三） |

### 关键观察

**1. 判定结果零分歧**。4 格全部判"回 P1"，老规则与新规则在 ExamSniper 场景下没有产生不同的方向级判定。

**2. 新规则提供的是判定粒度而非判定结果**。老规则的 D1 判定文本是"五维度独立都构成方向级否定"，全是 K 级；新规则在同一份 D1 上分出 3 个 kill shot（一/三/五）+ 2 个 Fixable（二幻觉为 M 具体性、四单位经济为 F 严重度）——粒度细化让消化策略可分项执行，但累计 ≥2 个 kill shot 后判定结果与老规则一致。

**3. 拆台二（D1·AI 幻觉）的具体性 M 标注是新规则的关键样本**。D1 拆台二引用的 Google AI 摘要案例属新闻摘要场景，迁移到考试场景靠逻辑推理，新规则把它判 M——不算 kill shot 但仍是有效论据。这是新规则比老规则更精细的地方：老规则会把它和其他四条一起作为"实质支撑"统一处理，新规则识别出"具体性强度"的差异。

**4. 拆台四（D1·单位经济）的严重度 F 标注是另一个关键样本**。新规则判 F 的理由是"SKU 上限 / 价格 / 阈值可调，v4 自己已写'超 40% 立刻调阈值'"——即论据指向的问题虽真但属"框架内可消化"。这与老规则的"实质支撑"标准不同——老规则只看"是否有实质支撑"，不看"严重度是 K 还是 F"。

### 4 格 + Y 主线对比

主线 Y-R1（3 kill shot）和 Y-R2（4 kill shot）都判回 P1。把全部 6 次判定放一起：

6 次判定 6 次判"回 P1"。**ExamSniper 这个 seed 在两套规则下都没让任何一次 P2D-fix 走到"框架内消化"——只有终止条件兜底才能逼出 v5**。这是一个比规则差异更重要的事实：seed 本身的拆台密度决定了规则是否能"放过"——拆台稀薄的 seed 才有可能在新规则的 Fixable 路径下框架内消化，拆台密集的 seed 撞两套规则都是回 P1。

## 比较三 · v5-旧 vs v5-新 哪个更站得住

两份 v5 在同一 seed、同一类拆台（差异化 / 付费引擎 / 护城河 / 合规四个维度）的攻击下，被各自规则的终止条件强制产出。路线差异显著。

### 路线对比

| 维度 | v5-旧（X · 老规则兜底） | v5-新（Y · 新规则兜底） |
|---|---|---|
| **核心定位** | "备考期资料整理工具" | "考前提分搭子" |
| **品牌话术** | "提分/押题/狙击/作弊救星"全面去敏感化 | "提分""狙击手"留作副标，押题立场拿到二节正面说明 |
| **监管应对** | 反滥用机制下沉 P0：考试时间窗限流 + 距考试 ≤6 小时降级 + 强制声明 | 承认"不能完全消除，是赛道系统性风险" |
| **课件锚定**（拆台 1 消化） | 保留"页码溯源"叙事 | 改为"术语 / 推导对齐本课老师"，页码段折叠 |
| **押题立场**（拆台 2 消化） | 全面去敏感化 + 不申请教务背书 | 主动收窄 TAM 至"想稳定拿分"用户，承认 TAM 缩小 |
| **数据护城河**（拆台 3 消化） | 重定义为"中国高校本地化 + 学科审校" | 校级数据降为长期愿景，差异化只保留产品形态层两条 |
| **答案输出形态** | 仍输出"答题模板"（学科审校公共课） | **取消"完整解答示范"，改为"答题要点骨架"** |
| **SKU 结构** | 9.9 急救档 + 39.9 公共课审校 + 39.9 专业课 AI 直出 + 168 学期 | 19.9 周卡 + 39 专业版（新增）+ 69 学期 + 9.9 真题包 |
| **退出条件** | "1 年内没建审校题库主动收缩" | "6-12 月内没结构性壁垒，靠速度跑赢" |

### 内部一致性

**v5-旧的内部矛盾点**（X-R2 P2D-fix-judgment 第 11 行已点出）：

- 重新定位为"备考期资料整理工具"以切割考场（拆台三的让步）
- 综合日志声明的"考前应试效率"产品魂仍在产品博客深度文章 / 团队内部叙事中保留
- 这两层在终止条件兜底下并存——前台合规话术 vs 后台保留产品魂

**v5-新的内部矛盾点**（Y-R2 idea-v5 拆台响应日志已点出）：

- 自由判断本应回 P1（4 个 kill shot），终止条件不允许
- 五条消化动作各自落到产品骨架的具体位置（一节、二节、三节示例 ③、六-1、六-2、七-1）
- 整体保留"考前提分搭子"为核心定位，没有像 v5-旧那样背"合规化重写后保留旧魂"的二元矛盾——但代价是诚实承认"监管系统性风险不能消除"

**判定**：v5-旧的内部矛盾是"前台 vs 后台"的话术分裂；v5-新的内部矛盾是"产品方向 vs 自由判断"的归档分裂（已在拆台响应日志显式标注、不藏匿）。后者更诚实，但代价是把"无法消除的风险"摆到风险清单的第一条。

### "更站得住"的分维度评估

| 评估视角 | 哪份更站得住 | 理由 |
|---|---|---|
| 监管诚实度 | v5-旧 | 反滥用机制 P0 + 退出条件 + 全面去敏感化，对监管表态明确 |
| 差异化诚实度 | v5-新 | 直接承认"标页码无价值"+ 价值在术语对齐——是命中 P2D 论据 1 后的真实重写，不是话术包装 |
| 内部一致性 | v5-新 | 产品魂未分裂，归档诚实 |
| 商业锐度 | v5-新 | 保留"考前提分搭子"叙事 + 19.9 + 39 + 69 三档结构，承认 TAM 缩小但保住口碑节点 |
| 工程可执行性 | 平 | 两份都给出具体的产品形态调整（v5-旧：考试时间窗限流；v5-新：取消完整答案改骨架）；都不止是话术 |
| 退出条件可信度 | 平 | 两份都给了 1 年 / 6-12 月退出门槛 |

**总评**：两份 v5 各有取舍，没有"哪个全面更站得住"的简单答案。v5-旧赌"合规化让位换上线可能"，v5-新赌"产品形态调整 + 系统性风险承认换商业锐度"——这是两条不同的商业判断，本身没有规则层面的对错。

但这恰好暴露了**规则差异在终止条件兜底产物上的倾向**：

- **老规则（粗粒度二元触发）**兜底产物倾向**全面合规化**——因为规则不区分 K/F，每条都得当 K 处理，导致 v5 被迫做"全维度合规化重写"。
- **新规则（K/F 细分 + 各 kill shot 独立消化路径）**兜底产物倾向**按维度分别处理**——K 项做产品形态调整（论据 5：取消完整答案）、F 项做 SKU 调整（论据 4：新增专业版）、对无法消除的 K 项坦白承认（论据 5：监管系统性风险）。

这是 meta-observations 的最重要观察——**规则差异不只是判定粒度差异，是兜底产物倾向差异**。

## 比较四 · 流程长度

### 实际流程

| 实验 | 规则 | Round 1 P2D-fix | Round 2 P2D-fix | 实际轮数 |
|---|---|---|---|---|

**两条主线流程长度相同——都是 2 轮**。

### README 预期 vs 实际

README 第 12 行："如果触发回 P1 走 Round 2，否则直接 Round 1 框架内产出 v5-新"——隐含假设：新规则可能因 ≤1 kill shot 在 Round 1 就产出 v5。

**这个假设在 ExamSniper 场景下没有兑现**。Y-R1 P2D-fix 直接判 3 kill shot ≥ 2 触发回 P1，与老规则的 X-R1 同步走 Round 2。新规则的"提前结束"机制（≤1 kill shot 框架内消化）在这个 seed 下完全没用上。

### 对场景拆台密度的观察

把 6 次判定全部并起来看（3 个 kill shot + 4 个 kill shot + 老规则两次都判回 P1），ExamSniper 这个 seed 的拆台密度天然偏高——竞品（NotebookLM/免费 LLM）+ 监管（AI 考试禁令）+ 合规（学术诚信）三条独立硬墙均有可复核的 2025 政策 / 行业先例支撑，任何一条都满足 H + K，单独构成 kill shot。新规则的"放过"机制需要 ≥2 个独立维度都拆不出 kill shot，这在拆台密度高的场景下几乎不可能。

**新规则在缩短流程方面的潜在价值，需要在拆台密度更低的 seed 上才能验证**——目前 ExamSniper / 美团风控 / Agent 评测平台三个场景下尚未观察到。

## 实验产出对方法论本体的回灌候选

按记忆规则"方法论不做思辨性挖掘——只由实际使用撞到的真问题驱动"，本场景在跑动中撞到的、值得回灌方法论的具体观察：
