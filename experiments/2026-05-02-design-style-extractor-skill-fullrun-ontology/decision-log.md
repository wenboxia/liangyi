## 决策点 5 · 2C-rollback 是否回退

**位置**：读 Claude-4 P2C 漂移诊断后

**P2C 指出的方向漂移**（4 处）：
- 漂移 A · 从"专业纪律工具"滑向"大众友好工具"——所有硬门槛软化的累积

- 漂移 C · 双层关系从"互相校准"变成"先后单向"——v3 第三节"双层防止散文化"的论证基础被动摇
- 漂移 D · 成功标准从绝对降为相对——v1 "做出对的味道"被替换为 v3 "不输于直接喂图"

**我的判断**：
- 漂移 A：(c) 确认漂移、不回退、显性记录——底色就是 vibe coder 友好；但增补"双轨服务对象"段说明专业设计师也可作草稿用
- 漂移 B：(b) 部分回退——产物是灵活资产、用户可直接当成品也可作初品手改、但定位回到"资产"
- 漂移 C：(c) 双重保留——没有明确倾向、把"互相校准"和"4 步流程 + 单向锚"两者并置
- 漂移 D：(b) 部分回退——"做出对的味道"是合格标准、"不输于直接喂图"是底线、两者并存

**给 Claude-2 的指令**（原文摘要）：
> 漂移 A 接受、底色是 vibe coder 友好、专业人员也可快速打草稿 / 漂移 B 产物是灵活资产、普通用户可直接用、专业设计师可作初品 / 漂移 D 不能这么对立、skill 肯定要做到最好、下限高于直接喂图也不矛盾 / 漂移 C 没有明确倾向和决定、可以都保留

**事后注释**：漂移 A 的"双轨服务对象"补救在后续 P2D 被 H4 直接打回——"双轨用户定位是矛盾承诺、低门槛和精修起点不能共用同一份产物"，最终在 v5 删干净。这次决策不是判断错——是 P2D 暴露了 P2C 没看到的内部矛盾。**P2D 在本场景做了 P2C linear 链条没做完的事**。

## 决策点 7 · 2D-fix 框架判定

**位置**：读 DeepSeek-2 P2D 拆台后

**P2D 拆台论据列表**（含 K/H 标记）：
- K1 · "双层耦合"在 LLM 里是伪因果关系、体感层和令牌层无法互相约束
- K2 · "可重复"是假卖点——同一份 skill 在不同下游模型上的执行方差大到让它不成立
- H3 · 万能抽取器的前提（5–7 张截图压缩完整风格）在 UI 设计领域是假的
- H4 · 双轨用户定位是矛盾承诺、低门槛和精修起点不能共用同一份产物

**我的判定**：4 条全部为框架内问题（不回 P1、在 idea 内消化）

**和 Claude-2 对齐过的 4 项最终决策**：
- **K1 应对**：双层耦合从"互相约束（产品哲学支点）"降级为"结构化产出 + 人类可审计"——接受降级
- **K2 应对**："可重复"卖点收窄到"在固定下游模型 + 固定 skill 组合下可重复"——接受收窄；具体上下游模型清单作为讨论阶段开放议题（不在 v5 里硬定）
- **H3 应对**："万能抽取器" → "参考图风格压缩器"；motion 字段选 B（独立分区、只描述性格、不出数值）；明确覆盖率 70–80%
- **H4 应对**：单一定位 vibe / web coder、双轨叙述全部删干净

**最终路径**：Claude-2 续修 → `idea-v5.md`、并新增第七节"已知风险与应对"把 K1/K2/H3 作为方案自身认知正面写出。

**事后注释**：K1 的应对实质上是回到了 P2C 漂移 C 的"双重保留"问题——但这次是基于 LLM 自回归架构限制做的诚实降级、不是 P2C 时的"未明决策"。同一处机制在 P2C 是"漂移、双重保留"、在 P2D 升级为"伪因果、必须降级"。**P2D 比 P2C 更深、采用 P2D 的判断是合理的**。
